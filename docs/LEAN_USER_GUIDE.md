# Lean ERP 日常使用

[返回 README](../README.md#日常使用)

## 日常操作

1. 管理员在设置建立账户；采购员维护物料、客户和供应商。
2. 销售负责人新建需求、报价及签约，签约时另行指定项目经理和项目成员。收款节点合计必须等于最终报价，销售通过交接服务生成执行项目和应收；从销售单的执行项目链接进入后续工作。内部项目也可直接在项目模块创建。
3. 经理可先在项目“成本与预算”页签设置材料、人工、费用预算，再维护或导入 BOM。采购员按缺料建采购，提交后由经理批准，自动生成应付。超预算时需明确确认并填写原因，核算快照留在审计中；未设置预算的旧项目仅提示、不拦截。手工采购的数量超出项目 BOM 缺口（备件、损耗补买等）时须填写“超 BOM 采购原因”，审批时会看到提示；按缺料补货请用“从 BOM 多选下单”。用表格导入采购时，超出缺口的那张单须在“超 BOM 采购原因”列填写原因（同组任一行填写即可，通常写在超出的那一行），不填则预览时提示该行超出多少。待审批的采购单发现选错时，采购员可直接“作废采购”，不必等审批人退回。
4. 仓管分批收货：先填入库日期（实际到货当天，之后在库存流水、现有库存和采购明细里都能查到），表格默认全选并按待收填入，没到货的行取消勾选即可；超过待收的数量提交前就会提示，多送部分请采购另行“新建采购”补单。供应商不再补货时，兼有采购权限的人可在收货时勾选该行“余量不再到货”并填写原因，与收货一次完成；纯仓管请采购在“取消未收余量”处理。首次使用的新库位需勾选确认；按项目领料（占用其他项目已到货物料时需确认）；库存页或项目 BOM 页的“按 BOM 领料”可一次领整个项目的多行物料：每行前有勾选框，默认都不勾，勾上的行按 BOM 未领数量和库位填入数量（可改小），没勾的行本次不领，不用逐行清零；上方可按“非标件（机加、钣金）”“标准件 / 电气件”筛开，按住 Shift 先后点两行的勾选框可把中间的行一起勾上；任一行不满足则整单不出库。项目 BOM 页点“展开完整列”可看到每种物料“本项目最近入库”日期（采购反审冲回的不算），采购缺料导出也带这一列。零散领多种物料时，在“库存 → 现有库存”勾选各行（只能勾有库存的行，翻页、换搜索后勾选保留，一次最多100行），点“批量领料（N）”，选项目（已验收项目须选该项目的售后任务）、填一次领料说明，再逐行填写本次领料数量（默认留空，按实物点数填写；需要整库位领走时点“全部按可用填入”），一次提交出库；任一行超过可用库存或 BOM 剩余（售后任务除外）则整单不出库，提示会写明是哪种物料。管理员打开“批量管理”时勾选列让给批量删除，退出后恢复原勾选。每次领料——单行领料、勾选批量领料、按 BOM 领料——都生成一张领料单（单号如 LL000001），成功提示里点“查看 / 打印领料单”可打印或另存 PDF，交领料人和仓管签字。领料时可填“领料人”（实际来仓库领料的人，如“装配班 张师傅”，不一定有系统账号，选填），会印在领料单上，领料单列表、库存流水和物料跟踪表都能看到；经办仓管由系统另记。之后可在“库存 → 领料单”按项目、日期、单号、领料人或物料查找并重新打印，库存流水的“关联单据”列也能点到所属领料单。领料单上线前的历史领料没有领料单；退料仍从原领料流水办理，不改动领料单。收货、领料、收付款登记、批准采购等日常确认的说明可以不填，系统自动记为动作名；退回、取消、冲销、盘点等纠错仍须填原因。未收余量可取消，退货、盘点和退款保留历史。
5. 经理在项目“任务与工时”一键生成六阶段里程碑，安排负责人和日期，成员完成任务，工时由负责专业主管或项目经理统一登记。发货前检查任务和对应领料量，支持多批设备交付。金额可见角色（管理员、项目经理、财务）打开发货对话框时，顶部提示条会逐个列出本项目未收的应收节点（款项名、未收金额、到期日，逾期标“已逾期”），发货成功后再提醒一次；仅提示不拦截，如合同约定发货后付款，请通知财务用“调整到期日”改期。
6. 每批完成安装后由经理验收。售后关联验收批次：质保内免费，质保外登记收费；过保免费须由项目经理写明原因。售后领料和工时纳入项目成本。
7. 财务登记费用、收付款、退款和冲销；合同约定的付款时间变化时，在应收行“调整到期日”（须写原因，金额不变）。任务、采购及余额全部处理后才能结项；需要继续售后时可重新打开项目。

淘宝、京东等网上买的物料可以记下商品链接：在“基础资料 → 物料”新增或编辑物料时填“购买链接”，可以直接粘贴 App 里“分享 → 复制链接”得到的整段文字，系统只保存其中的链接。BOM 导入模板末列也是“购买链接”：新物料按表保存；已有物料原来没有链接时补上，已有链接不会被覆盖（要换链接到基础资料改）；填的不是网址时这一行照常导入，只是不保存链接，预览里会写明。填了链接的物料，在 BOM“缺料下单”、从 BOM 多选下单、采购单“查看明细”和物料列表里，名称旁显示“淘宝 ↗”“京东 ↗”这样的链接，点开在新标签页打开商品页。

采购合同、领料单要存成 PDF 时，点页面上的“打印 / 另存为 PDF”，在打印窗口的“打印机”里选“另存为 PDF”再保存。文件名已默认填好：采购合同为“采购合同-供应商-合同编号”（归档版本加“第N版”，未批准加“草稿”），领料单为“领料单-单号-项目编号”。不要用浏览器菜单的“另存为”或 Ctrl+S，那样存下的是网页。Windows 默认用 Edge 打开 PDF 时，PDF 文件显示的就是 Edge 图标，属正常；右键“属性”里文件类型为 .pdf 即可。

合同/费用、采购/库存、工时各只维护一份业务事实。成本为 CNY 含税经营口径，不替代法定会计账。附件通过登录鉴权下载；成员仅可访问所属项目，敏感金额由后端按角色过滤。

## 非标件改图（换版）

同一个非标件每改一次图就是一个新的图档版本，系统里用一个新的物料编码表示；项目 BOM 里把旧版换成新版，叫“换版”。

1. **工程师换版**：项目 BOM 页某行点“操作 → 升版”，填新的图档版本（如 B）、变更说明，名称或规格有变化时一并填写；系统自动新建新版物料（同图号、同版本的已存在就直接用），在原单元把旧版换成新版。同一物料还用在其他项目时，可勾选一并换版（默认只改本项目，只能勾选自己能维护 BOM 的项目）。换成另一个型号用“替换物料”。批量改图用 BOM 导入：在模板末列“替换原编码”填旧版编码，本行物料编码填新版；同图号升版时物料编码可以留空，只填新的“图档版本”。
2. **旧版还没到货的采购**：换版时自动按新图改单。还没批准的采购单直接改成新版；已批准的采购单里旧版余量取消、同单新增新版明细，采购员在工作台“换版改单待确认”或采购单“确认换版改单”里处理：供应商能按新图做就“按新图改单”（报价变了可改单价，应付同步调整；调高单价须由采购经理、项目经理或管理员确认并复核预算），不能做就“取消余量”再按缺料重新下单。确认前仓库不能收这一行。
3. **旧版已到货或已领用**：多出来的旧版出现在项目 BOM 页上方“旧版待处理”和工作台：
   - 仓管：在库的旧版“在库报废”（出库，金额计入项目材料成本）或“留作备件”（不出库，不再算本项目的）。
   - 仓管或工程师：已装在设备上的旧版拆下报废，用“已装机报废”登记数量。
   - 采购员：能改制的用“开返修单”生成一张新版物料的返修采购草稿，照常提交审批；在库旧版返修的，收到改好的新版时旧版自动出库。

4. **反复改图时少走弯路**：
   - 别的项目已经换成新版的旧版物料，在 BOM 行、物料下拉、BOM 导入预览和基础资料物料列表里标“有新版 B”（或“该图已有新版 B 版（编码）”）。BOM 行“操作 → 升版（换成已有 B 版）”会直接填好新版本号，确认后复用已有新版，不再重复建料。
   - 升版、替换物料对话框和导入预览会先写明换版后的影响：哪些采购单会直接改成新版、哪些已批准采购要等采购员确认、换版后旧版已装机和在库各有多少要进“旧版待处理”；别的单元还要用旧版的会先留给它们。
   - 基础资料“物料 → 操作 → 版本记录”列出同一图号的全部版本、当前最新版，以及你参与项目里每次换版的时间、项目、数量和变更说明（ECN）。
5. **合同已归档的采购按新图改单后**：确认后会提示重签；工作台“换版待重签合同”列出这些采购单，采购合同页上方逐条列出与已归档版本相比改了什么（数量、新增新版明细、单价、交期），点“查看改单后的当前合同”核对，与供应商签回后“归档新版本”，提醒随即消失。

换版不再因为旧版在途或已领用被拦住；换版记录在“旧版待处理”下方的“换版记录”里可查。

## 物料跟踪：跨项目查看全部物料状态

左侧导航“物料跟踪”（能看 BOM 的岗位都有）把所有项目的物料汇成一张表，每个项目的每种物料一行，代替手工维护的物料跟踪 Excel：

- **一行看清**：需求（BOM 各单元合计）、已采购（已批准，另写“待批 N”）、已收、已领、缺料、在途，以及采购单号、供应商、单价、金额、采购交期、最近入库日期、送货单号 / 收货说明、采购员、最近领料日期、领料人、领料单号，图号 / 版本、型号 / 规格、单位、类别、单元、需求日期、申请日期、申请人和备注。同一物料分几次采购时，采购单号、供应商、交期并列写在格子里，单价不同写“多个”（悬停看全部价格）。缺料与 BOM 页同一口径。
- **不在 BOM 的物料也列出**：项目后来另外采购（零星采购、补料）或领用、但不在当前 BOM 里的物料（包括改版时从 BOM 移除但已买或已领的），同样各占一行，标“不在 BOM”，需求和缺料写“—”。勾“只看不在 BOM 的物料”可以单独查看。
- **状态**：缺料（BOM 还有缺口）、在途（已批准未到货）、待批采购、待领料（库存够或已到货，还没领完）、已领完。上方按状态一键筛选，另可按物料类别、供应商、关键词（物料编码、名称、型号、图号、项目）筛选。
- **范围**：上方“项目筛选”选项目时只看该项目；不选时看需求中到交付中的项目，勾“包括已验收、已结项项目”看全部。只看到自己参与的项目（全局岗位看全部）。
- **跳转与导出**：项目号点开该项目 BOM，采购单号点开采购明细，领料单号点开可打印的领料单。“导出 Excel”按当前筛选导出全部行。
- **谁能看什么**：采购单号、供应商、采购员、送货单号只给能看采购单的岗位（采购、仓管、财务、经理）；单价、金额只给能看采购价的岗位；其他人看需求、数量、交期和领料情况。手机上每种物料一张卡片，数量写成一行“需求 · 已采购 · 已收 · 已领 · 缺料”。

## 采购单批准后发现填错（反审）

采购单批准后才发现单价、数量或交期填错，而且已经收了货，可以“反审”：采购列表该单“操作 → 更正与撤销 → 反审”。有权批准这张采购的人（经理、采购主管）可以反审；本单申请人不能反审自己的单子（与批准同一规则），管理员例外但须写明原因。

1. 打开反审先看清会发生什么：要冲回哪几次收货（物料、数量、库位、收货日期）、作废多少应付；本单归档过采购合同的，会提醒改单后与供应商重签。
2. 填“反审原因”，写清要改什么（例如“第 2 项单价 12 改为 10.5”），确认后单子回到草稿：已收的货按收货数量从库存冲回（库存流水记“反审冲回”），应付作废；冲回的成本差与采购退货一样计入本项目“采购退货与反审价差”。
3. 采购用“修改采购”改好后重新提交审批；批准后重新生成应付，仓库重新收货，收货日期可以填实际到货那天。

下列情况反审会被拦下，并逐条写明先做什么：已付款或有供应商退款（财务先冲销）、已有未作废的对账单（财务先作废）、有到货在隔离待检（仓管先处理隔离品）、已办理采购退货或登记了采购质保、含换版改单明细，以及到货已被领用（库存不够冲回，或冲回后会占用其他项目已到货的物料，请先退料）。

采购列表“采购编号”下面写着提交人（还没提交过的草稿写创建人）。被审批人“退回修改”、同意修改申请或反审回到草稿的单子，状态写“已退回，待修改”“已反审，待修改”，下面写着谁、什么时候、为什么退回（悬停看完整原因），提交人的工作台也会把它排进“今天要处理的”。重新提交后这些提示自动消失。

## 编号、列表与批量操作

物料、往来单位、销售、项目、采购、交付和对账七类编号均支持手工填写或留空自动生成，页面新增和Excel/CSV导入规则一致。管理员在设置中配置自动编号，仅影响留空的新记录。手工编号最多30字符，Excel按文本填写保留前导零；已用编号（含停用、已删除）不可重新占用。自动编号会避开已用编号。销售签约可另填执行项目编号，合同编号仍按签署合同填写。


物料建议先由指定人员核对厂家或供应商的完整型号，再统一维护内部编码。BOM填写已有编码时复用该物料，名称型号可留空；补填不一致会提示核对。表里填的编码系统里没有、但同图号同版本的物料已经有了（常见于表里沿用了自己的旧编号）：名称一致就按系统里的编码使用，预览写明“表中编码 X 系统里没有；同图号同版本的物料是 Y，已按系统编码使用”，可以直接确认导入；名称不同会拦下并写出系统编码，请核对图号，或把编码改成系统编码。已有物料没有品牌的（BOM 和导出里品牌一栏空着），可在导入文件的品牌列填上后导入，预览显示“沿用已有物料，补填品牌”，确认后品牌写入物料资料；已有品牌不会被文件改写，品牌写错须到基础资料修改。不填编码时，系统找到一条除品牌外完全相同、且没有品牌的物料，会补品牌并复用它，不会再建一个重复物料；找到多条时提示填写编码。只补品牌、BOM 数量单元都没变的文件也可以确认。填写新的自编编码时须同时填写物料名称、完整规格和单位；留空编码自动建料时还须选择产品编码类别，有图物料须填图号。

名称、规格、品牌和单位按原文保存（仅去除首尾空白），不自动猜型号、补后缀或删除内部空格、符号。名称或型号的空格、全角差异及同品牌同型号的异名会提示疑似重复；先核对现有编码，确属不同物料时到基础资料填写独立建码原因。基础资料里系统不因相似就自动合并；BOM 导入时同规格、同品牌、同单位的物料按同一物料复用，预览会列出「请核对」的自动处理，确认前逐条看一遍。已有错误型号及重复编码须逐项核对处理，本次不会批量改写历史资料。

业务列表、经营报表及 BOM 支持每页 10/20/50/100 条，默认 20 条，选择在当前浏览器保存并跨页面复用；长表格在内部滚动。

各业务列表和表单明细增加“序号”，同一筛选结果跨页连续计数，例如每页10条时第二页从11开始。筛选或排序后序号随当前顺序变化，查找原单仍使用物料编码、订单编号等业务编号。编辑明细显示“第几行/项”；导入预览和Excel附件保留原文件行号，合同保留原明细序号。

列较多时，表格底部会显示横向滚动条及“向左查看 / 向右查看”按钮；全部列已放得下时不显示多余按钮。手机窄屏可横向查看全部列，收货和出库明细继续逐款展示，便于填写。滚动查看、分页和序号显示不会改变勾选记录或原有业务编号。

管理员清理销售、项目、BOM、采购、库存、收付款、任务、交付、工时、基础资料、用户或附件时，可先筛选，再点表格上方“全选筛选结果（…项，跨页）”，点击“批量删除”并核对明细、填写原因后确认。每批最多1000项；超过1000项时按钮明确显示“选择筛选结果前1000项”，处理后可继续下一批。表头复选框只选/取消本页，翻页保留勾选；切换筛选、项目、表单、附件所属单据或刷新会清空旧选择。已有采购、领料、库存等关联影响时仍按原规则校验，任何一条不能删除则整批保留；删除记录和原因可在“已删除记录”查询。BOM删除的是当前项目的用料明细，不会删除基础物料资料。BOM 的维护用料、缺料下单两个视图在批量删除模式下用同一套勾选；缺料下单视图里的采购勾选和“从 BOM 多选下单”此时收起，点“退出批量删除”后恢复。库存、资金、工时等历史流水只移入“已删除记录”，原始记录和余额保留；用户删除后停用并保留历史，不能删除当前登录账号。公司资料、编号规则、审计日志及只读经营报表不提供删除操作。
采购、销售单据的“附件”弹窗里传错了文件（例如传错比价表），上传人本人可以自己删除，不用找管理员：勾选要删的附件（只有自己有权删除的行才有复选框）后点“删除所选（N）”，或点该行右侧“删除”，核对文件名、填写一次原因（整批共用）后确认。项目经理可整理本项目内他人上传的附件。删除只是把附件移出列表，记录、文件本体和上传审计仍保留并写入删除审计；已作为收付款流水、补录凭证、对账单、补充协议或归档采购合同依据的附件不能删除，项目已结项需先重新打开，任一份被拦截则整批不删，提示会写明是哪一份文件。每批最多50份。管理员登录时该弹窗仍使用上一段的批量删除（含“已删除记录”），不会同时出现两套勾选；这类上传人自助删除不进入“已删除记录”，其依据是附件列表之外保留的记录和审计。

采购列表及项目BOM的“从 BOM 多选下单”支持按品牌、单元、标准件/非标件组合筛选，跨页勾选或全选筛选结果，再统一填写供应商、数量和单价。品牌和类别在物料资料维护，单元在项目BOM行维护；保存时重验实际缺口，订单仍需提交审批。

业务页面可选择 Excel/CSV 导出全部筛选结果，采购明细逐行展开，经营报表带合计。支持物料、客户供应商、销售和采购草稿、项目、任务、期初库存、领料、费用、收付款、对账草稿、工时及发货的模板下载和批量导入；BOM 保留原导入入口，银行流水上传银行原始文件（见[银行流水导入](BANK_IMPORT.md)）。操作顺序为下载模板 → 选择文件预览 → 修正行级错误 → 确认导入；各模板的填写规则见模板旁“下载填写说明”，通用做法见[导入模板填写说明](IMPORT_TEMPLATES.md)。导出最多20000行；确认再次校验并整批保存，导入不覆盖原记录，签约、审批及流水纠错仍走原操作。

详细业务范围见 [CORE_ERP_SCOPE.md](CORE_ERP_SCOPE.md)，固定管控规则见 [OPERATIONAL_HARDENING.md](OPERATIONAL_HARDENING.md)。


## 六阶段项目里程碑

入口：项目列表 → 点击项目名称 → 任务与工时 → 项目任务 → 一键生成里程碑。项目经理或管理员可使用，默认20个节点，确认前可移除不适用行、添加节点之外的任务、选择负责人和计划完成日期。已有项目不自动新增，重复生成只补缺少节点，保留原有任务与安排。

| 阶段 | 默认节点 |
| --- | --- |
| 设计阶段 | 3D画图、3D评审、长交期物料、标准BOM、电气BOM、其它图档 |
| 采购阶段 | 长交期、电气料、其它物料 |
| 装配阶段 | 安装、接线 |
| 调试阶段 | 对信号、手动调试、自动调试 |
| 发货阶段 | 客户预验收、整改、发货 |
| 客户终验收阶段 | 现场安装接线、现场调试、现场验收 |

任务从上往下按设计、采购、装配、调试、发货、客户终验收排列，各阶段内按模板节点顺序展示；翻页、导出保持相同顺序。自定义任务排在所属阶段固定节点之后。

执行人可搜索姓名并多选，选中的姓名显示在输入框中，可逐个移除。多人共同执行时，由负责专业主管或有权限的项目经理统一确认整项完成；主管按实际人员和日期登记工时，员工查看。每位执行人都能在“我的任务”和工作台看到该任务。

六阶段可交叉推进，例如设计期间先跟进长交期物料。点击阶段卡片可筛选任务，再次点击或点“全部”恢复列表；客户终验收阶段同时显示各批安装和验收任务，方便直接办理。任务“操作 → 重新分配”可同时调整执行人和计划完成日期，只想改日期时用“改计划日期”（须写原因，会通知执行人）；无需的计划可取消，保留记录。新增单项任务时先选阶段、再选节点；节点留空可填写任务名称。已取消的节点不会被模板重复创建，需要继续时重开原任务。

“发货”由全部设备实际登记发货后完成；“现场安装接线”由全部设备发货且各批安装任务完成后汇总完成；“现场验收”由全部批次实际登记验收后完成。这三个汇总节点不能直接点完成或重复登记工时，请在“交付与售后”办理验收、从“项目操作 → 发货”登记发货，在批次安装任务登记安装进度和工时。原发货所需任务、BOM、领料及数量检查，验收前安装完成检查仍有效。

生产经理仍仅能创建参与项目的装配、调试任务，不因新增阶段获得采购、发货、验收或设计派工权限。项目相关人员可查看节点进度，执行人可在工作台找到自己的待办。任务导入的执行人支持多个姓名或账号，用分号分隔（例如“张工；李工”）；重名仍填写姓名（账号）。任务导入模板新增选填“里程碑节点”，继续兼容旧六列文件；日期填具体计划完成日期，不填工期天数。

自动同步节点的操作栏显示同步依据和“查看交付进度”入口：发货按实际发货记录、现场安装接线按各批安装任务、现场验收按实际验收记录完成。这些节点不提供手动“完成任务”，实际批次安装仍在具体安装任务确认。

### 任务计划与实际完成日期

任务列表、详情和导出分别展示“计划完成日期”和“实际完成日期”。点“完成任务”时确认实际完成当天，可补录过去日期，不能填写未来日期；完成任务不要求填写工时。系统同时保留提交时间，便于追溯。

历史已完成任务没有实际日期的，由负责专业主管或有权限的项目经理在“操作 → 补录完成日期”填写；已有日期通过“更正完成日期”说明原因后修改，保留修改记录。重开任务会清空当前完成日期，重新完成时再填写。

发货、现场安装接线和现场验收汇总节点从实际业务记录同步日期。批次安装日期不得早于发货或晚于验收，验收日期不得早于安装完成。历史安装日期不全时，先补齐具体安装任务；不要直接更改汇总节点。

任务经过的天数不等于人员实际投入的工时；当前完成日期登记不自动生成工时或人工成本，已有工时记录仍保留。

### 开始任务与自动计算天数

执行人或有权限的经理在任务行点“开始任务”，确认实际开始日期，再在做完后点“完成任务”确认实际完成日期。开始日期可补录，日期不能晚于今天，完成不能早于开始。忘记点击开始时，也可以在完成窗口补录实际开始日期；留空会提示缺少日期，系统不会用任务创建日期代替。

任务列表和详情自动显示“任务历时”及“提前／延期”：按自然日包含开始和完成当天，当天完成记1天；例如11月1日开始、11月9日完成为9天。未完成算到今天，完成后固定到实际完成日。与计划完成日期比较，显示提前几天、按期完成或延期几天；未完成只显示已逾期或未逾期。没有计划日期则不计算偏差，没有实际开始日期则不计算历时。

日期有误，由负责专业主管或有权限的项目经理在“操作 → 更正开始日期／更正完成日期”说明原因；历史已完成任务使用“补录开始日期／补录完成日期”。更正后天数自动重算，原日期和修改记录保留。重开保留最初开始日期，返工时间包含在历时中；取消的任务不继续计算。

这些天数用于跟进进度，不自动换算为人员工时或人工成本。一个任务多人共同执行只统计一份任务历时，原有工时及成本记录保持独立。

### 查看已经登记的工时

登记成功后，页面会显示人员、工作日期和本次保存的小时数，点击“查看工时明细”可立即核对。任务列表新增“已登记工时”，点击小时数或“操作 → 查看工时”可查看任务累计、本人工时及每笔记录的人员、工作日期、小时数、说明和提交时间；没有记录时显示“未登记”。

这里的“我的累计”按实际工作所属人员统计，经理代填的工时归被代填人。合计包含所有分页，并扣除冲销；更正后原记录标为“已冲销”，负数冲销和更正后的记录都保留。移至“已删除记录”的历史流水仍计入核对合计。工时填错请在项目“任务与工时 → 工时记录”找到记录后更正。“已完成”是任务状态，不能代替工时提交回执；任务历时天数与人工工时分开。

### 专业主管统一跟进任务

进入“项目 → 具体项目 → 任务与工时 → 项目任务”，项目经理点击“设置专业主管”，从项目成员中选择机械、电气、采购、生产、交付与验收主管。没有选人的专业由项目经理代管；先在项目成员加入人员，再设置主管。

创建或重新分配任务时可选“负责专业”，不选按阶段/节点自动确定。任务列表显示对应主管；分配或调整后，主管工作台的“任务提醒”出现未读消息，“我负责确认的任务”集中列出待办，点“查看并处理”直接定位任务。阅读提醒不等于完成任务。

主管记录实际开始、完成日期，并按每名员工、每个工作日的实际小时数登记；员工可以查看进度及工时明细。系统自动显示任务历时和提前/延期天数，但不会将历时换算为人工费用。已登记工时可以更正，系统保留原记录、冲销和更正记录。原来的派工、取消、重开、发货和验收权限不因指定主管而增加。
