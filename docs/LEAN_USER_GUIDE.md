# Lean ERP 日常使用

[返回 README](../README.md#日常使用)

## 日常操作

1. 管理员在设置建立账户；采购员维护物料、客户和供应商。
2. 销售负责人新建需求、报价及签约，签约时另行指定项目经理和项目成员。收款节点合计必须等于最终报价，销售通过交接服务生成执行项目和应收；从销售单的执行项目链接进入后续工作。内部项目也可直接在项目模块创建。
3. 经理可先在项目“预算与成本管控”设置材料、人工、费用预算，再维护或导入 BOM。采购员按缺料建采购，提交后由经理批准，自动生成应付。超预算时需明确确认并填写原因，核算快照留在审计中；未设置预算的旧项目仅提示、不拦截。手工采购的数量超出项目 BOM 缺口（备件、损耗补买等）时须填写“超 BOM 采购原因”，审批时会看到提示；按缺料补货请用“从 BOM 多选下单”，采购导入不支持超出缺口的行。待审批的采购单发现选错时，采购员可直接“作废采购”，不必等审批人退回。
4. 仓管分批收货（首次使用的新库位需勾选确认）、按项目领料（占用其他项目已到货物料时需确认）；库存页或项目 BOM 页的“按 BOM 领料”可一次领整个项目的多行物料，任一行不满足则整单不出库。收货、领料、收付款登记、批准采购等日常确认的说明可以不填，系统自动记为动作名；退回、取消、冲销、盘点等纠错仍须填原因。未收余量可取消，退货、盘点和退款保留历史。
5. 经理在项目“任务与工时”一键生成六阶段里程碑，安排负责人和日期，成员完成任务并登记工时。发货前检查任务和对应领料量，支持多批设备交付。金额可见角色（管理员、项目经理、财务）打开发货对话框时，顶部提示条会逐个列出本项目未收的应收节点（款项名、未收金额、到期日，逾期标“已逾期”），发货成功后再提醒一次；仅提示不拦截，如合同约定发货后付款，请通知财务用“调整到期日”改期。
6. 每批完成安装后由经理验收。售后关联验收批次：质保内免费，质保外登记收费；过保免费须由项目经理写明原因。售后领料和工时纳入项目成本。
7. 财务登记费用、收付款、退款和冲销；合同约定的付款时间变化时，在应收行“调整到期日”（须写原因，金额不变）。任务、采购及余额全部处理后才能结项；需要继续售后时可重新打开项目。

合同/费用、采购/库存、工时各只维护一份业务事实。成本为 CNY 含税经营口径，不替代法定会计账。附件通过登录鉴权下载；成员仅可访问所属项目，敏感金额由后端按角色过滤。

## 编号、列表与批量操作

物料、往来单位、销售、项目、采购、交付和对账七类编号均支持手工填写或留空自动生成，页面新增和Excel/CSV导入规则一致。管理员在设置中配置自动编号，仅影响留空的新记录。手工编号最多30字符，Excel按文本填写保留前导零；已用编号（含停用、已删除）不可重新占用。自动编号会避开已用编号。销售签约可另填执行项目编号，合同编号仍按签署合同填写。


物料建议先由指定人员核对厂家或供应商的完整型号，再统一维护内部编码。BOM填写已有编码时复用该物料，名称型号可留空；补填不一致会提示核对。填写新的自编编码时须同时填写物料名称、完整规格和单位；留空编码自动建料时还须选择产品编码类别，有图物料须填图号。

名称、规格、品牌和单位按原文保存（仅去除首尾空白），不自动猜型号、补后缀或删除内部空格、符号。名称或型号的空格、全角差异及同品牌同型号的异名会提示疑似重复；先核对现有编码，确属不同物料时到基础资料填写独立建码原因。系统不因相似就自动合并。已有错误型号及重复编码须逐项核对处理，本次不会批量改写历史资料。

业务列表、经营报表及 BOM 支持每页 10/20/50/100 条，默认 10 条，选择在当前浏览器保存并跨页面复用；长表格在内部滚动。

各业务列表和表单明细增加“序号”，同一筛选结果跨页连续计数，例如每页10条时第二页从11开始。筛选或排序后序号随当前顺序变化，查找原单仍使用物料编码、订单编号等业务编号。编辑明细显示“第几行/项”；导入预览和Excel附件保留原文件行号，合同保留原明细序号。

列较多时，表格底部会显示横向滚动条及“向左查看 / 向右查看”按钮；全部列已放得下时不显示多余按钮。手机窄屏可横向查看全部列，收货和出库明细继续逐款展示，便于填写。滚动查看、分页和序号显示不会改变勾选记录或原有业务编号。

管理员清理销售、项目、BOM、采购、库存、收付款、任务、交付、工时、基础资料、用户或附件时，可先筛选，再点表格上方“全选筛选结果（…项，跨页）”，点击“批量删除”并核对明细、填写原因后确认。每批最多1000项；超过1000项时按钮明确显示“选择筛选结果前1000项”，处理后可继续下一批。表头复选框只选/取消本页，翻页保留勾选；切换筛选、项目、表单、附件所属单据或刷新会清空旧选择。已有采购、领料、库存等关联影响时仍按原规则校验，任何一条不能删除则整批保留；删除记录和原因可在“已删除记录”查询。BOM删除的是当前项目的用料明细，不会删除基础物料资料。库存、资金、工时等历史流水只移入“已删除记录”，原始记录和余额保留；用户删除后停用并保留历史，不能删除当前登录账号。公司资料、编号规则、审计日志及只读经营报表不提供删除操作。

采购列表“从 BOM 多选下单”及项目BOM“按缺料采购”支持按品牌、功能单元、标准件/非标件组合筛选，跨页勾选或全选筛选结果，再统一填写供应商、数量和单价。品牌和类别在物料资料维护，功能单元在项目BOM行维护；保存时重验实际缺口，订单仍需提交审批。

业务页面可选择 Excel/CSV 导出全部筛选结果，采购明细逐行展开，经营报表带合计。支持物料、客户供应商、销售和采购草稿、项目、任务、期初库存、领料、费用、收付款、对账草稿、工时及发货的模板下载和批量导入；BOM 保留原导入入口。操作顺序为下载模板 → 选择文件预览 → 修正行级错误 → 确认导入。单文件最多1000行/5MB，导出最多20000行；确认再次校验并整批保存，导入不覆盖原记录，签约、审批及流水纠错仍走原操作。

详细业务范围见 [CORE_ERP_SCOPE.md](CORE_ERP_SCOPE.md)，固定管控规则见 [OPERATIONAL_HARDENING.md](OPERATIONAL_HARDENING.md)。


## 六阶段项目里程碑

入口：项目列表 → 点击项目名称 → 任务与工时 → 项目任务 → 一键生成里程碑。项目经理或管理员可使用，默认20个节点，确认前可移除不适用行、添加自定义任务、选择负责人和计划完成日期。已有项目不自动新增，重复生成只补缺少节点，保留原有任务与安排。

| 阶段 | 默认节点 |
| --- | --- |
| 设计阶段 | 3D画图、3D评审、长交期物料、标准BOM、电气BOM、其它图档 |
| 采购阶段 | 长交期、电气料、其它物料 |
| 装配阶段 | 安装、接线 |
| 调试阶段 | 对信号、手动调试、自动调试 |
| 发货阶段 | 客户预验收、整改、发货 |
| 客户终验收阶段 | 现场安装接线、现场调试、现场验收 |

任务从上往下按设计、采购、装配、调试、发货、客户终验收排列，各阶段内按模板节点顺序展示；翻页、导出保持相同顺序。自定义任务排在所属阶段固定节点之后。

执行人可搜索姓名并多选，选中的姓名显示在输入框中，可逐个移除。多人共同执行时，由负责专业主管或有权限的项目经理统一确认整项完成；主管按实际人员和日期登记工时，员工查看。每位执行人都能在“我的任务”和工作台看到该任务。

六阶段可交叉推进，例如设计期间先跟进长交期物料。点击阶段卡片可筛选任务，再次点击或“查看全部阶段”恢复列表；客户终验收阶段同时显示各批安装和验收任务，方便直接办理。任务“操作 → 重新分配”可同时调整执行人和计划完成日期，只想改日期时用“改计划日期”（须写原因，会通知执行人）；无需的计划可取消，保留记录。新增单项任务时先选阶段、再选节点；节点留空可填写自定义任务名称。已取消的节点不会被模板重复创建，需要继续时重开原任务。

“发货”由全部设备实际登记发货后完成；“现场安装接线”由全部设备发货且各批安装任务完成后汇总完成；“现场验收”由全部批次实际登记验收后完成。这三个汇总节点不能直接点完成或重复登记工时，请在“交付与售后”办理验收、从“项目操作 → 发货”登记发货，在批次安装任务登记安装进度和工时。原发货所需任务、BOM、领料及数量检查，验收前安装完成检查仍有效。

生产经理仍仅能创建参与项目的装配、调试任务，不因新增阶段获得采购、发货、验收或设计派工权限。项目相关人员可查看节点进度，执行人可在工作台找到自己的待办。任务导入的执行人支持多个姓名或账号，用分号分隔（例如“张工；李工”）；重名仍填写姓名（账号）。任务导入模板新增选填“里程碑节点”，继续兼容旧六列文件；日期填具体计划完成日期，不填工期天数。

自动同步节点的操作栏显示同步依据和“查看交付进度”入口：发货按实际发货记录、现场安装接线按各批安装任务、现场验收按实际验收记录完成。这些节点不提供手动“完成任务”，实际批次安装仍在具体安装任务确认。

### 任务计划与实际完成日期

任务列表、详情和导出分别展示“计划完成日期”和“实际完成日期”。点“完成任务”时确认实际完成当天，可补录过去日期，不能填写未来日期；完成任务不要求填写工时。系统同时保留提交时间，便于追溯。

历史已完成任务没有实际日期的，由负责专业主管或有权限的项目经理在“操作 → 补录完成日期”填写；已有日期通过“更正完成日期”说明原因后修改，保留修改记录。重开任务会清空当前完成日期，重新完成时再填写。

发货、现场安装接线和现场验收汇总节点从实际业务记录同步日期。批次安装日期不得早于发货或晚于验收，验收日期不得早于安装完成。历史安装日期不全时，先补齐具体安装任务；不要直接更改汇总节点。

任务经过的天数不等于人员实际投入的工时；当前完成日期登记不自动生成工时或人工成本，已有工时记录仍保留。

### 开始任务与自动计算天数

执行人或有权限的经理在任务行点“开始任务”，确认实际开始日期，再在做完后点“完成任务”确认实际完成日期。开始日期可补录，日期不能晚于今天，完成不能早于开始。忘记点击开始时，也可以在完成窗口补录实际开始日期；留空会提示缺少日期，系统不会用任务创建日期代替。

任务列表和详情自动显示“任务历时”及“提前／延期”：按自然日包含开始和完成当天，当天完成记1天；例如11月1日开始、11月9日完成为9天。未完成算到今天，完成后固定到实际完成日。与计划完成日期比较，显示提前几天、按期完成或延期几天；未完成只显示已逾期或未逾期。没有计划日期则不计算偏差，没有实际开始日期则不计算历时。

日期有误，由负责专业主管或有权限的项目经理在“操作 → 更正开始日期／更正完成日期”说明原因；历史已完成任务使用“补录开始日期／补录完成日期”。更正后天数自动重算，原日期和修改记录保留。重开保留最初开始日期，返工时间包含在历时中；取消的任务不继续计算。

这些天数用于跟进进度，不自动换算为人员工时或人工成本。一个任务多人共同执行只统计一份任务历时，原有工时及成本记录保持独立。

### 查看已经登记的工时

登记成功后，页面会显示人员、工作日期和本次保存的小时数，点击“查看工时明细”可立即核对。任务列表新增“已登记工时”，点击小时数或“操作 → 查看工时”可查看任务累计、本人工时及每笔记录的人员、工作日期、小时数、说明和提交时间；没有记录时显示“未登记”。

这里的“我的累计”按实际工作所属人员统计，经理代填的工时归被代填人。合计包含所有分页，并扣除冲销；更正后原记录标为“已冲销”，负数冲销和更正后的记录都保留。移至“已删除记录”的历史流水仍计入核对合计。工时填错请在项目“任务与工时 → 工时记录”找到记录后更正。“已完成”是任务状态，不能代替工时提交回执；任务历时天数与人工工时分开。

### 专业主管统一跟进任务

进入“项目 → 具体项目 → 任务与工时 → 项目任务”，项目经理点击“设置专业主管”，从项目成员中选择机械、电气、采购、生产、交付与验收主管。没有选人的专业由项目经理代管；先在项目成员加入人员，再设置主管。

创建或重新分配任务时可选“负责专业”，不选按阶段/节点自动确定。任务列表显示对应主管；分配或调整后，主管工作台的“任务提醒”出现未读消息，“我负责确认的任务”集中列出待办，点“查看并处理”直接定位任务。阅读提醒不等于完成任务。

主管记录实际开始、完成日期，并按每名员工、每个工作日的实际小时数登记；员工可以查看进度及工时明细。系统自动显示任务历时和提前/延期天数，但不会将历时换算为人工费用。已登记工时可以更正，系统保留原记录、冲销和更正记录。原来的派工、取消、重开、发货和验收权限不因指定主管而增加。
