# 自动化设备 ERP 岗位职责

系统固定十一个角色，一个账号可以兼任多个角色。权限按具体业务合并，项目范围、本人任务、审批身份分离和敏感金额控制继续生效；没有角色表、权限树或可配置审批流程。

| 岗位 | 角色代码 | 主要职责与操作 | 数据范围及限制 |
| --- | --- | --- | --- |
| 管理员 | admin | 用户与公司设置、编号、审计、全业务管理及系统升级 | 全局；本人审批例外仍须原因和审计 |
| 项目经理 | manager | 销售交接、项目计划与成员、任务分配、预算、BOM、采购审核、交付售后及结项 | 项目操作受参与/负责范围约束；经营报表须另授权，不能因经理身份直接记账或收货 |
| 销售经理 | sales_manager | 客户、销售需求、报价、合同签约与附件、交付回款查询 | 本人销售；签约选择具备管理员或项目经理角色的执行负责人 |
| 采购员 | purchaser | 物料与供应商、按 BOM 多选下单、提交采购、合同归档、交期跟踪、取消余量及采购质保 | 跨项目采购；可见采购单价，不能审批或执行库存/资金写入 |
| 仓管 | warehouse | 采购收货、隔离品处理、领退料、采购退货、盘点 | 库存数量与采购到货；采购价格、合同与项目成本不可见 |
| 财务 | finance | 对账、收付款、退款、费用、凭证、银行核对及成本读取 | 跨项目财务；不因财务身份修改销售、采购或项目计划；总经理报表需其他授权 |
| 普通成员 | member | 本人任务完成、工时登记与更正、项目技术及交付附件 | 仅参与项目；不能维护 BOM、采购、预算或收付款 |
| 采购经理 | purchase_manager | 采购员全部采购职责，加普通/超预算采购批准与退回、审批待办 | 跨项目采购；本人创建或提交的单据不能自批。不自动获得项目管理、销售、完整项目成本、银行或预付款核准权限 |
| 机械工程师 | mechanical_engineer | 机械设计任务、机械物料及图号资料、参与项目 BOM 修订/导入、图纸及装配技术文件、本人工时 | 仅参与项目的工程写入；共享物料可维护，不自动获得供应商维护、采购单、合同、预算、派工或成本权限 |
| 电气工程师 | electrical_engineer | 电气设计/调试任务、电气物料及图号资料、参与项目 BOM 修订/导入、原理图/程序及参数文件、本人工时 | 与机械工程师使用相同工程权限边界，通过岗位与任务分工；不自动获得管理或资金权限 |
| 生产经理 | production_manager | 参与项目装配、调试任务创建与派工，装配/调试/安装/售后任务跟进和完成，团队生产工时登记与更正，保内免费售后及技术资料 | 仅参与项目；不自动获得设计派工、BOM编辑、项目预算、发货验收、采购审批、收付款或成本查看权限 |

## 生产、测试与设备售后

生产经理沿用项目任务：设计完成后进行装配，全部装配完成后进行调试；测试记录和故障处理说明填写任务描述、完成原因及项目技术附件，不另建生产台账。工作台“生产与售后派工”显示参与项目的装配、调试、安装和售后未完成任务；“我的待办”仍只显示本人任务，两组可能包含同一任务，不能相加作为总任务数。

生产经理可分配生产任务、代录及更正团队生产工时；更正保留原记录、负数冲销与原费率快照，不能查看人员费率或项目成本。设计任务仍由项目经理派工，发货和客户验收仍由项目经理登记，安装与验收任务随交付创建。生产经理不能取消交付关联安装任务，也不能重开已验收的安装或已交付生产阶段任务。

已验收批次在保修期内（含截止当天）由生产经理登记免费售后并派工；过保及收费售后先由项目经理确认费用、创建唯一应收，再交生产经理安排和完成维修。涉及应收的售后取消/重开仍由项目经理处理；生产经理只能取消/重开没有账款的售后。免费售后、安装调试及维修报告可在项目附件中追加，沿用鉴权下载。兼任采购只扩充采购职责，不扩大跨项目生产派工、团队工时或售后写入范围。

## 工程资料与协作

机械、电气工程师共用项目 BOM，不另建机械/电气物料副本；物料专业归属及具体工作通过物料信息、功能单元和任务名称说明。两类工程师可以协同维护同项目 BOM，当前没有按专业锁定 BOM 行或图纸的机制。版本冲突、已采购/已领用数量底线、预览回滚和导入整批确认继续执行。

文件上传沿用项目“附件”：图纸用于工程图档，其他可存放程序/参数和说明，交付用于调试及验收资料。单文件20MB，上传追加原文件与审计，下载需要鉴权；没有新增图纸发布审批、专业文件夹、文件版本树或大文件分片。工程师不能访问项目合同、财务凭证或销售/采购单据附件；需要给工程岗位使用的技术文件应上传项目技术附件。关闭项目需先由有权人员重开才能继续上传技术资料。

## 采购审核与金额

采购经理通过原采购审批操作产生唯一应付，不增加第二套采购账或多级审批。本人创建或提交的采购，即使兼任项目经理仍不能自行批准；预算调整人与超预算批准人分离，管理员例外须填写原因。

采购经理可读取采购单价、合同及材料预算摘要。仅有采购经理权限时，预算检查返回本单金额、批准后材料占用、材料预算、累计采购净额、超额提示及审批快照；不返回人工、费用、全部实际成本或总预算明细。其他预算超额只提示需要与项目负责人复核，服务器仍按全部真实预算校验。完整成本查看、修改项目预算、合同预付款核准、收付款和实际收货保持各自权限。

## 兼岗与总经理

例如采购经理兼机械工程师可以跨项目读取采购，但只能在自己参与的项目修改 BOM；采购经理兼销售经理仍只管理本人销售。项目经理兼采购员可以完成本项目采购申请，批准须交另一有权限的人。

总经理不另设角色：沿用 manager，由管理员明确开启 management_reports。新增采购经理、工程师和生产经理不会自动获得该权限。现有账号通过前向迁移保留原岗位与数据，不自动分配新增岗位。
