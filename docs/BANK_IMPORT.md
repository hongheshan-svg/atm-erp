# 银行流水导入

在「收付款 → 银行到账与认领 → 导入」选择工行 XLSX 或华夏 XLS 原始文件。保留银行表头、标题及汇总，不调整列顺序。单个文件不超过 5 MB、1000 行。

先预览日期、金额、账户、户名、行号和导入状态，再确认。华夏收入/支出总额、笔数必须与银行表头汇总一致；工行原文件没有独立汇总时明确显示仅逐笔汇总，不据此宣称余额已勾稽。任何行解析失败或汇总不符，整批不能导入；确认时再次检查，失败整批回滚。

银行账户、交易时间、方向金额、余额、对方账号及原始编号构成交易指纹。同一文件重复上传、改名、不同用户上传重叠交易都会跳过已有记录，不新增资金记录。工行重复凭证号不能作为唯一流水号：系统生成带 IMPORT 前缀的导入标识，同时保留原编号。华夏保留交易日期与核心流水号组合。原始列、来源行、文件哈希、余额和银行户名保存在明细中。

缺少对方户名的交易保留为「待核实户名」。财务根据银行回单通过「核实对方户名」补充真实户名和核实依据，审计保留核实记录，原始文件内容不被覆盖。待核实交易不能认领、匹配或关联退回。

个人收付款、手续费和同公司账户互转完整保留；不推断个人交易的用途，不自动关联项目或核销。已登记收付款的使用匹配；未登记客户收入可认领。采购付款仍须先核准对账并登记付款。

历史本次测试脚本生成的工行文件哈希/行号标识、华夏日期/核心流水号可在重新预览确认时补齐来源证据，无需删除或重建原记录。
