# 非标自动化设备表单填写口径

适用约 50 人公司的现有 Lean ERP 模块。表单复用原业务字段，提示中的示例不会自动写入记录；填写未确认的技术参数时注明“待确认”，不要把示例作为客户承诺。

| 业务 | 填写重点 |
| --- | --- |
| 销售、项目 | 项目名称区分客户、产品和设备；需求说明记录产品样件、工艺、节拍、精度、工位、现场接口、验收标准和资料要求。技术协议、布局图走附件。设备数量是合同整机或整线数量，不是工位数。 |
| 签约、补充协议 | 按签署合同拆分预付款、发货款、验收款和质保尾款，明确期限和金额；原合同调整继续走补充协议。项目负责人只选管理员或项目经理，兼岗按角色集合判断。 |
| 物料 | 标准件写完整订货型号与确认品牌；非标件写图号、版本、材质和关键加工要求。支持手工物料编码，含前导零；同一规格优先复用已有物料。 |
| BOM | 单元统一命名，例如上料、检测、下料。数量填写整个项目该单元总需求，已包含全部设备，系统不会再乘台数。变更说明写依据、版本、受影响工位和旧料处理。 |
| 采购 | 核对编码、规格、品牌、基础单位；明细可单独填写供应商承诺交期。说明会写入采购合同补充约定，可记录图纸版本、检验、随货资料及包装要求。收货地址在签署版本归档时确认。 |
| 收货、质量、库存 | 合格数量和隔离数量分开填，合计为本次到货。实盘数量填写实点总数，不填差额。库位保持一致命名。退换货继续引用原批次。 |
| 任务、工时、交付、售后 | 任务写明单元、工作内容、完成标准和版本；机械、电气、软件、装配和调试共用现有阶段。工时填写本人实际投入；完成、验收及故障处理写结果和依据，记录通过附件保存。发货数量为本批整机数。 |
| 预算、费用 | 材料、人工、费用分别填；完工估算注明剩余采购、调试工时、差旅运输依据。费用不能重复计入采购材料或工时已产生的成本。 |
| 收付款、对账 | 采用 CNY 含税经营口径。收付金额按实际结算额填写；银行记录收入正、支出负，对方退款余额可为负。账户标识和银行流水号与回单保持一致，付款依据写明合同及节点。 |
| 设置、首次安装 | 公司资料与合同主体一致；一人一个账号，多岗在同一账号勾选；小时成本按公司统一核算口径维护。编号规则只影响新单据。 |

## 统一输入行为

- 数量最多 3 位小数，金额和工时最多 2 位小数；设备台数、质保月数、账期天数和流水位数使用整数。金额始终保留十进制字符串，不自动舍入或接受千分位、单位和科学计数法。
- 计划交期、任务期限、采购交期及合同收款期限由用户确认填写；实际业务日期和实际合格收货日期默认当天，可按实际情况补录。历史记录编辑保留原日期。
- 需求、故障、变更及处理说明采用整行多行输入；明细显示行号，添加行后转到所在页。提交和 BOM 预览检查全部明细，错误提示带明细行号。
- 服务端继续最终校验业务状态、额度、权限、锁账及幂等性。前端提示不产生新的台账，不改变合同、库存、应收应付或成本的事实来源。
- 登录、查询筛选和经营报表保持各自用途；不向只读查看表单加入编辑校验，不增加角色或可配置审批流。
