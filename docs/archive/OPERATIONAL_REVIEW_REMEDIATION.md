# 第二轮 ERP 评审整改

本轮按用户“全部按建议修复”落实，保留固定六角色和既有业务事实，不引入额外业务模块。

| 评审事项 | 实施结果 |
|---|---|
| 完工材料覆盖 | 增加剩余材料估算，未估全不显示完整总额；提示排除实际和在途，纳入未来共享库存领用及未下单需求 |
| 采购付款期限 | 独立付款到期日、生成应付及10列表格模板；8/9列历史模板兼容 |
| 不同配置交付 | 本批配套清单、累计领料检查和交付快照，退料保护已交付所需数量 |
| 工程变更 | 修改/导入保存前可预览差异与阻塞数量，调用原服务校验后回滚，无持久业务写入 |
| 质量处理 | 操作记录展示数量与后续处理，退回明确保留补货义务 |
| 后补付款凭证 | 不可变追加关联、角色/项目/分类校验、幂等与鉴权下载，保留原金额 |
| 中文业务详情 | 协议前后中文字段、附件名和下载；只读长明细使用表格 |
| 表格阅读 | 金额格式与对齐、退款说明、项目内部省略重复项目列、主表常用操作 |
| 待办办理 | 详情直接办理、同条件分页，逾期显示明细日期；保存保留分页位置 |
| 成本与报表追溯 | 分类别读取原成本贡献，风险数字筛选及业务页面入口；累计口径明确 |
| 估算更新提醒 | 显示人员时间，成本来源及项目变化或超过30天提示复核 |
| 移动端 | 抽屉导航、当前标签自动可见、首列金额/数量摘要 |
| 权限 | 继续固定角色后端授权，金额与附件权限不依赖界面隐藏 |
| 运维 | 健康/备份完整性及时间/磁盘检查脚本，异常JSON和非零退出码；恢复与发布回退规程 |
| 企业试运行 | 已给出脱敏订单选择、六角色清单和签认要求；企业实际订单尚未提供，不标为已完成试运行 |

本轮测试与截图证据追加在SIMPLIFICATION_EVIDENCE.md。企业主机告警渠道与负责人需要在实际部署侧接入检查退出码，未擅自发送外部通知或新增常驻服务。未提交、推送或发布版本。

验收完成：后端162项、前端26项、浏览器20项覆盖（18项完整运行＋2项专项复测）、运维脚本分支检查通过。独立恢复30张表及57个附件一致，非空库保护及重复安装通过；103个运行文件与最终源码一致。
