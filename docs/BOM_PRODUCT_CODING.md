**执行依据：用户确认以 Word 规范为准。** Excel 是历史业务资料，不作为新编号格式依据。新项目采用 `ATMYYNN`，不采用样表的 `AYYNN`。已有 `A2605` 原样保留，不能自动认定与 `ATM2605` 是同一项目或自动替换；历史关联须核对原合同后确定。设备名称沿用用户已确认的销售合同原文。

## 文件核对

样表一个工作表、32列、946条具名明细，项目号均为 A2605，产品编号全部为空，无公式。零件类型为标准件435条、机加件413条、钣金90条、特殊工艺6条、其它2条。此次只调整系统，不向业务库导入原表，不凭空补品牌、编码或既往财务流水。

规范项目号是 ATM＋两位年＋01–99，样表使用 A2605；保留现有项目号，新安装默认使用规范。已有安装的编号规则不被升级覆盖，管理员可在设置中选择前缀 ATM、日期 YY、流水2位、每年重置。规范示例 ATM25O1 中字母 O 按正文数字序列01解释；产品表中孤立的 10125000001 与明确的十位结构不一致，自动生成采用正文及其余十位示例。

## 设备名称与项目编号的执行口径

- 设备名称按销售合同中设备/产线名称原文填写（用户于2026-09-11明确）。不按客户、型号或编号自动拼接名称；同一合同包含多种设备时，在需求说明列清各设备名称和数量，项目名称沿用合同约定的整线/项目名称。
- 销售未签约可使用暂定名称，签约前按合同核定；签约创建项目复用销售名称。独立项目尚无合同，需求说明注明名称待确认。旧项目名称不自动批量改写。
- 项目编号为7位 `ATMYYNN`，例如2026年第1项 `ATM2601`；NN为01–99，每年重置。设置中的“应用项目规范”通过原编号配置接口保存，版本冲突校验与审计不变，保留当前计数和历史编号。当期已用序号达到99时停止取号，不能清零绕过。
- 物料编码是10位内部物料标识，不等于项目编号、设备名称、研发型号或工程图号。八类规则如下，保留原自定义编码能力。未分类物料继续兼容旧普通编号规则；按规范建新料应选择类别并填写型号/规格。
- 原文件没有规定设备型号的字符串格式，仍由研发给出，不从项目号或物料流水猜测型号。型号/版本变更按新料和BOM修订维护；“应用项目规范”不修改型号、图号或物料编号。

设置 → 编号规则集中展示上述口径；销售、项目新增/编辑表单同步合同命名提示。该规范页面是说明，不代表管理员已有编号配置已被自动覆盖。

物料分别维护型号/规格、图号、图档版本、品牌、产品编码类别和标准/非标属性。选择产品编码类别必须填写型号/规格，有图必须填图号。同图号及版本不能重复分配给另一物料，大小写不影响重复识别，历史停用记录也占用。已按类别建码后，类别、型号/规格、图号和版本只读；升级新版本新建物料并通过带变更说明的 BOM 修订替换。图号按研发给出的实际值录入，保留样表旧图号，字段提示提供工程图 A26-E-05-P-000001、模具子图 ATM-T1-P-000001 示例，不根据物料流水猜测工程图号。

## 原表字段归属

| 原表字段 | 系统归属与处理 |
| --- | --- |
| 项目号 | 项目，BOM 页面按当前项目管理 |
| 产品编号、零件名称、图号/型号、版本/品牌、单位、零件类型 | 物料主数据；拆分图号/型号和版本/品牌；零件类型对应产品编码类别，保留独立标准/非标采购筛选 |
| 需求数量、需求日期、申请日期、申请人 | 项目 BOM；申请人是纸质申请信息，不代替登录用户、授权或审计身份 |
| 备注1、备注2 | 确认用途后分别录入单元或变更说明；原表合并备注含工艺描述，不能一律猜作单元 |
| 实际交期、收货数量、送货单号 | 采购收货与其单据，不直接写入 BOM |
| 采购员、供应商、PO号、含税单价、采购交期 | 采购单与明细；采购选料展示产品类别、图号、版本和需求日期；合同保存图号与版本快照 |
| 需求总价、含税总价 | 以实际采购明细金额为准，不另建可编辑的 BOM 金额账 |
| 出库数量、出库日期、领料员、库存数量 | 库存流水与库存投影，保留原事务与权限校验 |
| 是否盖章、是否收票、开票金额、说明、税率% | 相关采购附件、合同归档及财务原始凭证；此次不新增发票/税务模块，不把原表税率系数1.13直接当作税率1.13%入账 |

## 模板与兼容

物料新模板依次为物料编码、物料名称、规格、图号、图档版本、产品编码类别、品牌、物料类别、单位、独立建码原因。支持类别两位代码、完整中文名和机加件/钣金/特殊工艺等明确别名；“其它”需明确有图/无图。旧四列、六列、七列及上一版中文模板仍按原字段映射，不能按新列位误读。

BOM新模板依次为物料编码、单元、需求数量、变更说明、需求日期、申请日期、申请人、物料名称、规格、图号、图档版本、产品编码类别、品牌、物料类别、单位。已有编码直接关联物料，补填的物料资料必须与主数据一致。编码留空时必填名称、规格、产品编码类别和单位，有图类别还需图号；全部身份字段相同则复用，否则确认时自动创建物料并生成编码，存在多个相同候选时需填写明确编码。预览不保存物料、不占用业务编号；确认整批事务保存物料与BOM，任一行失败全部撤销，重复确认不重复建料。

日期填写 YYYY-MM-DD 或 XLSX 日期单元格；旧三/四/七列模板仍可使用，旧三/四列模板不清空已有申请信息。新模板空日期可清除该字段。确认沿用项目范围、BOM版本、已领/在途数量底线及原权限。

原始32列混合台账需映射到上述BOM模板后上传；编码可以留空，不必先单独导入物料。采购、收退料和历史款项按各自模块及原单据另行核对。本次未导入946行实际业务数据。
