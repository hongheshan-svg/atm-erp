# 采购合同查看与打印

在采购订单选择“预览采购合同”，直接查看一份完整合同：双方信息、全部采购明细、合同条款、补充约定和签章区连续显示。长规格、地址及备注完整保留；手机可在明细表中左右滑动。点击“打印 / 另存为 PDF”即可输出整份合同，内容较长时自动分为多页 A4，无需切换附件或另选整套打印。

新模板加入以下非标自动化采购事项：

- 图号、版次、技术协议及清单的适用范围，冲突和缺漏先确认。
- 加工材质、公差、配合、热处理、表面处理与关键尺寸检验。
- 标准件品牌型号、原厂及供货追溯、替代料书面确认。
- 首件/样件和不合格处理；涉及整机或模块时明确接口、工况、节拍、精度和验收方法。
- 图纸和需求变更影响的价格、在制品、工装、材料及交期确认。
- 程序和参数备份、许可、技术资料、安装调试、培训及售后安排。
- 保密、知识产权、质保和违约处理。

默认质保期为各批货物验收合格之日起12个月，合同标题、正文和PDF均按月数显示；采购单另有约定时按该单保存的月数生成，历史签署条款保留原文。

这些约定按实际供货内容适用。具体节拍、精度、测试工件、验收期限、程序交付范围、服务时限和额外责任，由双方在技术协议或补充约定中确认；模板没有替双方填写统一数值。正式签署前应由负责人员及法务结合项目复核。

“合同版本”保留最新归档、当前采购资料及各历史版本。历史归档连续展示当时保存的明细和条款，内容不会因模板升级改变；新条款用于当前采购资料及以后确认的新归档。双方签署文件可直接预览，归档时核对整份合同及收货地址，历史文件仍保留。

行业约定为项目通用模板，参考[《中华人民共和国民法典》第三编合同](https://www.cac.gov.cn/2020-06/01/c_15925617772683192.htm)中买卖合同（质量、检验及通知）和承揽合同（材料、图纸、变更、技术资料及验收）的规则拟定，不是官方示范合同。核对日期：2026-10-27。
