## 实施清单

- [x] 共用框架：216px 深色侧栏、60px 顶栏、底部品牌区、移动端抽屉。
- [x] 共用列表：分层工具栏、服务端筛选、状态标签、清晰主操作、分页、侧边详情/表单。
- [x] 工作台：指标、优先处理与分类双栏、聚焦待办列表。
- [x] 经营报表：紧凑指标、风险条、经营明细、关注明细。
- [x] 销售：状态筛选、单据详情、附件与签约交接。
- [x] 项目列表：紧凑元数据、状态、交期、明确入口。
- [x] 项目详情：概要、任务/工时、BOM、采购、交付/售后、财务、成本、附件。
- [x] BOM：品牌/单元/类别/缺料筛选、多选采购、导入预览与变更。
- [x] 采购：状态筛选、收货详情、审批、合同与附件。
- [x] 合同预览：独立工具栏、A4 正文和附件、打印版不含系统信息。
- [x] 库存：共享库存与流水、物料详情。
- [x] 收付款：款项、对账、月结、流水、银行认领及操作详情。
- [x] 基础资料：物料与往来单位、侧边表单、自定义编码。
- [x] 设置：用户兼岗、公司、编号、审计、账户。
- [x] 登录：行业线稿、左右布局、完整错误与提交状态。
- [x] 安装向导：品牌顶栏、五步骤、当前表单与帮助、确认启用。
