# v1.8.21

## 本次更新

本版修复业务流程审计确认的5项问题，重点保证一笔真实银行交易只使用一次，并让重新产生的待结算事项及时显示。

- **防止跨项目重复收款**：同一账户的手工登记、银行认领、匹配和退回共用事务锁，等待其他操作完成后重新核验可用金额；正常的跨项目拆分收款继续允许。
- **未认领退款核对已登记金额**：原收入和退款支出中，已经手工登记但尚未匹配的金额不能再用于退回；仅真正未使用的余款可退回。误登记请先冲销，已到账部分可匹配已有收付款。
- **华夏流水识别统一**：依据银行原始证据识别核心流水号与导入后的日期前缀，避免同笔收入再次认领；不同账户、日期、方向继续区分，不把工行凭证号误认成唯一交易号。
- **冲销后恢复待结算事项**：已整理款项因冲销、合同或售后更正重新产生待收付或退款时，自动恢复款项及相关收付流水的显示，保留原删除记录并追加恢复记录。
- **流程进度保护金额**：普通员工仍可查看预付款的跟进提示、节点与相关人员，提示不再包含具体金额；财务原单权限不变。
- 补充真实并发、银行身份、退款、恢复记录和多岗位回归测试；修正旧页面用例对工作台前5条概览的依赖，从完整采购列表定位真实订单。

## 兼容与验证

- 无数据库迁移、运行时依赖或安装配置变化。不自动改写历史银行流水号、收付款金额或现场账款；不自动合并疑似交易。
- 沿用当前岗位与审批规则、锁账限制、不可覆盖流水和操作审计，不新增资金台账或配置化流程。
- 本地隔离验证：654项后端用例、220项关联前端单测、42项CI路由检查和150项桌面/手机浏览器用例通过；首次安装向导2项按本地范围跳过。静态检查及构建通过。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.21-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.21/atm-erp-v1.8.21-linux-docker.zip -o atm-erp-v1.8.21-linux-docker.zip && unzip atm-erp-v1.8.21-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：
