# v1.8.25

## 本次更新

- **BOM 与采购联动**：BOM 行尾可直接“修改此行／替换物料／移除”，移除确认写明单元、编码和数量；已停用物料标出“已停用”，只能替换或移除。采购缺料视图勾选后“从 BOM 多选下单”，同物料一处填价，草稿按物料分组；手工采购超出项目 BOM 缺口时须填写超 BOM 原因。审批对话框列出供应商、项目、交期与账期、含税合计及逐行 BOM 核对；采购列表增加含税合计和供应商筛选。
- **待审批采购可直接作废**：采购维护人员填写原因即可整单作废待审批采购，审批人无需再处理；有待处理修改申请时须先由审批人处理。
- **项目推进**：里程碑可按阶段批量填写计划日期和统一执行人；项目列表显示任务进度和逾期，项目页显示推进检查、成员名单和交期逾期天数，区分“无销售合同”与“未签约”；任务新增“改计划日期”；成本页显示合同金额、毛利与毛利率。安装人、验收负责人、售后执行人和工时人员可搜索，本项目成员排在前面。
- **库存与收付款**：库存页新增“按 BOM 领料”，一次领整项目多行；收货、领料明细改为表格（手机为逐行卡片），部分到货行高亮。库存流水和收付款流水显示来源项目、采购单与对账单，可直接跳转。财务可调整应收应付到期日，应收应付按未结和到期日排序；确认对账时说明谁可以确认预付款。
- **日常动作少填一步**：开始任务、完成任务、登记工时、收货、隔离品合格入库、领料、收付款登记、批准采购等日常确认的原因／说明改为选填，系统记录默认说明；退回、作废、冲销、盘点、退料等纠错动作仍须填写原因。
- **工作台**：新增待启动项目、已批准待下单、缺料待采购、我的合同逾期应收、已报价待签约等待办。
- **手机端**：工作台、销售、项目、BOM、采购、库存、收付款、基础资料和经营报表按手机宽度重排：列表只留名称、状态和操作，其余信息并入摘要行；筛选收进“筛选 · N”；对话框明细改为卡片；按钮和链接触控区不小于 40px；状态页签放不下时换行。
- **显示统一**：数量去掉多余的 0（2.000 显示为 2），金额统一千分位，时间统一为“年-月-日 时:分”；“组装阶段”统一为“装配阶段”。经营报表“刷新明细”不再提示页码无效。

## 升级说明

- 本版没有数据库迁移，沿用现有配置、数据库、附件与运行卷；升级前仍请完整备份。
- 手工新建或修改采购时，数量超出项目 BOM 缺口须填写超 BOM 原因；采购导入暂不支持原因列，超出缺口的行会被拒绝，请改为手工建单。
- 日常确认动作的原因改为选填后，旧客户端照常提交原因不受影响；审计记录保留实际填写的原因，未填写时记录默认说明。
- 待审批采购作废沿用原“作废采购”接口和审计，不生成财务冲减（待审批单尚无应付）；删除待审批采购仍不允许。
- 本版界面变化以展示为主，权限范围不扩大：调整到期日沿用财务登记收付款的权限，改计划日期与重新分配权限相同。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.25-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.25/atm-erp-v1.8.25-linux-docker.zip -o atm-erp-v1.8.25-linux-docker.zip && unzip atm-erp-v1.8.25-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：
