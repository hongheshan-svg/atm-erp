## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.6.0-<platform>-docker.zip`，解压并进入目录。需先安装 Docker Engine / Docker Desktop（Linux 容器）和 Compose v2。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.6.0/atm-erp-v1.6.0-linux-docker.zip -o atm-erp-v1.6.0-linux-docker.zip && unzip atm-erp-v1.6.0-linux-docker.zip && (cd atm-erp-v1.6.0-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.6.0-SHA256SUMS.txt`。
