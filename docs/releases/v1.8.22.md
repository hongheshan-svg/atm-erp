# v1.8.22

## 本次更新

- **自编编号与自动编号并行**：物料、往来单位、销售、项目、采购、交付、对账均支持手工编号，留空才自动生成；页面新增和Excel/CSV导入使用相同规则，保留前导零。BOM可以直接导入尚未使用的自编物料编码。
- **物料资料核对**：名称和完整型号保留原文，系统不猜测型号或补后缀；空格、全角差异及同品牌同型号的异名提示核对。已有编号的资料不一致时拒绝覆盖，疑似重复须明确独立建码原因，不自动合并。
- **六阶段项目里程碑**：设计、采购、组装、调试、发货、客户终验收共20个默认节点，可一键生成，按项目增删、指定负责人和日期；支持交叉推进。发货、安装和验收节点与实际业务同步，继续保留发货和验收校验。
- **跨页批量删除**：管理员可全选当前筛选结果，所有已有删除入口每批最多1000项。翻页保留选择，切换筛选清空旧选择；业务关联保护、审计、整批回滚及历史流水保留规则不变。
- **填写说明与兼容性**：更新编号、BOM和任务模板说明，新增任务节点选项及本单编号列，兼容旧版模板。

## 升级说明

- 从v1.8.21升级时，新增任务里程碑字段和唯一约束，采用前向迁移；已有任务不会自动生成模板，历史编号、型号及合同归档不会批量改写。
- 沿用现有岗位权限、财务审批与项目范围。对账导入仅创建草稿，不自动确认或付款。
- 升级前完整备份，保留原配置、数据库、附件及运行卷；由现有升级流程完成备份与迁移。

## 验证

本次功能已完成针对性后端、前端及电脑/手机操作验证。发布流程还会强制核对同一代码版本的发版验证结果：全部后端测试、前端单测、运维脚本测试、受影响页面的双视口测试，以及本次迁移所需的升级演练；通过后才构建并发布安装包。不将发版验证表述为全业务链验收。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.22-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.22/atm-erp-v1.8.22-linux-docker.zip -o atm-erp-v1.8.22-linux-docker.zip && unzip atm-erp-v1.8.22-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.22-SHA256SUMS.txt`。
