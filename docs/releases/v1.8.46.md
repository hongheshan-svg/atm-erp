# v1.8.46

采购合同、领料单「另存为 PDF」更好用。有同事反馈点了「打印 / 另存为 PDF」后，保存出来的文件看起来像网页、不像 Excel 导出的 PDF。原因有两个：一是浏览器菜单里的「另存为」存的是网页；二是 Windows 默认用 Edge 打开 PDF 时，PDF 文件也显示 Edge 图标，和网页文件分不出来。另外文件名默认是「采购合同 · 项目 ERP」，每次都要手动改。

没有数据库迁移和配置变化。

## 本次更新

### PDF 默认文件名自动填好
在打印窗口选「另存为 PDF」时，文件名已经按单据填好，不用再手动改名：
- 采购合同：`采购合同-供应商全称-合同编号`。查看已归档版本时加「第N版」，未批准的加「草稿」，已取消的加「已取消」。
- 领料单：`领料单-单号-项目编号`。

浏览器标签页标题同步显示这个名字。文件名里 Windows 不允许的字符（如 `/`、`:`、`*`）会换成空格。

### 打印按钮旁写明怎么存成 PDF
采购合同页的「打印 / 另存为 PDF」按钮下方、领料单页的工具栏下方，各加了一行提示：在打印窗口的「打印机」里选「另存为 PDF」再保存，得到的就是 PDF 文件；浏览器菜单里的「另存为」存下的是网页，不是 PDF。打印出来的纸面和 PDF 里不显示这行提示。

使用说明（`docs/LEAN_USER_GUIDE.md`）同步补充了这一段，并说明 Windows 上 PDF 显示 Edge 图标属正常，右键「属性」看到文件类型为 .pdf 即可。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.46-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.46/atm-erp-v1.8.46-linux-docker.zip -o atm-erp-v1.8.46-linux-docker.zip && unzip atm-erp-v1.8.46-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.46-SHA256SUMS.txt`。
