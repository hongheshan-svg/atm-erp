# v1.8.2



## 本次更新

- BOM 导入支持编码留空，确认时按产品编码规范自动创建物料；相同物料复用，重复确认不重复建码，失败整批回滚。
- 支持八种有图/无图产品类别、图号和图档版本；BOM 补充需求日期、申请日期与申请人，采购筛选及合同带出物料图档信息。
- 更新物料和 BOM 导入模板，兼容旧模板；历史物料编码及已有项目编号规则保持不变，新安装项目默认使用 ATM＋两位年＋两位流水。

## 兼容与验证

包含数据库前向迁移，升级先备份，不回退或清空数据库。有图物料自动编码需填写图号；原始混合台账应按新模板整理。

本地隔离验证：后端256项、前端62项及桌面/移动端6项浏览器测试通过。发布由完整CI及安装包校验把关。



## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.2-<platform>-docker.zip`，解压并进入目录。包内包含 GitHub 预构建的 amd64/arm64 镜像，校验后直接安装，不在本机构建。需先安装 Docker Engine / Docker Desktop（Linux 容器）、Compose v2 和宿主机 Python 3.11。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、Python 3.11、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.2/atm-erp-v1.8.2-linux-docker.zip -o atm-erp-v1.8.2-linux-docker.zip && unzip atm-erp-v1.8.2-linux-docker.zip && (cd atm-erp-v1.8.2-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.2-SHA256SUMS.txt`。
