# v1.8.30

本版修正一个可能让同一笔银行到账被认领两次的问题，不新增业务功能。

## 本次更新

- **手工登记银行流水不再重复登记同一笔华夏交易**：
  - 华夏银行的流水号有两种写法：只写核心流水号（如 `000123`），或写成「交易日期:核心流水号」（如 `2026-01-05:000123`）。导入银行流水和手工登记收付款时，系统都把这两种写法当作同一笔交易。
  - 此前在「银行到账与认领」里手工新建银行流水时，只拦截写法完全相同的流水号。换一种写法就会再登记一条，两条可以分别认领，收付款会多记一次。
  - 现在手工新建时也按同一规则查重：同一账户、同一银行日期，已有任一写法的有效记录（包括导入的记录）就拒绝登记，并提示原记录 ID。
  - 核心流水号在其他日期重复使用、或出现在其他账户时，仍按另一笔处理。银行文件导入的查重规则不变。

## 升级说明

- 本版**没有数据库迁移**。升级沿用现有配置、数据库、附件与运行卷，按常规先完整备份再升级。
- 本版只拦截新的重复登记，不改动已有数据。升级后建议管理员在「历史数据核查」里选「疑似重复的银行记录」，确认此前是否已经有同一笔到账被登记成两条；如有，误录的那条先撤销匹配再作废。
- 接口方面：`POST bank-records/` 遇到上述同一笔交易时返回 409，错误挂在 `reference` 字段上。其余调用方式不变。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.30-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.30/atm-erp-v1.8.30-linux-docker.zip -o atm-erp-v1.8.30-linux-docker.zip && unzip atm-erp-v1.8.30-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.30-SHA256SUMS.txt`。
