# v1.8.29

本版是一次全项目审查后的修正版，不新增业务功能，只纠正不一致、错误提示和低效的地方。

## 本次更新

- **工作台口径与页面一致**：
  - 管理员本人发起的预付款核准申请，不再从“预付款核准”待办里消失。它会留在列表中并标注“本人申请，需填写例外原因”，处理方式与采购审批相同。
  - “缺料项目”现在把尚未关联 BOM 行的草稿、待批采购也算作在途，与“从 BOM 多选下单”的缺料数字一致，不再误报。
  - 已经全部到货、正在待检（隔离）的采购，不再显示为“未交货逾期”。采购的最近待到货日、工作台逾期采购和经营报表的迟到采购视图使用同一口径。
- **导入模板说明更正**：
  - 期初库存、收付款、工时、领料、业务对账五类导入的“原因 / 说明”列实际可以留空，模板不再标红为必填，并写明留空时的默认记法。
  - 收付款导入的“结算方式”留空时，按填写说明记为银行转账。这些收付款之后可以直接与银行流水匹配、认领。
- **安装向导可以一次改完全部 8 种编号规则**：此前同时修改 8 种会提示超出数量。
- **附件与姓名显示**：已结项项目的附件不再显示删除按钮，需先重新打开项目。采购处理记录、收付款凭证、成本来源和对账确认人这几处，没有填写姓名的账号改为显示账号，不再是空白。
- **导出表头**：收付款、对账、工时、领料等导出补齐中文列名，不再夹带英文字段名。
- **编辑时可以清空选填项**：编辑项目、任务、销售、物料、往来单位和公司资料时，把需求说明、计划交期、联系人、电话、地址等选填项清空后保存，现在会真正清空。此前保存后会保留原值。
- **金额与时间显示**：
  - 收货数量比待收多 0.5 这类负差值现在能正确拦截。
  - 采购合计按行舍入，与服务端金额一致。
  - 附件上传时间、对账确认时间、收付凭证时间和采购处理记录统一按北京时间显示，不再随浏览器时区或显示 UTC 时间。
- **附件分类名称一致**：上传附件时的分类名称与列表一致（结算凭证、交付验收）。
- **更快、更稳**：
  - 项目页的款项汇总一次带出已收付和到货信息，不再按款项逐条查询。
  - 收付款页的余额汇总先排除已结清款项。
  - 审计日志一页的业务编号改为批量查询。
  - 结项检查银行余额改为一次查询。
  - BOM 导入在补填品牌前按固定顺序锁定物料，避免与同时进行的收货、领料等操作互相等待。
- **页面细节**：
  - 列表在翻页越界时自动回到上一页。
  - BOM 页重新加载时清除残留错误。
  - 详情弹窗主按钮与行内操作一致。
  - 供应商筛选清空后恢复全部。

## 升级说明

- 本版**没有数据库迁移**。升级沿用现有配置、数据库、附件与运行卷，按常规先完整备份再升级。
- `scripts/backup.py` 不指定 `--env-file` 时默认读取 `.env`；只有 `.env.lean` 的旧部署会自动沿用它。README 中的运维命令已改为 `.env`，并注明旧部署的写法。
- 付款导入留空结算方式的行，从本版起记为银行转账。如需记为现金或其他，请在该列明确填写。
- 接口方面：预付款待办行新增 `self_requested` 字段；采购的 `next_delivery_date` 不再统计已到货待检的数量。其余调用方式不变。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.29-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.29/atm-erp-v1.8.29-linux-docker.zip -o atm-erp-v1.8.29-linux-docker.zip && unzip atm-erp-v1.8.29-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download
