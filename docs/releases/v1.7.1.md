# v1.7.1 · 工作台布局与待办体验优化



## 本次更新

- 工作台新增待办概览、优先处理清单和分类筛选，按岗位及项目权限展示。
- 每类默认显示 5 条，支持独立翻页、空分类折叠、加载骨架屏和更新时间；旧请求不会覆盖刷新后的结果。
- 补充项目名称、供应商、银行户名、收支方向及待匹配金额，统一逾期和审批提示，优化手机布局。
- 修正银行、对账和款项入口，进入时清除之前保留的项目筛选，避免待办记录被隐藏。

## 升级与验证

本版无新增数据库迁移，不改变业务金额和审批权限。升级前请备份数据库及附件。

本地后端 241 项、前端 47 项测试通过，已检查桌面和手机布局、分类翻页、空分类展开及银行跳转。正式发布须通过完整 CI，包括前后端检查、双端浏览器、OTA 和三平台安装验证。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.7.1-<platform>-docker.zip`，解压并进入目录。需先安装 Docker Engine / Docker Desktop（Linux 容器）和 Compose v2。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.7.1/atm-erp-v1.7.1-linux-docker.zip -o atm-erp-v1.7.1-linux-docker.zip && unzip atm-erp-v1.7.1-linux-docker.zip && (cd atm-erp-v1.7.1-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.7.1-SHA256SUMS.txt`。
