# v1.8.51

这一版按非标自动化行业的收款和报价习惯补了两块：收款节点可以按发货、验收、质保期满起算；报价时可以测算成本，签约后直接成为项目首版预算。

有一个数据库迁移（只新增字段，已有数据不变），没有配置变化。

## 本次更新

### 收款节点按交付事件起算
- 签约（以及补充协议增额）时，每个收款节点可以选「起算方式」：固定日期、签约后、首批发货后、全部发货后、全部终验收后、质保期满后，再填「事件后天数」（0–365）。常见的「预付 30% / 发货 30% / 验收 30% / 质保金 10%」可以照合同原样录入。
- 选了起算方式的节点，「收款到期日」填的是预计日期，只用于回款预测；登记发货、验收后，系统自动把到期日改成「事件日期 + 天数」，并写入操作审计。
  - 全部发货：已发货数量达到合同设备数量的那一天。
  - 全部终验收、质保期满：最后一批的验收日、质保到期日。
- 起算前不算逾期：款项列表状态显示「待起算」，到期日显示「预计 2026-12-01（待全部终验收 + 15 天）」；列表汇总、经营报表、工作台和「逾期账龄」都不计入。「未来 30 天回款」仍按预计日期列入，标注「预计待收 · 待〈事件〉」。
- 财务「调整到期日」：起算前调的是预计日期，事件发生后仍自动重算；已起算的节点调整后不再自动重算。
- 已起算的到期日不会因为之后整理交付记录而变动。
- 销售「交付与回款」、发货时的应收提示同样显示起算方式。
- 不选起算方式的节点和以前完全一样，已有合同的收款节点不受影响。

### 报价测算成本并带入项目预算
- 报价时可以选填材料、人工、费用三项测算成本，三项要么都填、要么都不填（没有的填 0）；不填时保留上次测算。
- 销售「查看明细」显示测算合计和测算毛利率（签约前按报价、签约后按现行合同额）及测算人；没有该项目金额权限的人看不到，与报价金额相同。
- 签约时，如果执行项目还没有预算，测算三项直接成为项目首版预算（预算版本 1），审计原因为「签约带入报价测算」；已经有预算的历史项目不覆盖。
- 预算调整人记为测算人：与手工修改预算相同，测算人不能批准本项目的超预算采购（管理员例外，须写原因）。
- 项目「成本」页在预算之外单独列出「报价测算 vs 实际」以及测算毛利率；经营报表的成本说明里显示报价测算合计，导出新增「报价测算成本」列。测算只用来回看报价准不准，不参与预算占用和超预算判断。

### 其他
- 经营报表「实际成本 / 预算」一栏的预算是材料、人工、费用三项合计，原来误标为「材料预算」，现改为「预算」。

## 升级说明
- 数据库迁移 `0033_receivable_trigger_quote_estimate`：应收新增 `trigger`、`trigger_days`、`planned_date`、`triggered_on`，销售单新增 `estimate_materials`、`estimate_labor`、`estimate_expenses`、`estimated_by`。全部可空或有默认值，已有数据原样保留。没有配置变化。
- 接口：`sales/{id}/quote/` 新增选填 `estimate_materials`、`estimate_labor`、`estimate_expenses`；`sales/{id}/sign/` 与补充协议的 `milestones` 行新增选填 `trigger`、`trigger_days`；应收列表新增 `trigger_label`、`trigger_days`、`planned_date`、`triggered_on`、`awaiting_trigger`，起算前 `status` 为 `awaiting`；`projects/{id}/cost-analysis/` 新增 `quote_estimate`；经营报表行新增 `estimated_cost`。旧客户端不传新字段时行为与之前相同。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.51-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.51/atm-erp-v1.8.51-linux-docker.zip -o atm-erp-v1.8.51-linux-docker.zip && unzip atm-erp-v1.8.51-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download
