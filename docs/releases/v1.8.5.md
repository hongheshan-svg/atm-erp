# v1.8.5 · 界面配色统一与列表精简

## 本次更新

- 全站配色收敛到一张 `:root` 变量表，Element Plus 的主题变量重映射到同一批 token，颜色不再散落在各页样式里；侧栏、状态徽标、风险色在所有页面取同一个值。
- 工作台只呈现最紧的 7 项待办，其余按类别折进「其他待办」做深链；当前为零的类目不再各占一行，收成底部一句说明。
- 经营报表的两项逾期金额并入待收款、待付款主卡的说明，不再单列重复；关注行因此由 5 项减到 3 项，明细列头合并为「实际成本 / 预算」。
- 销售、收付款、库存、项目页的列表改为「主值 + 副行」合并列：销售 7 列减到 5 组，收付款 9 列减到 5 组（原金额移入收付流水弹窗），库存 8 列减到 5 组且数量直接带单位。项目页内的列表不再重复项目名。
- 收付款页头新增待收款、待付款、其中已逾期三张余额卡，与列表共用当前筛选和项目边界。为此新增 `GET /api/business/entries/summary/`，财务角色可直接取到汇总——此前余额只能从经营报表取得，而该接口不对财务开放。应收应付的拆分规则抽成 `services/finance.py` 的 `split_balance`，经营报表与收付款页共用，两处口径不会分叉。
- 修复销售经理工作台看不到逾期销售订单：到期判定遗漏了 `sales` 这一类。
- 修复工作台点「我的销售订单」可能落到空列表：跳转未清除销售页记住的上次搜索词。
- 前端错误提示不再回落到 axios 的英文描述，断网、超时、网关 HTML 错误页按类型或状态码给出中文；OTA 执行器的失败原因（含异常类名）、安装器、备份与运维脚本的报错和 `--help` 说明一并中文化。

## 升级说明

沿用 Lean ERP 独立数据库，本版无新增迁移，不改变现有数据。升级服务先备份再升级。本版只改界面呈现与一个新增的只读汇总接口，既有接口的字段和权限边界不变。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.5-<platform>-docker.zip`，解压并进入目录。包内包含 GitHub 预构建的 amd64/arm64 镜像，校验后直接安装，不在本机构建。需先安装 Docker Engine / Docker Desktop（Linux 容器）、Compose v2 和宿主机 Python 3.11。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、Python 3.11、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.5/atm-erp-v1.8.5-linux-docker.zip -o atm-erp-v1.8.5-linux-docker.zip && unzip atm-erp-v1.8.5-linux-docker.zip && (cd atm-erp-v1.8.5-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，全新安装的初始密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。首次登录的安装向导会要求修改该密码，之后请使用向导中设置的新密码；忘记时按安装器结尾打印的命令重设。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.5-SHA256SUMS.txt`。
