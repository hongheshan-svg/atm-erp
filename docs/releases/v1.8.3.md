# v1.8.3 · 十一岗位协作与 BOM 同屏采购

## 本次更新

- 增加采购经理、机械工程师、电气工程师和生产经理，支持十一种固定岗位与一人多岗；工程和生产操作继续受参与项目范围限制。
- BOM 多选采购采用左侧选料、右侧草稿持续显示，支持品牌、单元、标准/非标及编码类别组合筛选、跨页选择和精确金额预览。
- 修复跨角色业务链中的授权、幂等、对账、收付款、物料导入及操作提示问题，保留审计与原业务事实。
- 完善设备命名与项目、物料编码说明，设备名称以销售合同为准，统一岗位职责与使用文档。
- 普通提交使用快速 CI，发布执行完整业务链、桌面/移动浏览器、OTA 和三平台安装验证。

## 升级说明

沿用 Lean ERP 独立数据库，新增迁移扩充岗位，不清空现有用户与业务数据。升级服务先备份再迁移；管理员可在用户管理中配置新增岗位。Docker 安装包携带 GitHub 预构建双架构镜像，原生包携带预编译依赖。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.3-<platform>-docker.zip`，解压并进入目录。包内包含 GitHub 预构建的 amd64/arm64 镜像，校验后直接安装，不在本机构建。需先安装 Docker Engine / Docker Desktop（Linux 容器）、Compose v2 和宿主机 Python 3.11。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、Python 3.11、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.3/atm-erp-v1.8.3-linux-docker.zip -o atm-erp-v1.8.3-linux-docker.zip && unzip atm-erp-v1.8.3-linux-docker.zip && (cd atm-erp-v1.8.3-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.3-SHA256SUMS.txt`。
