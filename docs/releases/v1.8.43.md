# v1.8.43

本版修复一轮界面易用性审计发现的问题。审计按 9 个岗位，在电脑宽度（1366）和手机宽度（390）下逐页检查。重点是三类问题：一是会让人做错、漏看的逻辑；二是笔记本上要横向拖动、文字被切掉；三是新人看不懂的术语和大段说明。没有数据库迁移。

## 本次更新

### 工作台
- 修复「今天到期」的任务可能不出现在「今天要处理的」列表里。以前每类待办只取 5 条，逾期任务一多，今天到期的就被挤出去，顶部卡片却显示「今日截止 1」。现在每类取 7 条，与列表上限一致。
- 同一批任务不再列三遍。原来的「我正在做的工作」改名为「接下来的任务」，只列还没排进「今天要处理的」的任务。按钮按实际状态显示：已开始的写「继续处理」，没开始的写「查看任务」。「其他待办」里不再重复「我的待办」，没有其他待办时整块不显示。
- 「今天要处理的」最多 7 条，全部直接显示，表格里不再有单独的滚动条。
- 整页没有任何待办时（多见于新装系统），「从我的岗位开始」指引放到最前面。管理员的第一项是「准备基础资料」（添加客户、供应商和物料）。
- 仓库的快捷入口改成带图标的按钮，卡片说明文字由 11px 改为 12px。

### 不会再让人白填一张单
- 库存为 0 的行不再显示「领料」，只能盘点。以前点「领料」能打开完整的领料单，填完提交才被拒。
- 报价金额没报过价时留空，不再预填 0.00（以前预填的 0 一提交就报错）。前端在提交前就会提示「不能小于 0.01」。
- 服务端校验出的字段错误不再出现三次。以前顶部红条、汇总框和字段下方各写一遍。现在只在汇总框和对应字段下各出现一次；不属于具体字段的错误仍显示在顶部。
- 数字校验的提示写明规则，例如「请输入大于 0 的数字，最多 2 位小数，不要带单位或千分位」，不再是「请输入范围内的正数」。
- 「新建项目」表单顶部提醒：已签约的销售单会自动生成执行项目，请先到「销售」页确认，避免重复建项目。负责人默认填当前用户，与新建销售一致。

### 列表与表格
- 1366 宽的笔记本上，项目、任务、销售、采购、收付款、物料、库存、用户列表都不用再横向拖动。序号列由 70 收窄到 56，各列宽度重新分配。表格里不再套一层竖向滚动条，只随页面滚动。
- 名称、编码过长时显示省略号，悬停可看全文，不再硬切成半个字（例如收付款的「合同款」、物料编码 CUSTOM-…）。
- 销售、采购等列表打开右侧面板时，列表只保留名称和状态两列，其余信息在右侧面板里看。以前客户名被切断，状态和金额被挤出视野。
- 一格里叠多行的地方，副行带上名称，例如「到期金额 ¥ 300.00」「约定付款 2026-12-01」「品牌 SMC」。以前要靠第几行来猜意思。物料的「单位」单独成列。副行与主行重复时不再显示，例如「无图·标准件」下面再写「标准件」，逾期任务的「已逾期 4 天」写两遍。
- 任务表的工时列没有登记时显示「未登记」（可点开查看），不再被截成「未登记 · 查…」。
- 没有对应里程碑节点的任务，节点一栏留空，不再显示「自定义任务」。
- 收付款页的「应收应付与费用」默认勾选「仅看未结」，财务进来先看到要处理的款项。带搜索词、从别处定位到某条款项，或在项目详情里看本项目款项时，仍显示全部。全部结清时提示原因，并提供「显示已结清款项」按钮。
- 用户管理的「总经理报表权限」只对管理员和项目经理显示授权状态，其他岗位显示「—」，不再一律写「未授权」。

### 项目详情页头
- 「下一步」只讲眼前这一步：只显示第一个还有缺项的环节，最多 3 个缺项，只写名称（详情在悬停提示里）。其余收进「全部检查（另有 N 项）」。以前同时铺开 7 个、有的被截成「还有 …」。
- 「项目待办」里计数为 0 的类别不再各占一个胶囊，只在末尾写「其余 N 类无待办」。

### 窗口与按钮
- 「新建项目」改为与「新建销售」相同的方式，在工作区内展开，不再弹居中对话框。项目的其他操作同样在右侧面板里完成。
- 右侧面板底部的「取消」和主按钮并排靠右，主按钮不再独占一行、「取消」不再掉到下一行。
- 「暂存并关闭」改名为「稍后再填」，并说明内容只保留在本机浏览器，不会提交，也不会生成草稿单据，与「保存销售草稿」区分开。离开页面时的确认按钮也相应改为「保留填写并离开」。
- 主按钮悬停时加深颜色。以前悬停会变成很淡的浅蓝，看起来像不能点。Element Plus 的红、绿、橙与自定义状态标签统一为同一套颜色。

### 表单与输入框
- 必填标记统一：不标即必填，选填项写「（选填）」。「按 BOM 下单」不再单独使用红色星号。
- 原生输入框与 Element Plus 下拉框统一为 14px（手机上仍为 16px，避免 iOS 聚焦时放大），占位文字颜色统一。
- 「需求说明」的多行提纲改为一行提示，不再看起来像已经填好。日期框保留浏览器原生控件（可直接键盘输入，手机弹出系统日期盘），外观与其他输入框对齐。
- 项目筛选框的提示由「输入项目筛选名称或编号」改为「输入项目名称或编号」。

### 页签与页面结构
- 手机上的页签自动换行，全部可见。以前收付款的 5 个页签只露出 3 个，也没有提示可以左右滑动。
- 库存页「收货进度」（待收货 / 部分收货）改用与列表状态筛选相同的分段样式；顶部快捷入口去掉与下方页签重复的「采购收货」。
- BOM 页未选项目时，列出在推进中的项目（需求中到交付中，按交期），点一下进入。以前只有一个空的输入框。

### 文字
- 库存、收付款的说明缩短；经营报表的五行口径说明默认收起，标题直接写出最关键的一句。
- 术语改成直白的说法：
  - 「隔离待处理」改为「到货待检」
  - 「编制用料 / 采购缺料」改为「维护用料 / 缺料下单」
  - 「确认占用其他项目到货」改为「允许领用其他项目的到货」
  - 「自定义任务」改为「节点之外的任务」
  - 「本人申请仍执行审批隔离」改为「自己提交的采购、付款等仍要由别人审批」
  - 「前导零会保留」改为「开头的 0 会原样保留（如 007）」
- 领料单的数量统一显示为 2.5、0（与库存列表一致），不再显示 2.500、0.000。领料窗口标题显示物料编码和名称，不再显示「#2」这样的内部序号。电脑上不再显示「手机上按每款物料逐项填写」。

### 首次安装向导
- 「初始密码」改为「初始密码（刚才登录用的密码）」，并说明为什么要再输一次。
- 「人员与兼岗」一步说明：系统没有单独的「总经理」岗位，总经理请选「项目经理」，再勾选「总经理经营报表授权」。
- 未填或格式不对时，在页面上用中文列出全部问题并标红字段，焦点落到第一项，不再弹浏览器自带的提示。
- 最后一步的确认勾选框改为醒目的确认框。
- 装完登录后，工作台最前面就是「准备基础资料」等岗位指引。

### 其他
- 加了网站图标，浏览器不再每页报一次图标 404。
- 浏览器标签页标题按页面区分，例如「库存 · 项目 ERP」；项目详情显示项目名称。
- 未登录打开 `/erp/` 时，不再先闪一下带导航的界面再跳到登录页。

## 升级说明

- 没有数据库迁移，没有配置变化。
- 接口：任务的 `milestone_label` 在没有对应里程碑节点时由「自定义任务」改为空字符串，导出的「里程碑节点」列相应留空。
- 金额、数量校验的提示文字有变化，「领用其他项目到货」的提示中勾选项名称也有变化。按提示原文做判断的外部脚本需要更新。
- 收付款页的款项列表默认只显示未结清款项，需要看已结清款项时取消勾选「仅看未结」；项目详情里的项目款项不受影响。

## 验证

已完成：
- 改动前在隔离预览库灌入真实规模数据（12 个项目、25 种物料、BOM、任务、销售和两条完整业务链），用 9 个岗位账号在 1366 和 390 宽度逐页、逐页签截图检查，共 22 项问题。改动后在同一环境复查截图，并实测 1366 宽下各列表都不出现横向滚动条。
- 后端按影响范围选出的 45 个测试模块共 860 项。首轮 1 项失败：断言了旧的数字提示措辞。更新断言后，该模块与里程碑模块重跑通过。checks 阶段（矩阵登记、Ruff、Django 检查、迁移检查）通过。
- 前端单元测试 733 项、ESLint、类型检查通过，新增首次安装向导、项目页头、项目待办、工作台、收付款默认筛选、表单错误去重等用例。
- 浏览器用例按影响范围选出 45 个文件，桌面端和手机端各 98 项。首轮失败的原因：
  - 本地预览后端中途重启；
  - 预览库数据冲突：项目序号用尽、物料重名；
  - 本版有意修改的文字和数量格式，已同步更新用例；
  - 两处真实问题，均已修复并补了单元测试：项目内款项被默认筛选隐藏、手机上多人任务漏显示共同执行人。
- 重跑后全部通过。只有 3 项未通过：手机端重复使用同一预览库导致的物料重名或按型号复用，这 3 项在桌面端首轮干净数据上通过。

未完成：
- 首次安装向导的浏览器用例需要全新安装环境，本地没有运行，只有单元测试覆盖，由 CI 运行。
- 没有在有真实业务数据的正式服务器上验证。

发布流程强制执行本版代码的发版验证，通过后才发布；不将其称为完整业务链验收。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.43-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.43/atm-erp-v1.8.43-linux-docker.zip -o atm-erp-v1.8.43-linux-docker.zip && unzip atm-erp-v1.8.43-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.43-SHA256SUMS.txt`。
