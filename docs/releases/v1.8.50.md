# v1.8.50

这一版是一轮审计整改：堵住登录、文件解压、换版调价几处安全和权限漏洞，修正换版改单、合同金额、工作台提醒里的口径问题，并改进升级后的磁盘清理。

没有数据库迁移，没有配置变化。

## 本次更新

### 退出登录在服务器上立即生效
- 点「退出登录」后，当前的登录令牌和续期令牌在服务器上立即作废，复制出去的令牌也不能再用。
- 闲置超过 15 分钟（登录令牌已过期）再退出，续期令牌同样会被作废。
- 只能作废自己的令牌，不能借退出接口作废别人的登录。

### 换版改单调高单价须经理确认
- 采购确认「换版改单」时，维持原价或降价可直接确认。
- 调高单价会增加已批准的应付，须由采购经理、项目经理或管理员确认；采购单的申请人不能确认自己单据的调价（管理员例外，须写原因），与批准采购的独立审批规则相同。
- 调价后超出项目预算时，须勾选「确认承担超预算调价」；预算调整人不能确认本项目的超预算调价（管理员例外，须写原因）。

### 采购单与合同按有效数量计
- 采购合同预览：有已取消数量的明细，数量和金额显示扣除取消后的有效值，并注明原数量和原金额；合计显示「现行有效含税合计」。
- 采购明细合计同样扣除已取消数量。
- 「处理记录」新增取消未收余量、换版按新图改单、确认换版改单、取消换版余量几类记录，写明新旧物料、数量、冲减金额和调价前后单价。
- 工作台「重签合同」提醒：取消余量后合同内容变化的、已全部收货的采购单也会提醒归档新版本合同。

### 任务通知发给执行人
新建任务、改派、重开或取消任务时，除提醒主管外，也给执行人本人发站内通知。

### 跨项目一步升版更稳
- 「升版」并勾选其他项目一起换版时，改为一次按固定顺序锁定全部项目、采购单和物料，避免与收货或另一次升版同时进行时卡死。
- 工作台「旧版待处理」改为批量计算，项目多时打开更快，数字与原来一致。

### 导出不再带内部列
项目、采购、对账、附件等导出文件不再包含只用于按钮显示的内部字段（如「可管理」「可审批」、下载路径），对账导出与列表列一致；新增列都有中文表头。

### 文件安全
- 附件预览（Word、Excel）和 BOM 导入按实际解压出来的大小限制，伪造文件头的压缩包无法绕过。
- 问题反馈的 GitHub 令牌改为加密保存。升级前保存的令牌仍可使用，管理员重新保存一次即加密。

### 其他
- BOM 页：项目详情稍后返回时，默认视图（维护用料 / 缺料下单）按当前用户能否编辑 BOM 自动选择；手动切换过的不再被改回。
- 「旧版待处理」面板切换项目时不会显示上一个项目的数据。
- 问题反馈提交超时的提示改为：内容可能已送达，请管理员先到反馈仓库确认，避免重复提交。
- 容器升级成功后自动删除已被替代的历史版本目录，保留当前版本、待重启版本和全部备份；另提供 `python scripts/container_ota.py prune --keep-backups N` 手动清理较旧备份（至少保留 1 份）。

## 升级说明
- 没有数据库迁移，没有配置变化。
- 新增接口 `POST /api/auth/logout/`（可带 `{"refresh": "..."}`）。已作废令牌记录在缓存（Redis）中，Redis 清空后作废记录随之丢失，令牌最长 12 小时后自然过期。
- 换版改单确认接口新增可选字段 `confirm_over_budget`（布尔值）。
- 采购合同预览新增 `effective_total`，明细新增 `effective_quantity`、`effective_amount`。
- 问题反馈令牌用 `SECRET_KEY` 加密。**更换 `SECRET_KEY` 后需要管理员重新填写反馈令牌**，否则页面显示未配置。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.50-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.50/atm-erp-v1.8.50-linux-docker.zip -o atm-erp-v1.8.50-linux-docker.zip && unzip atm-erp-v1.8.50-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.50-SHA256SUMS.txt`。
