# v1.3.0 · 销售交接与模块操作完善

- 新增销售经理角色，只操作本人销售订单；签约时指定项目经理执行，并可只读查询交付及回款。
- 设置、基础资料、库存、收付款及项目内模块拆为独立页签，支持直达链接、选择记忆、键盘操作及移动端滚动。
- 销售和采购支持独立上传合同、报价和技术资料，项目自动汇总；沿用角色权限和鉴权下载，原文件保留。
- 补齐七角色销售到项目、采购、生产、分批交付、售后、收付款及结项验证，修正跨日期报表测试。

本地验收：后端 179 项、前端 31 项、桌面及移动端浏览器 26 项全部通过。

提供 macOS、Linux、Windows 原生及 Docker 联网安装包和 SHA256 校验文件。升级采用前向迁移，保留现有业务数据；安装与升级说明见 README。
