# v1.8.14

## 本次更新

按易用性审阅的17项建议改进日常操作，让员工能看懂当前对象、填写要求、错误原因和下一步。

- 表单：复杂表单扩大编辑区域，完整流程可展开；提交按钮说明业务动作。未提交内容支持会话暂存和恢复，离开前提醒；错误集中展示并可定位到字段。
- 选择资料：输入名称或编号即搜索，支持键盘和分页；姓名优先显示，重名保留账号或编号。可按原权限就近新增客户、供应商和物料，自动选回原表单。
- 导入与 BOM：明确导入对象、项目和模板入口；错误行可筛选、定位，下载带错误批注的 Excel 修正重传；BOM 区分编制用料与采购缺料。
- 岗位操作：工作台显示普通进行中任务，项目增加待处理摘要；库存突出收货、领料和退料，期初登记与批量导入归入管理员初始化；岗位指引可跳过并重新打开。
- 财务与附件：付款前先显示缺少的对账或核准条件，提供处理入口；当前操作可上传并选中凭证，支持鉴权预览和下载；保存后可直接查看实际生成的记录。
- 防误操作：不同项目、不同款项的草稿分别保存；切换项目后关闭旧表单；搜索新名称时不继续沿用旧对象。

保持原岗位授权、项目范围、金额与库存校验以及幂等规则。无数据库迁移，无新增业务模块。会话暂存不等于已提交，退出账号会清除；文件需重新选择，已上传附件留在原项目或单据。

## 验证与使用范围

发布由 Release 工作流强制核验同一源码的发版验证：后端全部阶段、前端单测、运维脚本，以及按改动范围选择的桌面和手机视口页面。未运行完整业务链；手机视口与窄屏检查不等同于员工试用或真机软键盘验收。

实施与验收明细见 [17项修改记录](https://github.com/hongheshan-svg/atm-erp/blob/v1.8.14/docs/USABILITY_IMPLEMENTATION.md)。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.14-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.14/atm-erp-v1.8.14-linux-docker.zip -o atm-erp-v1.8.14-linux-docker.zip && unzip atm-erp-v1.8.14-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.14-SHA256SUMS.txt`。
