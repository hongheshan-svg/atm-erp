# v1.8.23

## 本次更新

- **任务多人共同执行**：新建任务、一键生成里程碑、重新分配和重开均可搜索姓名并多选执行人。任一执行人或有权限的经理确认后整项任务完成，每人分别登记本人工时；每位执行人都能在我的任务、工作台和流程进度中查看。
- **里程碑按业务顺序展示**：设计、采购、组装、调试、发货、客户终验收自上而下排列，阶段内按节点顺序展示，翻页与导出保持一致。自动同步节点显示完成依据和交付进度入口。
- **全部业务表格更易查看**：列表与明细统一显示序号，分页序号连续；宽表增加常显横向滑条及左右查看按钮，手机上避免固定列遮挡内容。导入预览和合同保留原文件行号及原明细序号。
- **批量删除可定位问题**：BOM删除受业务关联阻止时显示实际物料编码、名称和单元，删除确认清单支持搜索、序号及定位高亮，保留已选内容与删除原因。
- **人员选择与导入改进**：手机多选下拉不再撑宽页面，长姓名和账号可换行，增加“完成选择”；同名人员显示账号区分，任务导入可用分号分隔多人，兼容原单人模板。

## 升级说明

- 新增任务共同执行人关联表，采用正向迁移；原单人执行任务与历史记录保留，无需重新分配。旧版单人接口继续兼容。
- 重新分配替换完整执行人集合并保留审计；项目访问范围、岗位权限、业务关联删除保护及库存资金流水保留规则不变。
- 发货、现场安装接线和现场验收汇总仍由实际业务记录同步，不能用手动完成绕过发货或验收校验。
- 升级前完整备份，沿用现有配置、数据库、附件和运行卷，由现有升级流程完成备份与迁移。

## 验证

已完成相关模块的本地后端、前端及电脑/手机实际操作验证。发布流程对本版代码强制执行发版验证：全部后端阶段、前端单测、运维脚本测试、受影响页面双视口验证，以及本次数据库迁移所需的升级演练。验证通过后才构建并发布安装包，不将其表述为完整业务链验收。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.23-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.23/atm-erp-v1.8.23-linux-docker.zip -o atm-erp-v1.8.23-linux-docker.zip && unzip atm-erp-v1.8.23-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：
