# v1.8.6 · 请求日志与接口加固

## 本次更新

- 补上请求日志。此前 `DEBUG=false` 时 Django 默认把 `django.request` 的 ERROR 只发往管理员邮件，而系统未配置收件人，线上出现 500 时除了一行访问日志状态码之外不留任何痕迹，事后无从排查。现改为输出到标准错误，容器内由 supervisord 收集，`docker logs` 直接可见，不依赖外部日志服务。
- 任务列表消除 N+1 查询。判断任务能否取消或重新打开时，序列化每一行都要反查一次「同项目是否已发货」和「后续阶段是否完工」，这两项对同一项目的所有任务答案相同。改为在查询集上用子查询注解一次，列表和导出的查询数由随行数线性增长变为常数：十行任务由 20 条降至 4 条，十一条任务的导出由 22 条降至 4 条。
- 导出与导入新增限流。此前除登录外全站没有任何速率限制，而一次导出最多扫两万行、一次导入要解析整张表格。现按真实开销分档，均以操作人计：导出每分钟 12 次，解析并导入表格每分钟 30 次（留出「传错了改一改再传」的余地），取字段表和下载模板只返回列定义、不单独限制，与其余接口一样受每分钟 600 次的全局兜底约束。
- 表格导入的四个接口由基类改为按需混入。附件、银行匹配、银行流水、对账单和 BOM 并不支持表格导入，此前也各自暴露了四条只会返回错误的路由，现已移除。
- 账目与流水不可隐藏。删除和软删早已禁止，但直接置位删除标记再保存同样能让一笔款项从所有余额中消失。现在保存时即拒绝，把这条约束从约定变为代码层面的强制。

## 升级说明

沿用 Lean ERP 独立数据库，本版无新增迁移，不改变现有数据，接口字段与权限边界均未变化。升级服务先备份再升级。升级后请留意：同一账号每分钟导出超过 12 次、或导入表格超过 30 次时会返回限流提示，属预期行为。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.6-<platform>-docker.zip`，解压并进入目录。包内包含 GitHub 预构建的 amd64/arm64 镜像，校验后直接安装，不在本机构建。需先安装 Docker Engine / Docker Desktop（Linux 容器）、Compose v2 和宿主机 Python 3.11。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、Python 3.11、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.6/atm-erp-v1.8.6-linux-docker.zip -o atm-erp-v1.8.6-linux-docker.zip && unzip atm-erp-v1.8.6-linux-docker.zip && (cd atm-erp-v1.8.6-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，全新安装的初始密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。首次登录的安装向导会要求修改该密码，之后请使用向导中设置的新密码；忘记时按安装器结尾打印的命令重设。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.6-SHA256SUMS.txt`。
