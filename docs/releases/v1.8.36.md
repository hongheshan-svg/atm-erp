# v1.8.36

本版处理审查清单中第四到第六类：测试稳定性、重复和多余代码、文档整理。业务规则和计算结果不变，没有数据库迁移；少数提示文字和数字显示统一了口径，见下文。

## 本次更新

### 统一的提示与显示
- **导出上限**：
  - 各处导出超限的提示统一为「一次最多导出 20000 行，请缩小筛选范围。」。
  - 采购单导出按明细展开后的行数计算，超限时在生成文件前直接提示，与文档「最多 20000 行，采购按明细展开」一致。
- **BOM 移除、替换、批量移除**：低于已领用和在途数量时，提示与修订、导入相同：给出各单元合计和最低可改为的数量。
- **金额和数量显示**：
  - 收付款、对账、销售等下拉选项和提示里的金额，统一为两位小数加千分位，例如对账核准金额预填由「500」显示为「500.00」。
  - 采购质保、审批内容、记录详情和手机列表摘要里的数量，去掉末尾多余的零，例如「2.000 台」显示为「2 台」。
- **日期**：导出文件名里的日期和初始化向导的编号示例按北京时间取当天，不再随浏览器所在时区变化。
- **报表关注列**：没有关注事项时显示「—」。

### 修正
- **列表搜索**：页面刚打开或保存后列表还在加载时，在搜索框按回车会被忽略。现在随时都能提交，加载中的旧结果自动丢弃。
- **手机端项目任务主管**：每行下方约 400px 的空白已去掉。
- **BOM 导入预览**：核对在途数量时不再计入已删除的采购单，与保存时一致。
- **金额字段**：银行流水和对账的金额、对方余额，接口收到负数数字（而非文本）时也能正确识别。
- **读屏和键盘**：
  - 收发货明细和 BOM 采购选择里的输入框带上行号和物料名，读屏能分清是哪一行。
  - 状态页签、批量操作栏、合计区加上分组说明。
  - 窄屏只保留一个「全选」可聚焦。
  - 「查看导入记录」由按钮套链接改为单一链接。

### 代码整理（行为不变）
- **前端**：
  - 小数运算、文件下载、物料类别和编号规则名称、窄屏判断，各自只保留一份实现。
  - 原来分散在 13 处的定点小数计算，改为共用一个模块，并逐处核对舍入规则与修改前一致。
- **后端**：
  - BOM 可修改状态、采购状态名称、发货数量合计、采购退货确认、取消明细的收货状态等，都改为调用同一个函数，不再各写一份。
  - 任务列表每行少两个子查询。
  - 删除已不会执行的旧代码：华夏银行空流水号的旧分支、未用的付款到期函数、领料时补建编号规则（安装、升级和启动时已由初始化完成）。
  - 删除未使用的静态文件配置。
  - 不再写入未使用的 `is_staff` 字段。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.36-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.36/atm-erp-v1.8.36-linux-docker.zip -o atm-erp-v1.8.36-linux-docker.zip && unzip atm-erp-v1.8.36-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.36-SHA256SUMS.txt`。
