# v1.7.0 · 银行流水导入与系统稳定性修复



## 本次更新

- 新增工行 XLSX、华夏 XLS 流水预览与导入，校验汇总、重复交易和来源证据；个人收付款及手续费完整保留，由财务核实后认领或匹配。
- 优化银行列表查询、页面切换和大采购单编辑，避免重复请求、隐藏页加载和过期弹窗数据。
- 修复撤销重开丢失原减免金额、预算审批日期序列化和待付款到期筛选问题。
- 修复伪造转发地址绕过登录限流，完善附件备份恢复、恢复重试与服务健康监测。

## 升级与验证

升级前请备份数据库与附件。本版自动应用银行导入来源字段及撤销金额快照迁移，不清空现有业务数据。旧版本已撤销且缺少原减免记录的单据会阻止无依据重开，需人工核实。

发布通过完整 CI 门禁后生成安装包，覆盖后端、前端、桌面与移动端浏览器、OTA 及三平台安装验证。具体修复与本地验证记录见 docs/SYSTEM_RELIABILITY_FIXES.md。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.7.0-<platform>-docker.zip`，解压并进入目录。需先安装 Docker Engine / Docker Desktop（Linux 容器）和 Compose v2。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.7.0/atm-erp-v1.7.0-linux-docker.zip -o atm-erp-v1.7.0-linux-docker.zip && unzip atm-erp-v1.7.0-linux-docker.zip && (cd atm-erp-v1.7.0-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.7.0-SHA256SUMS.txt`。
