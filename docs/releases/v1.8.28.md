# v1.8.28

## 本次更新

- **现有库存勾选批量领料，生成真正的领料单**：仓管在“库存 → 现有库存”勾选要领的各行物料（只能勾有库存的行，翻页、换搜索后勾选保留，一次最多 100 行），点“批量领料（N）”。选一次项目，已验收项目还要选该项目的售后任务；填一次领料说明，再逐行填写本次数量，一次提交就出一张领料单。数量默认留空，需要整库位领走时点“全部按可用填入”。任何一行库存不足、超过 BOM 剩余或占用其他项目到货未确认，整单都不出库，提示会写明是哪种物料。
- **所有领料都出领料单**：单行领料、勾选批量领料、按 BOM 领料都会生成领料单（编号默认 LL000001 起，可在编号规则里调整前缀）。领料成功后可直接“查看 / 打印领料单”，打印页带公司抬头、明细和领料人、仓管签字栏。库存模块新增“领料单”页签，可按项目、日期、单号、物料查找；库存流水的“来源采购单”列改为“关联单据”，可点开对应的采购单或领料单。领料单不显示金额。
- **收货逐行勾选到货，少到的可一并取消余量**：
  - 收货表格每行有“到货”勾选，默认全选并按待收填好。没到货的行取消勾选即可，这一行不会提交。
  - 待收数量仍不能改。超过待收的数量提交前就会提示，多送部分请采购另行“新建采购”补单。
  - 供应商不再补货时，兼有采购权限的人可以勾选该行“余量 X 不再到货”并填写原因，收货和取消余量一次完成，应付按取消金额冲减。纯仓管看不到这个选项，仍请采购在“取消未收余量”处理。
- **入库日期看得到**：
  - 收货对话框第一项改为“入库日期（实际到货 / 合格收货日）”。
  - 库存流水新增“入库日期”列；现有库存在库存数量下方显示最近一次入库日期，导出为单独一列。
  - 采购“查看明细”显示每行的入库日期，分批到货时列出最近几批的日期和数量。
- **采购明细信息更全**：采购“查看明细”第一列合并显示物料名称、编码、规格、图号和品牌，并显示项目号 / 单元、明细交期、已收、待收、已取消等数量。手机上按行显示成卡片。
- **采购、销售附件可自己删除误传文件**：上传人在附件弹窗里勾选自己上传的附件，点“删除所选（N）”，或点该行“删除”，填一次原因即可，每批最多 50 份。项目经理可整理本项目内他人上传的附件。已作为收付款、对账、补充协议或归档合同依据的附件不能删除，任一份被拦截时整批都不删。删除只是移出列表，文件和审计都保留。管理员仍使用原来的批量删除。
- **BOM 导入可补填物料品牌**：已有物料原来没有品牌的，在 BOM 导入文件的品牌列填上后导入，确认时会把品牌补进物料资料，BOM 和导出里就能看到品牌。已有品牌不会被文件改写。不填编码时，如果系统里恰好有一条除品牌外完全相同、又没有品牌的物料，会补上品牌并沿用它，不会再建一个重复物料；有多条时提示填写编码。只补品牌、BOM 数量和单元都没变的文件也可以确认。

## 升级说明

- **本版有数据库迁移**：正向迁移 0027 新增领料单表，并给库存流水增加一个可为空的领料单关联列。只加表加列，不改动已有数据。升级沿用现有配置、数据库、附件与运行卷，请先完整备份再前向迁移；迁移后不支持退回旧版本程序。
- 升级前的历史领料没有领料单，库存流水“关联单据”列显示“—”。新安装的系统由初始化写入领料单编号规则；已上线的系统在第一次领料时自动补建，前缀默认 LL。
- 收货接口新增可选的“余量不再到货”参数，单条采购单读取新增入库记录字段，库存列表新增最近入库日期；附件新增批量删除接口。原有调用方式不变。
- 已验收项目在“按 BOM 领料”时仍需关联售后任务：请改用现有库存勾选批量领料，并选择该项目的售后任务。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.28-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.28/atm-erp-v1.8.28-linux-docker.zip -o atm-erp-v1.8.28-linux-docker.zip && unzip atm-erp-v1.8.28-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：
