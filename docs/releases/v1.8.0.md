# v1.8.0 · 全系统界面与行业表单优化

## 本次更新

- 统一 14 类页面及各子模块的导航、工具栏、筛选、分页、状态标签与侧边详情，完善桌面、手机和中间宽度布局。
- 优化工作台、经营报表、项目详情、BOM 多选采购、库存、收付款、基础资料和设置；长表单内部滚动，底部操作保持可达。
- 更新登录行业插图和首次安装五步向导，采购合同集中展示预览、版本、归档与打印操作。
- 完善用户主岗位及兼岗筛选、库存物料属性筛选、未结款项搜索，并保留原权限范围、敏感金额过滤和退款余额。
- 修复导入模板、预览与页面字段对应，优化自动化设备行业表单填写和校验。
- 改善 OTA 实际运行版本校验和升级进度反馈。

## 升级与验证

本版无新增数据库迁移，继续复用原业务数据与固定角色权限。升级前请备份数据库及附件；正式部署使用 production 配置并保留登录限流。

本地后端 248 项、前端 60 项及桌面/手机浏览器回归 40 项通过，两个独立新数据库分别完成首次安装验收。发布流水线验证前后端、双端浏览器、OTA 及三平台安装后才公开安装包。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.0-<platform>-docker.zip`，解压并进入目录。需先安装 Docker Engine / Docker Desktop（Linux 容器）和 Compose v2。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.0/atm-erp-v1.8.0-linux-docker.zip -o atm-erp-v1.8.0-linux-docker.zip && unzip atm-erp-v1.8.0-linux-docker.zip && (cd atm-erp-v1.8.0-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。首次登录按向导完成配置。

### Manual download

从下方 **Assets** 下载对应平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.0-SHA256SUMS.txt`。
