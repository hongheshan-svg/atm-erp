# v1.0.0 · Lean ERP

面向约 50 人非标自动化公司，围绕销售到项目交付、售后和结算完成 Lean ERP 重构。

## 主要变化

- 九个独立入口：工作台、销售、项目、BOM、采购、库存、收付款、基础资料、设置。销售独立维护需求、报价及合同，签约事务交接执行项目和应收。
- 六种固定角色、成员项目范围、敏感金额过滤、采购提交与经理批准；权限由后端校验。
- 采购、库存及收付款使用事务锁和幂等保护。支持分批收货、取消余量、退款、分批交付、免费/收费售后及工时纠正，原始流水保留。
- 保留深蓝侧栏、蓝色主操作和白色卡片，统一表格与弹窗样式；工作台新增分类图标、待办数量、空状态说明和模块入口。低频设置默认折叠并按需加载。
- 清理旧扩展与冗余业务分支，按模块组织页面和服务；公共组件与验证技能复用。
- 部署仅 PostgreSQL 15、Redis 7、应用三个服务；提供安装、备份及独立恢复入口。

## 安装与兼容性

**本版不兼容 v0.3.x 等旧版全量 ERP 数据库，不可覆盖原部署升级。** 请使用独立项目和新卷；检测到旧表、旧迁移会拒绝启动，不要清库或绕过 schema guard。

从本版本源码目录执行 `bash install.sh`，Windows 使用 `./install.ps1`。默认地址 `http://127.0.0.1:8080/erp/`，管理员 `admin` 的随机初始密码保存在 `.env.lean`。本次发布提供源码，安装脚本从源码构建 Docker 镜像；不提供旧版的一键升级代理。

当前 Lean 预发布数据库可按现行迁移向前更新；销售迁移保留项目编号、成员及流水，将商业金额移到销售单。环境密钥须单独保管，备份归档不包含密钥。

## 验证

- 本地后端 111 项、前端 19 项测试通过，lint、类型检查及生产构建通过。
- 最终 UI 的桌面/移动 Chromium 10 项通过，包含六角色销售到交付、售后与结算完整链路。
- 独立 Docker 全新安装通过；备份恢复逐表核对 28 张表、16 个附件一致，非空覆盖被拒绝，重复安装保留数据。

GitHub CI 结果见本版本关联 PR。移动端为 Chromium 仿真，不代表真机软键盘验证；Windows 安装脚本有 CI 检查，不代表 Windows Docker 实机已验收。
