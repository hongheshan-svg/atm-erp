# v1.8.20

## 本次更新

本版改善附件查看、采购修改申请、合同查看与打印、BOM询价导出，减少员工反复下载、逐项选择和页面切换。

- **附件在线预览**：采购、销售、项目及收付款相关附件统一提供预览。支持图片、PDF、Excel/CSV、Word DOCX和文本；Excel可切换工作表、分页查看，PDF可翻页和缩放。预览与原件下载均沿用原权限，不调用外部文档服务。表格和Word以文字/单元格内容为主，复杂排版、图表及不支持格式可下载原件。
- **待审批采购申请修改**：采购员填写原因，由独立审批人同意退回草稿或驳回。同意后修改并重新提交审批；申请待处理时阻止普通批准及绕过申请的直接修改、作废或删除。列表、工作台、流程进度及处理历史显示申请状态。已批准单继续使用原取消余量、更正流程。
- **完整采购合同**：双方信息、全部采购明细、条款、完整备注及签章区在同一页面连续显示，打印/PDF自动分页，无需切换正文和附件。默认质保明确显示为各批货物验收合格之日起12个月；另有约定的单据仍以保存的月数为准。
- **非标自动化采购条款**：补充图纸版本、材质公差与关键工艺、标准件替代确认、首件/性能验收、变更费用与交期、程序和技术资料交付、现场服务、保密及知识产权事项。具体技术指标与服务时限需按项目书面约定，签署前结合实际项目复核。
- **BOM导出准确匹配范围**：可导出“已选N项”或“当前筛选结果N项”，包含所有分页。筛选标准件后全选81项，只导出这81项；同料不同单元分别保留。存在当前筛选外的历史选择时明确提示，支持只导出当前筛选结果。
- **BOM文件易读**：列名与类别中文显示，去掉内部ID和权限标记；编码保留前导零，数量可求和。导出输入为空、行已删除或不属于当前可见项目时明确拒绝，不回退成全项目导出。
- 修复资料选择器在表单重新显示时丢失选项，以及BOM视图单选按钮被撑宽、文字竖排的问题。

## 兼容与验证

- 无数据库迁移，不回写历史已签署合同或修改既有库存与账款；原文件下载保留。历史合同沿用当时归档条款，新行业条款用于当前资料和后续确认的新版本。
- BOM导出文件用于核对和询价，导入仍请下载专用模板。
- 已完成相关后端、前端、权限、桌面/手机页面和真实文件下载验证。正式发布须通过同一Git tree的发版验证：全部后端阶段、全部前端单测与运维脚本测试，浏览器按发布改动范围执行双视口检查，不包含完整业务链；适用的升级和安装验证由影响计划选择。未通过不会发布。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.20-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.20/atm-erp-v1.8.20-linux-docker.zip -o atm-erp-v1.8.20-linux-docker.zip && unzip atm-erp-v1.8.20-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.20-SHA256SUMS.txt`。
