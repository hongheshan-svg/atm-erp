# v1.8.1 · 预构建安装与自动升级修复

## 本次更新

- Docker amd64/arm64 镜像在 GitHub 构建并验证，正式安装包携带镜像归档、固定镜像身份与 SHA256。安装和 OTA 直接导入，不再本地编译。
- 三平台原生包携带 CI 预编译依赖，校验后离线安装，无需本机编译依赖或前端。仍需准备 Python 3.11、Nginx、PostgreSQL 15 和 Redis 7。
- 安装器默认注册并启动宿主机升级服务，异常退出自动恢复，页面按真实心跳显示连接。
- 修复后台执行器私有权限设置导致解压文件在 Docker 内不可读的问题，增加与真实服务一致的权限回归。
- 简化升级进度显示；断连明确标记旧进度，不再同时显示缓存的“已连接”。详细步骤、失败原因和备份位置可展开查看。
- 保留管理员升级授权、固定仓库、备份优先、前向迁移及失败审计；不清库、不自动回退数据库。

本版无数据库迁移。v1.8.0 及更旧的源码构建型执行器需使用新版安装包原地安装一次，接入新的自动服务后使用预构建 OTA；保留原配置、数据库和备份。新执行器不再为旧的源码型发布包执行本地构建。运行环境与接入步骤见 README。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.1-<platform>-docker.zip`，解压并进入目录。包内包含 GitHub 预构建的 amd64/arm64 镜像，校验后直接安装，不在本机构建。需先安装 Docker Engine / Docker Desktop（Linux 容器）、Compose v2 和宿主机 Python 3.11。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、Python 3.11、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.1/atm-erp-v1.8.1-linux-docker.zip -o atm-erp-v1.8.1-linux-docker.zip && unzip atm-erp-v1.8.1-linux-docker.zip && (cd atm-erp-v1.8.1-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.1-SHA256SUMS.txt`。
