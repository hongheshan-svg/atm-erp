# v1.8.4 · 局域网部署修复与流程可见性

## 本次更新

- 修复非 HTTPS 部署下登录与全部写操作失效：`crypto.randomUUID()` 仅在安全上下文可用，而安装器默认以明文 HTTP 提供服务，用局域网 IP 访问时登录、BOM 勾选采购、批量导入、所有操作对话框保存、安装向导和系统升级都会失败。改为在缺失时回退生成合法标识。
- 销售、项目、采购、交付、收付款、对账、银行流水、收付流水、任务和采购质保十条流程统一展示流程节点与当前位置；取消、作废等终止状态离开主链单独标示，不假装停在某个节点上。
- 列表操作列改为「实心按钮＝下一步该做的事」，菜单不再重复该操作并按推进单据、质保、查看资料分组；采购页操作由 10 项平铺整理为 9 项分三组。
- 采购页以「从 BOM 多选下单」为主入口并说明两个下单入口的分工，导出导入收进单一菜单，顶部控件由 6 个减到 4 个。
- 登录页按视口自适应：插图不再决定页面高度，表单竖向节奏随屏高伸缩且保留 44px 触摸下限，常见笔记本与手机尺寸均一屏显示，不再需要下拉。
- 工作台默认展开全部非空待办分类，不再自动只选中其中一类。
- 安装器在端口与允许主机名不一致时给出明确提示；初始密码在安装向导修改后即失效，完成提示改为说明这一点并打印重设命令，原生安装新增 `reset-password`。

## 升级说明

沿用 Lean ERP 独立数据库，本版无新增迁移，不改变现有数据。升级服务先备份再升级。局域网部署需同时设置 `LEAN_BIND_ADDRESS` 与 `LEAN_ALLOWED_HOSTS`，只改其一时安装器会提示。完成安装向导后 `LEAN_ADMIN_PASSWORD` 不再可用，请使用向导中设置的新密码。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.4-<platform>-docker.zip`，解压并进入目录。包内包含 GitHub 预构建的 amd64/arm64 镜像，校验后直接安装，不在本机构建。需先安装 Docker Engine / Docker Desktop（Linux 容器）、Compose v2 和宿主机 Python 3.11。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、Python 3.11、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.4/atm-erp-v1.8.4-linux-docker.zip -o atm-erp-v1.8.4-linux-docker.zip && unzip atm-erp-v1.8.4-linux-docker.zip && (cd atm-erp-v1.8.4-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，全新安装的初始密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。首次登录的安装向导会要求修改该密码，之后请使用向导中设置的新密码；忘记时按安装器结尾打印的命令重设。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.4-SHA256SUMS.txt`。
