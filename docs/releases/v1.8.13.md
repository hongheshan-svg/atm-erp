# v1.8.13

## 本次更新

- 全部13类导入模板增加首次填写指引：打开先显示准备资料、最少填写内容及业务例子，点击“开始填写”进入数据页；逐列说明填什么、去哪里查、如何填写。
- 确定内容直接选择：产品编码类别、标准/非标、往来单位类型、任务阶段、采购账期和结算方式提供中文下拉，单位可选常用值或手填。说明页的“▼点此选择”可跳到对应输入格，并明确下拉箭头的打开方法。
- 减少漏填与格式错误：必填、条件必填和可选表头使用不同颜色；开始填写后标红本行可判断的缺项，编码、账号、电话和记录ID等保留文本格式。模板及独立说明统一使用中文文件名。
- BOM预览立即可见：选文件后立即显示预览窗口和读取状态；校验失败仍保留原始明细，按文件行号列出具体中文问题，确认按钮始终在窗口操作区。关闭、切换项目或版本后忽略旧请求，取消最终确认可返回预览。
- 明确纠错办法：区分项目、任务与BOM上传入口，解释已有/新增物料、规格与图号、姓名与账号、截止日期与天数，以及编号与ID。表头不匹配或没有数据时提示具体修改步骤。

## 兼容与验证说明

本版没有数据库迁移或运行时依赖变更。原模板表头、列序及旧版模板仍兼容；数据页不预填示例，填写说明不作为业务数据导入。请重新下载Excel模板以获得下拉和新指引，CSV仍需配合说明使用。

下拉、提示和缺项标红不能代替服务端校验。人员岗位、项目范围、状态、金额、整批回滚与重复确认保护继续生效；BOM预览不保存物料或占用编号，校验未通过时不能确认导入。

本地已通过277项后端测试、133项前端测试、静态检查与构建，以及桌面/手机共8项相关导入页面验证；核对13份Excel及13份HTML说明。发布由GitHub强制完成发版验证：全部后端阶段、前端单测及运维脚本测试，以及按变更范围选择的双视口页面测试；本版不触发OTA及安装器演练，不包含完整业务链测试。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.13-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.13/atm-erp-v1.8.13-linux-docker.zip -o atm-erp-v1.8.13-linux-docker.zip && unzip atm-erp-v1.8.13-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.13-SHA256SUMS.txt`。
