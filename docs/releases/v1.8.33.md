# v1.8.33

本版补全 v1.8.32 对大文件超时的修正，不新增业务功能。

## 本次更新

- **服务端处理较久的大导入不再被提前断开**：
  - v1.8.32 已把附件上传、文件导入及其确认、导出和下载在浏览器端的等待时间延长到 5 分钟。
  - 但服务器上负责把浏览器请求转给后端的 Nginx 只等后端 60 秒。处理上千行的导入确认或大批量导出时，超过 60 秒仍会提示失败，而后端可能已经写入完毕。
  - 本版把 Docker 部署和原生安装的 Nginx 后端等待时间统一改为 5 分钟，与浏览器端一致。
- 普通请求仍由浏览器在 25 秒后放弃。浏览器断开时，Nginx 随即关闭对应的后端连接，不会因此长时间占用服务。

## 升级说明

- 本版**没有数据库迁移**。升级沿用现有配置、数据库、附件与运行卷，按常规先完整备份再升级。
- Docker 部署随新镜像生效。原生安装在启动时重新生成 Nginx 配置，升级后重启服务即可生效。
- 如果在本系统之外还有一层反向代理（如公司网关、负载均衡），它的读取超时也需要不少于 5 分钟，否则大文件导入仍会在那一层被断开。

## 验证

已完成：
- CI 脚本测试：新增用例核对 Docker 与原生 Nginx 的等待时间都与前端一致，在修复前的配置上确认失败。
- 静态检查。

发布流程强制执行本版代码的发版验证，通过后才发布；不将其称为完整业务链验收。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.33-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.33/atm-erp-v1.8.33-linux-docker.zip -o atm-erp-v1.8.33-linux-docker.zip && unzip atm-erp-v1.8.33-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.33-SHA256SUMS.txt`。
