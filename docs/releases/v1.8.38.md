# v1.8.38

本版优化 CI 与发版流程的耗时，并修正浏览器自动化测试偶发被接口限流的问题；前端遇到短暂限流时会自动等待并重发。业务规则不变，没有数据库迁移。

## 本次更新

### 短暂限流自动重发
- 服务端每个账号每分钟最多处理 600 次接口请求，用来防止脚本失控。偶尔连续操作碰到上限时，页面以前直接提示「操作过于频繁，请稍后再试」。
- 现在如果服务端只要求等 5 秒以内，页面会自动等待后重发，最多两次，用户不必手动重试。
  - 被限流的请求在服务端并未执行；保存类操作重发时沿用同一操作标识，不会重复写入。
  - 登录、导出等按分钟计的限流仍直接提示，不会让页面长时间等待。

### 开发与测试环境
- `development` 环境（本地联调和 CI 的浏览器测试安装）的每账号接口上限放宽到 6000 次/分钟，与登录限流只在生产生效的做法一致。
- 生产环境（默认）不变：登录 10 次/分钟、接口 600 次/分钟。
- 原因：v1.8.37 发版时，浏览器测试的一个分片在约一分钟内以 admin 账号请求超过 600 次，3 个用例被限流而失败；重跑失败的分片后通过并发布。
- 浏览器测试的接口辅助函数遇到限流也会按服务端给出的等待时间重发，只等短暂限流的保存结果。

### CI 与发版耗时
基线取自最近 58 次运行：
- **发版前置检查**：查找可复用的验证结果时改为并发查询，结果与原来逐个查询完全相同。这一步从约 1.5–3.4 分钟降到预计 1 分钟以内，发版总耗时预计从 15–17 分钟降到 12–13.5 分钟。
- **actionlint**：改为下载固定版本的预编译文件并校验 SHA256，不再每次在线编译。此前约 70% 的运行没有命中缓存，每次多花 9–20 秒。
- **浏览器测试分片**：前端依赖和 Chromium 改为在后台安装，与镜像构建、安装器同时进行，每片约少 30 秒。
  - 这一步网络安装失败会重试最多 3 次，用例本身不重试。
  - 移除从未命中的 Playwright 缓存，释放约 3.5 GB 缓存额度。
- **原生安装冒烟测试**：nginx 的 apt 下载遇到网络错误时重试。
- 没有删除任何验证项，检查名称不变；发版仍强制验证 tag 对应的代码。

## 升级说明

- 本版**没有数据库迁移**，按常规升级即可；升级前按常规完整备份。
- 生产部署的限流规则不变。不要把 `LEAN_ENVIRONMENT=development` / `APP_ENVIRONMENT=development` 用于正式部署。

## 验证

已完成：
- 后端全量测试 852 项通过（新增 1 项：开发环境只放宽每账号接口上限）；静态检查和迁移检查通过。
- 前端：lint、typecheck 通过；Vitest 82 个文件、712 项通过（新增 3 项限流重发用例）；构建成功。
- `scripts/tests` 200 项通过；全部 workflow 经 actionlint 检查。
- 浏览器用例：在本机隔离安装上，按 v1.8.37 失败分片的同一组 13 个用例文件，桌面和手机各跑一遍，都在新的空库上运行，结果均通过。

发布流程强制执行本版代码的发版验证，通过后才发布；不将其称为完整业务链验收。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.38-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.38/atm-erp-v1.8.38-linux-docker.zip -o atm-erp-v1.8.38-linux-docker.zip && unzip atm-erp-v1.8.38-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.38-SHA256SUMS.txt`。
