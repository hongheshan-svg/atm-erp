# v1.5.0 · 多岗位兼任与权限合并

## 本次更新

- 一个账号可兼任多个固定角色，用户管理支持多选与回显，菜单和业务操作按岗位权限合并。
- 保留销售负责人范围、项目成员范围及敏感金额过滤；销售兼采购不扩大销售范围，销售兼财务可读取他人销售但不能修改。
- 报表继续单独授权，保留最后管理员保护、已有审批约束及角色变更审计；移除角色后重新校验接口、附件和操作重放权限。
- 兼容旧单角色账号，新增兼岗字段默认不改变现有权限；未完成任务的兼岗成员仍受项目移除保护。

## 升级与验证

升级前备份数据库及附件，执行 Lean 数据库前向迁移，不支持降级或旧版数据库。安装默认 production，开启登录限流。

本地后端 206 项、前端 36 项、桌面及移动端浏览器 32 项通过。完整 GitHub CI 在合并前验证。提供三平台原生及 Docker 联网安装包，不内置数据库、运行时或 Docker 镜像。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.5.0-<platform>-docker.zip`，解压并进入目录。需先安装 Docker Engine / Docker Desktop（Linux 容器）和 Compose v2。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.5.0/atm-erp-v1.5.0-linux-docker.zip -o atm-erp-v1.5.0-linux-docker.zip && unzip atm-erp-v1.5.0-linux-docker.zip && (cd atm-erp-v1.5.0-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.5.0-SHA256SUMS.txt`。
