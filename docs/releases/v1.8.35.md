# v1.8.35

本版处理审查清单中的性能问题，减少数据库查询，并新增 3 个索引。业务规则、提示文字和计算结果都不变，也不新增功能。

## 本次更新

### 数据量大时更快的操作
括号内是测试中同一操作在不同行数下的数据库查询次数（修复前 → 修复后）。修复后，查询次数不再随行数增长。

- **BOM**：
  - 导入预览：30 行 124 → 8。
  - 修订和修订预览：30 行修订 167 → 20。
  - 批量移除：30 行 192 → 18。
  - 这些操作期间锁住项目和物料编号的时间也随之缩短。
- **采购**：
  - 按 BOM 缺料下单：30 行 265 → 29。
  - 修改采购草稿：30 行 381 → 25。
  - 交期计划和质量退货，一次锁定全部明细。
- **领料**：
  - 批量领料：60 行 708 → 27。
  - 领料时会占住全公司共用的领料单号，等它的其他领料不再被大单长时间卡住。
- **发货与项目推进检查**：查询次数不再随 BOM 物料数增长，30 种物料 48 → 18。
- **工作台**：
  - 缺料项目一次统计：30 个项目 135 → 5。
  - 只请求某一类待办时，不再计算其他类别。
- **保存时的校验**：
  - 每次保存都要核对外键和约束，现在对已读出的关联记录不再重复查询，多条约束合并为一次核对。
  - 收货 20 行的总 SQL 从 1291 条降到 488 条，新建 20 行采购从 449 条降到 125 条。
  - 报错内容和顺序不变。
- **银行流水导入确认**：25 行 496 → 296，不再为每一行另写一条操作回执。
- **其他表格导入确认**：同一批内不再重复加锁和授权，人员和任务一次读出。每行仍单独核对权限。
- **财务与销售**：
  - 生成对账单时少算一次快照；月结确认复用已算好的快照。
  - 销售单的各项操作只读取、锁定销售单一次。
  - 销售「交付与回款」的应收回款不再逐条查询。
- **关注视图**：逾期应收、30 天回款、迟到采购和呆滞库存先在数据库中筛选，不再把全公司数据读进内存。
- **网页升级**：请求缺少操作标识时直接拒绝，不再先访问 GitHub。

### 新增索引
- 物料名称和规格查重，与系统实际比对的写法（忽略全半角、空格和大小写）一致，可以直接走索引。
- 审计记录按操作类型的索引，用于「已删除记录」列表和收付款恢复检查。
- 操作回执按内容指纹的索引，用于判断表格是否已经导入过。
- 删除一个没有任何查询使用的旧物料名称索引。

### 前端
- **远程下拉框**（项目、供应商、物料等）：
  - 打开页面时不再预先下载候选列表，展开时才读取。
  - 已有值时只读取这一条，用来显示名称。
  - 一张有多行选择框的表单，打开时不再同时发出多次列表请求。
- **列表和收货明细**：
  - 列表每行的操作按钮只在数据或权限变化时重新计算，输入搜索词时不再重复计算。
  - 收货明细与原单对照时，不再逐行在全表里查找。
- **登录页**：
  - 插图从 1.39MB 压缩到 114KB，画面看不出差别。
  - 手机上插图本来就隐藏，现在也不再下载。
- **生成对账单**：只读取合同、结算凭证和其他类附件，不再把项目的图纸、交付资料一并下载。

### 行为细节
- 银行导入的同一笔流水被管理员删除后再次导入，现在提示数据冲突（409）。此前，同一用户重导时会报服务器错误。

## 升级说明

- 本版**有数据库迁移**：`business.0028_item_match_indexes` 和 `core.0009_operation_indexes`。
  - 迁移只增删索引，不改动任何数据。
  - 由现有升级流程自动完成；升级前按常规完整备份。
- 建索引期间，物料、审计记录和操作回执三张表会短暂暂停写入。审计记录很多的部署，迁移可能需要多花几十秒。
- 接口不变：
  - 银行导入确认不再为每一行另写操作回执（`bank-import:<指纹>`）。系统中没有地方读取这些回执，整批回执和逐行查重保持不变。
  - 其余调用方式和返回内容不变。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.35-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.35/atm-erp-v1.8.35-linux-docker.zip -o atm-erp-v1.8.35-linux-docker.zip && unzip atm-erp-v1.8.35-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。
