# v1.8.37

本版收尾审查清单的剩余事项：固定全部 Python 间接依赖、银行导入预览标出已删除的同一笔流水、清理文档中的本机路径。业务规则不变，没有数据库迁移。

## 本次更新

### 银行导入预览
- 管理员删除的银行流水只是移入「已删除记录」，仍参与查重。以前重新导入同一笔交易时，预览只显示「已导入（跳过）」，可用户在列表里找不到这条记录。
- 现在这类行的状态显示「原记录已删除（跳过）」，并在预览表上方逐行注明原记录 ID 和流水号：
  > 第 N 行：与已删除的银行流水（记录 ID …，流水号“…”）是同一笔交易，此前已登记、后由管理员删除，本次跳过，不会重复导入。如需核对，请管理员在“银行到账与认领”的“已删除记录”中查看原始记录。
- 提示里不显示金额和对方户名。
- 确认导入时与其他已登记的交易一样计为跳过，不新增记录，也不影响整批导入。

### 安装包依赖固定
- 新增 `backend/constraints.txt`，固定运行所需的全部 45 个 Python 包（含间接依赖）的版本。Docker 镜像、三个平台的原生安装包、CI 测试环境都按同一份清单安装，发版时不会再解析到与 PR 验证不同的版本。
- 上游没有提供 macOS 可用的 autobahn 新版和 Intel 版 cryptography 新版，macOS 两种架构统一使用 autobahn 24.4.2、cryptography 48.0.1。
  - Apple Silicon 原生安装的 cryptography 由 50.0.2 降为 48.0.1，pyOpenSSL 由 26.4.0 降为 26.2.0，与 Intel Mac 一致。
  - Linux、Windows 和 Docker 的版本不变。
- 原生安装要求 Python 3.11.3 及以上的 3.11 版本。3.11.0–3.11.2 需要额外的依赖，而离线安装包里没有，安装会中途失败；现在启动安装时就直接提示。
- 升级依赖的步骤见 CI_OPERATIONS 的「Python 依赖固定」。

### 文档与测试
- 文档中的本机路径不再带用户名：改为 `~/…` 或「本机临时目录」，指向本机文件的链接改为纯文本。
- 付款条件、收发货明细、取消操作三个浏览器用例改用共用的保存和接口方法，只匹配准确的请求路径。

### 更正
- v1.8.35 的说明写有「银行导入的同一笔流水被管理员删除后再次导入，现在提示数据冲突（409）」，经核实这句不准确。
  - 已删除的流水仍参与查重，重新导入时这一行被跳过，整批照常导入。
  - 409 只会出现在两次导入、或导入与手工登记同时写入同一笔流水的情况。

## 升级说明

- 本版**没有数据库迁移**，按常规升级即可；升级前按常规完整备份。
- 原生安装如果使用 Python 3.11.0–3.11.2，请先升级到 3.11.3 及以上的 3.11 版本。Docker 部署不受影响。
- 银行导入预览的接口响应新增 `notices` 列表（行号与提示）；其他字段和确认接口不变。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.37-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.37/atm-erp-v1.8.37-linux-docker.zip -o atm-erp-v1.8.37-linux-docker.zip && unzip atm-erp-v1.8.37-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.37-SHA256SUMS.txt`。
