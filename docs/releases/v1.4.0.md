# v1.4.0 · 对账、采购账期与合同打印


## 本次更新

- 新增采购付款及退款对账、预付款核准、银行流水认领与匹配，保留冲销及核对历史，复用原收付款事实。
- 供应商账期带入采购，支持现付、月结30/60/90/120天和自定义天数；月结按每批合格收货当月月底加自然日计算，跨月分别到期。
- 物料新建和导入支持自定义编码，留空自动生成；补齐页面验收及采购合同中的编码展示。
- 采购自动提供合同预览及打印，正文单页 A4，完整明细附件单独打印；包含验收、一年质保及违约责任，不带系统生成信息。

## 升级与验证

升级前备份数据库及附件，沿用 Lean 独立数据库前向迁移，保留业务记录，不支持旧版数据库或降级。发布安装默认 production，开启登录限流。

本地后端 200 项、前端 35 项及合同桌面/移动端专项通过；完整 GitHub CI 在合并前验证。提供三平台原生及 Docker 联网安装包，不内置数据库、运行时或 Docker 镜像。


## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.4.0-<platform>-docker.zip`，解压并进入目录。需先安装 Docker Engine / Docker Desktop（Linux 容器）和 Compose v2。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.4.0/atm-erp-v1.4.0-linux-docker.zip -o atm-erp-v1.4.0-linux-docker.zip && unzip atm-erp-v1.4.0-linux-docker.zip && (cd atm-erp-v1.4.0-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，首次密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.4.0-SHA256SUMS.txt`。
