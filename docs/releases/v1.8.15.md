# v1.8.15

## 本次更新

- 完成32项审计整改，落实9项已确认业务规则，补齐权限、金额、库存、导入与并发回归。
- 修复兼岗跨项目敏感金额读取；批量列表复用成员范围，写入和重复请求继续重新授权。
- 采购支持按明细取消未收数量、分次收货、历史日期补录原因及“已到货待检”提示；合同取消金额与应付抵减一致。
- 收费售后的维修期限与客户付款期限分开；允许按真实合同填写早于签约日的收款节点并提醒；历史未签约项目重开仍保持未签约。
- 导入确认错误定位到文件行与字段，支持下载标注文件、内容防重及查看结果；生产经理可导入参与项目的装配和调试任务。
- 对账仅因经济事实变化而失效，申请时提前检查额度，收付款默认值受余额与核准额度约束；约定付款日单独展示。
- 允许锁账期间新增原始银行流水供核对，付款入账和历史账款修改仍受锁账限制。修复等价时间写法绕过银行交易防重的问题，兼容旧指纹和预览凭据。
- 修复跨项目导入及交叉工时登记死锁，保留每日工时上限、费率一致性和等待后的权限检查；完善刷新限流、附件超时重传和中文冲突提示。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.15-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.15/atm-erp-v1.8.15-linux-docker.zip -o atm-erp-v1.8.15-linux-docker.zip && unzip atm-erp-v1.8.15-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download
