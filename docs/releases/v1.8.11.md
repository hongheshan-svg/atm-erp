# v1.8.11

## 本次更新

- 客户与供应商：新增、编辑纯客户时隐藏供应商采购账期；供应商和双用途单位继续显示。切换为纯客户后清除不适用的采购账期。
- 项目进度：执行项目按“执行中 → 交付中 → 已验收 → 已结项”展示，不再把销售报价和等待客户确认显示为项目执行阶段。
- 导入模板：全部13类模板提供逐列填写说明。Excel附带“填写说明”页及表头提示，页面支持下载可打印、转发的说明文档；示例不写入数据区。
- 任务导入：明确按用户管理的“用户名”匹配，支持中文用户名；区分账号不存在、停用和项目成员范围问题，不再只显示“找不到user”。
- 中文提示：校验、登录、网络、限流、任务/BOM和银行流水导入错误显示中文；导入保留文件行号和中文列名，升级失败不直接显示内部英文异常名称。

## 兼容与验证说明

本版没有数据库结构迁移。已有单工作表模板、旧版列顺序及CSV仍兼容；新模板只导入“数据”页，不把说明或示例当作业务记录。账号与业务编号保持原值，原有岗位权限、项目范围、金额、库存、状态及整批回滚校验继续生效。

本地已通过受影响后端模块、前端单测、静态检查与构建，并验证电脑和手机上的客户账期、模板说明和中文导入错误。GitHub发版验证必须通过后才构建、发布安装包：全部后端阶段、全部前端单测与运维脚本测试，按版本差异选择相关页面的双视口验证及适用的OTA/安装器检查，不含完整业务链。

员工填写说明：[导入模板填写说明](https://github.com/hongheshan-svg/atm-erp/blob/v1.8.11/docs/IMPORT_TEMPLATES.md)。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.11-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.11/atm-erp-v1.8.11-linux-docker.zip -o atm-erp-v1.8.11-linux-docker.zip && unzip atm-erp-v1.8.11-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.11-SHA256SUMS.txt`。
