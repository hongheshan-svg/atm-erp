# v1.8.8 · containerd 升级兼容与中文密码设置

## 本次更新

- 修复 Docker containerd 镜像存储下的一键升级失败：镜像导入后，使用已校验归档中的配置、清单及索引摘要识别镜像，不再假设所有 Docker 引擎返回相同形式的 image ID。保留 SHA256、平台和镜像身份校验，不回退本地构建。
- 管理员创建账号、重设密码及安装向导添加团队成员时，可生成随机初始密码，也可手动设置。手动初始密码不限制长度、复杂度或纯数字，但不能为空；编辑账号时留空仍保留原密码。
- 用户在“设置 → 我的账号”自行修改密码时，继续检查原密码和新密码强度；长度不足、常见密码、纯数字及与个人信息相似的提示全部使用中文。安装向导中管理员修改自己的密码仍保留强度要求。
- 扩展全页面验收至十一岗位及独立授权的经营报表身份，并增加初始密码的桌面、手机端回归用例。升级 CI 同时验证 classic 与 containerd 镜像存储。

## 升级说明

本版不新增数据库迁移，不重置已有账号密码。升级仍遵循先备份后迁移，镜像准备失败时不会停止现有应用或开始数据库迁移。管理员分配初始密码后，请通知用户登录并自行修改；本版未新增强制首次改密流程。

已知非阻断界面问题：BOM 采购草稿中极长、无空格的英文物料名在部分桌面宽度下可能挤压数量标签；本次未修改该布局。

## 📥 Installation

### Docker

下载 `atm-erp-v1.8.8-<platform>-docker.zip`，解压并进入目录。包内包含 GitHub 预构建的 amd64/arm64 镜像，校验后直接安装，不在本机构建。需 Docker Engine / Docker Desktop（Linux 容器）、Compose v2 和宿主机 Python 3.11。

```bash
# macOS / Linux
bash install.sh
```

```powershell
# Windows PowerShell
.\install.ps1
```

### One-line install (Linux · Docker)

在空目录执行，需已安装 Docker、Compose v2、Python 3.11、curl 和 unzip：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.8/atm-erp-v1.8.8-linux-docker.zip -o atm-erp-v1.8.8-linux-docker.zip && unzip atm-erp-v1.8.8-linux-docker.zip && (cd atm-erp-v1.8.8-linux-docker && bash install.sh)
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，全新安装的初始密码见安装目录 `.env.lean` 中的 `LEAN_ADMIN_PASSWORD`。首次登录的安装向导要求修改管理员密码，之后使用新密码。

### Manual download

从下方 **Assets** 下载对应安装包：平台为 `macos` / `linux` / `windows`，安装方式为 `docker` / `native`。原生包包含预编译依赖，环境要求见 Installation Guide。校验清单为 `atm-erp-v1.8.8-SHA256SUMS.txt`。
