# v1.8.10

## 本次更新

业务与数据（#84）：

- 经营报表：已取消项目不再计入已签约合同额；销售列表对已签约但项目已取消的单据标注“项目已取消”。
- 采购：关联 BOM 行时按单元校验用量，不能借用同物料其他单元的数量；缺料列表与可下单数量保持一致。
- 应付到期：指定日期账期只对已合格收货部分计入到期和逾期，报表、收付款状态、工作台与账龄口径一致。
- 物料：已被 BOM、采购或库存使用的物料不能改写单位、规格、图号和图档版本，原为空的可以补填。
- 项目编辑完整记录修改前后值，并同步名称、需求、交期等字段到销售单。
- 收付款、退款与银行流水日期不能晚于今天，冲销日期不能早于原流水。
- 领料会占用其他项目已到货、未领用物料时需确认，并记入审计。
- 过保售后可由项目经理写明原因后免费登记，不生成应收。
- 采购单可设置供应商质保月数（默认 12 个月），用于质保截止日与采购合同质保条款。
- 库位统一全半角和空格；收货首次使用新库位需确认，表单提供已用库位候选。

界面：

- 用户名等自由文本不再被误翻译，附件分类“结算凭证”显示正确，布尔列显示“是/否”。
- 操作审计显示操作人姓名，可按人员、操作、对象和日期筛选。
- 领料的售后任务按所选项目联动；附件大小按 B/KB/MB 显示；发货配套物料列出全部单元与 BOM 合计。
- 导出的负数不再带单引号，xlsx 中金额、数量为数值，可直接求和。

安全：

- 网页响应补全防嵌入、防类型嗅探和来源策略头，并启用内容安全策略（CSP，仅允许同源脚本）；Docker 与原生安装一致。
- 移除仓库中误提交的测试用 TLS 证书与私钥，并忽略密钥文件（#83）。

质量保障（#85）：

- 发版本强制全量验证；日常改动按模块自动选择关联的权限、并发、导入导出和页面回归，共享核心改动不再需要手动指定测试范围。

## 兼容与验证说明

本版包含前向数据库迁移 `0020_purchase_warranty_months`（采购单质保月数，默认 12），升级时随正常迁移执行，存量数据无需处理。行为变化：未收货的指定日期账期采购不再显示为逾期；收货首次使用新库位需勾选确认；领料占用其他项目到货需确认。新增的 CSP 只允许同源脚本，在反向代理上额外注入页面脚本的部署需相应调整。

PR #84 的按影响范围 CI、#85 的按影响范围 CI 与全量 CI 均已通过；#85 同时更新了两个在 #80、#84 后过时的浏览器用例。发布流水线在构建前对本版代码执行全量验证（后端全部阶段、前端单测、含完整业务链的桌面与移动端浏览器测试、OTA 与安装器），通过后才构建和发布附件。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.10-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.10/atm-erp-v1.8.10-linux-docker.zip -o atm-erp-v1.8.10-linux-docker.zip && unzip atm-erp-v1.8.10-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.10-SHA256SUMS.txt`。
