# v1.8.32

本版修复审查中标为优先处理的 10 个问题，涉及银行与结项、登录会话、安装与备份恢复。不新增业务功能。

## 本次更新

- **结项与银行导入不再互相卡死**：
  - 结项检查改为先锁银行账户、再锁流水，与银行导入、认领、退回的加锁顺序一致。此前两者同时进行时，数据库可能判定为死锁，让其中一方失败。
  - 项目页的「推进检查」改为只读，不再加锁，也不会因为有人在导入大文件而一直转圈。检查结果和提示与结项时相同。
- **锁账期间可以照常导入当期银行文件**：
  - 文件里的交易如果与锁账期内已经手工登记的流水是同一笔，系统保留原记录不动，计为跳过。预览时显示「已登记（锁账期内保留原记录，跳过）」。
  - 此前这种情况会让整批导入失败，提示「业务已锁账至…」且不说明是哪一行。
  - 期间重新打开后再导入，会照常为这些记录补上导入来源，不会产生重复记录。
- **多个标签页之间的登录保持一致**：
  - 其他标签页退出登录时，本页随之回到登录页。
  - 其他标签页换成另一个账号登录时，本页会重新载入为新账号。此前本页会继续显示原账号的菜单和权限，实际操作却记在新账号名下。
  - 同一账号的例行续期不会打扰其他标签页。
  - 换账号后，原页面上还没提交的操作会被拦下，并提示刷新后再继续。
- **已经成功的操作不再提示失败**：操作过程中登录状态发生变化（例如其他标签页退出）时，已经提交成功的操作照常显示成功。此前会提示「登录状态已变化，请重试」，容易让人重复提交。读取数据的请求仍会拦下并提示重试。
- **大文件不再提前超时**：附件上传、文件导入及其确认、导出和下载的等待时间从 25 秒延长到 5 分钟。此前网络较慢时，页面先提示失败，服务器其实已经处理完毕。
- **更正工时必须填写更正原因**：「更正原因」不再预先填入原工作内容。
- **安装与升级**：
  - 发布包安装时，新生成的配置文件 `LEAN_IMAGE` 留空，使用包内固定的镜像摘要。同时先检查宿主机 Python 3.11，再生成配置。此前安装中途失败时，配置会指向一个不存在的本地镜像，直接 `docker compose up -d` 也无法启动。
  - Windows 安装器：
    - 相对路径的 `-EnvFile` 不会再读写到不同的文件；
    - 在非 Windows 的 PowerShell 上，新配置文件权限限制为仅本人可读写；
    - 镜像校验或导入失败时给出准确提示；
    - `install-native.ps1` 支持 `-User`（重设其他账户密码）和 `-NoOta`。
  - README 新增「直接 Compose 部署手动升级」步骤：先停应用、完整备份，再在新目录启动。
- **备份记录程序版本，恢复前核对**：
  - 备份归档记录部署实际运行的程序版本。网页升级过的部署，记录的是升级后的版本。
  - 恢复时如果目标程序比备份旧，会在写入数据库和附件之前拒绝，并说明需要哪个版本。此前要等还原完成、应用启动时，才以「旧迁移历史」这种令人误解的提示拒绝。
  - 早期没有版本记录的备份照常恢复，不做核对。

## 升级说明

- 本版**没有数据库迁移**。升级沿用现有配置、数据库、附件与运行卷，按常规先完整备份再升级。
- 已有的配置文件不受影响。之前因安装中断而留下 `LEAN_IMAGE=atm-erp-lean:local` 的配置，重新运行安装器即可修正。
- 备份不包含 `lean_runtime` 卷（网页升级安装的程序与升级日志）。恢复时须准备不低于备份所记程序版本的发布包或镜像，详见 README「备份与恢复」。
- 接口方面：
  - 银行导入预览的行状态新增「已登记（锁账期内保留原记录，跳过）」；
  - 锁账期内的这类行，确认结果计入 `skipped`。
  
  其余调用方式不变。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.32-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.32/atm-erp-v1.8.32-linux-docker.zip -o atm-erp-v1.8.32-linux-docker.zip && unzip atm-erp-v1.8.32-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：
