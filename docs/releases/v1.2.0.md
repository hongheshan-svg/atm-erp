# v1.2.0 · ERP 版本检查与在线升级

- 管理员左上角新增版本入口，支持检查最新正式版本与查看更新内容。
- 可选宿主机执行器支持 Docker 和原生部署：校验安装包、停机备份、前向迁移、重启及目标版本健康验证。
- 升级任务保留审计、幂等控制和中断状态；拒绝降级及重复执行，迁移后失败不自动回退数据库。
- 修复原生 Nginx 非 root 临时目录权限，增加受控停止；升级弹窗适配桌面和移动端。

包含 macOS、Linux、Windows 的原生与 Docker 联网安装包以及 SHA256 校验文件。

安装与首次启用 OTA 的说明统一见 [README](https://github.com/hongheshan-svg/atm-erp/blob/v1.2.0/README.md)。v1.0.0/v1.1.0 原始版本需先手动升级到含 OTA 的版本；已有 Lean 数据库执行前向迁移，禁止旧 schema 混用。
