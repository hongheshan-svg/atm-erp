# v1.8.16

## 本次更新

- 管理员可逐条删除或勾选批量删除业务记录，项目内列表、BOM编制列表、销售与采购附件均提供入口。
- 删除前显示所选记录，必须填写原因并确认；BOM同时显示物料编码和单元，减少选错同物料不同单元的情况。
- 新增“已删除记录”，可核对操作人、时间、原因及删除时内容；项目及单据内的历史记录按所属范围筛选。
- 库存、资金、工时等历史流水仅移出默认列表，原始数据、余额、成本及业务关联保留。业务错误继续通过冲销、更正、退料等原有动作处理。
- 有关联的资料或未完成的业务会提示处理顺序；批量操作中任一记录不能删除，整批回滚。删除账号会停用登录，当前登录管理员不能删除自己。

## 兼容与验证

- 无数据库结构迁移，不清空数据；公司资料、编号规则、审计日志和只读报表不提供删除入口。
- 本地已验证相关业务、权限、并发、整批回滚、余额与成本保留，以及桌面和手机实际操作。
- 正式发布经过 Release 发版验证：全部后端阶段、前端单测及运维测试，浏览器按本版改动范围运行双视口；不含完整业务页面链。本版不涉及OTA运行机制或安装器变化。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.16-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.16/atm-erp-v1.8.16-linux-docker.zip -o atm-erp-v1.8.16-linux-docker.zip && unzip atm-erp-v1.8.16-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.16-SHA256SUMS.txt`。
