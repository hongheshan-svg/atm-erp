# v1.8.31

本版在「历史数据核查」中新增一个类别，用来找出 v1.8.30 之前已经登记成两条的同一笔华夏银行交易。不新增业务功能。

## 本次更新

- **历史数据核查新增「华夏流水号不同写法的同一笔」**（设置 → 历史数据核查，仅管理员，可导出）：
  - 把同账户、同一银行日期的核心流水号（如 `000123`）与「日期:核心流水号」（如 `2026-01-05:000123`）视为同一笔交易，列出被登记成多条的未作废银行流水。判断规则与 v1.8.30 起手工新建银行流水的查重相同。
  - 与原有的「疑似重复的银行记录」不同：这一类不比金额，录错金额的重复也能查到；同一天碰巧金额相同、流水号不同的另一笔交易不会被误列。
  - 每条注明对应的银行日期和核心流水号，并写明本条是否已认领、匹配或退回（含金额）。
  - 核心流水号在其他日期复用、出现在其他账户、已作废的记录，以及工行凭证号，都不会列入。
- **查到后的处理方式**（系统不会自动修改）：对照银行原始流水，只保留一条。
  - 误录且未使用的一条：直接「作废误录银行记录」。
  - 已认领或匹配的一条：先「撤销银行匹配」。如果它对应的收付款与保留那条重复计入，到收付款流水「冲销付款」；否则把它改为匹配到保留的那条。最后作废该条银行记录。
  - 只撤销匹配不会冲销收付款。v1.8.30 升级说明里「先撤销匹配再作废」的说法不完整，以本版为准。

## 升级说明

- 本版**没有数据库迁移**。升级沿用现有配置、数据库、附件与运行卷，按常规先完整备份再升级。
- 升级后建议管理员打开一次该类别核对历史数据。
- 接口方面：`GET /api/business/data-checks/` 新增类别 `bank-aliases`，类别计数从 5 个变为 6 个；其余字段与调用方式不变。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.31-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.31/atm-erp-v1.8.31-linux-docker.zip -o atm-erp-v1.8.31-linux-docker.zip && unzip atm-erp-v1.8.31-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.31-SHA256SUMS.txt`。
