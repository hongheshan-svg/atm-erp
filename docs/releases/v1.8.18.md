# v1.8.18

## 本次更新

- 采购增加“整单取消未收余量”：几十行物料只需填写一次原因，自动取消各行尚未收货的余量；同时保留按明细取消入口。
- 已收货的数量、库存及资金记录继续保留；存在待检隔离物料时提示先处理待检，避免误取消已到货部分。
- 收货和项目出库操作界面展示项目编号、产品编码、零件名称、图号/型号、版本/品牌、单位、需求数量和零件类型等资料；收货保留单元区分，方便逐行核对实物。
- 明细最后增加“备注”，每次收货、每次出库可分别填写并保存；库存流水和采购处理记录可追溯相应备注。
- 明细支持分页；电脑采用横向表格，手机按行显示资料和输入项，填写数量及备注更清楚。

## 兼容与验证

- 新增库存流水备注字段，升级执行前向数据库迁移；历史流水备注为空，原有数量、金额及权限规则保持。
- 本地已完成采购取消、收货、出库、备注保存、重复提交、权限拒绝和事务回滚测试，并完成桌面及手机实际操作验证。
- 正式发布由 Release 强制执行发版验证：全部后端阶段、前端单测、运维脚本测试、按改动范围选取的双视口页面检查，以及本次迁移触发的 OTA 升级演练。通过后构建并发布安装包。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.18-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.18/atm-erp-v1.8.18-linux-docker.zip -o atm-erp-v1.8.18-linux-docker.zip && unzip atm-erp-v1.8.18-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：
