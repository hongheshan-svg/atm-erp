# v1.8.27

## 本次更新

- **采购员在项目页 BOM 页签多看几行**：BOM 表格里，逾期行的“已逾期·缺料”等标记原来另起一行，现在放得下就紧跟在需求日期后面，逾期行不再占两行高。1366×768 下，项目页 BOM 页签采购员首屏从 4 行增至 7 行，BOM 页采购视图从 7 行增至 11 行，编制视图从 10 行增至 11 行。需求日期列比原来宽，单元列相应收窄；单元名放不下时显示省略号，鼠标悬停可看全名。“在途”列的“待批 N”也一样，放得下时跟在数字后面。
- **管理员批量删除时 BOM 表格不再左右滚动**：管理员开启批量删除后，采购缺料视图改用和编制视图相同的删除勾选：勾选后点表格上方的“批量删除（N）”，也可以“全选筛选结果”。采购勾选、“从 BOM 多选下单”选择条和行尾“删除”按钮在批量删除模式下收起，点“退出批量删除”后恢复。这样在 1280 宽下，即使出现“其他项目待领”列，表格也不再左右滚动（原来多出 46px）。

## 升级说明

- 本版只改前端，没有数据库迁移和接口变化，沿用现有配置、数据库、附件与运行卷；升级前仍请完整备份。
- 管理员在采购缺料视图里，原来可以点行尾“删除”逐条删除；现在改为勾选这一行，再点“批量删除（1）”。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.27-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.27/atm-erp-v1.8.27-linux-docker.zip -o atm-erp-v1.8.27-linux-docker.zip && unzip atm-erp-v1.8.27-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。
