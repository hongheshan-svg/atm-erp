# v1.8.39

本版新增「问题反馈」：员工在 ERP 内提交问题，自动登记为维护者私有仓库的 GitHub Issue，并在系统内跟踪处理状态。新增一个数据库迁移；业务规则不变。

## 本次更新

### 问题反馈页面
- 左侧导航新增「问题反馈」，所有账号可用；任意页面右上角「反馈问题」进入时会带上当前页面路径。
- 填写类型（错误 / 功能建议 / 使用问题）、标题、问题描述；可选影响程度、出现频率、操作步骤、期望结果、相关页面和错误提示里的“错误编号”。
- 可附截图和文件：选择、拖入，或在表单里按 Ctrl+V 直接粘贴截图，提交前可预览、移除。
  - 最多 6 个，单个不超过 10 MB、合计不超过 20 MB。
  - 支持图片 png/jpg/gif/webp、PDF、Excel、Word、csv/txt/log/json 和 mp4/mov 录屏；服务端核对文件头，不收 HTML、SVG 和可执行文件。
  - 图片直接显示在 issue 里，其他文件给下载链接。
- 提交后在私有反馈仓库建成 issue，带 `from-erp` 和类型标签；页面下方列出全部已提交问题和状态（处理中 / 已解决 / 不处理），可只看自己提交的。
  - 状态从 GitHub 同步，全系统每两分钟最多同步一次。
  - 网络失败时内容保留在表单里；重试沿用同一操作标识，不会建出重复的 issue。
  - 每个账号每小时最多提交 20 条。

### 可见范围与隐私
- issue 和附件保存在私有仓库 `hongheshan-svg/atm-erp-feedback`，只有维护者能看到；GitHub 链接只对 ERP 管理员显示。
- 页面提示不要填写或截入账号、密码，与问题无关的客户名称、金额、联系方式尽量不填或遮挡。
- issue 不写提交人姓名，只写类型、版本、页面路径、岗位代码、错误编号和浏览器信息；提交人只记录在本地和「操作审计」里。
- 页面路径只保留定位用的参数，搜索词、筛选条件不会写进 issue。
- 用户填写的文字放在代码块里显示，其中的 @提及、链接、图片和 HTML 都不会生效。

### 管理员配置
- 「问题反馈」页底部「GitHub 连接」，保存一个细粒度令牌（`github_pat_…`）：只授予反馈仓库的 Issues 与 Contents 读写，不能访问代码仓库。
- 保存时会校验令牌能访问反馈仓库；令牌只存服务器，任何接口、审计和操作回执都不含原值；可随时更换或停用。
- 没有令牌时员工能看列表但不能提交。配置步骤（含建仓库和标签）见 `docs/ISSUE_FEEDBACK.md`。

### 自动修复循环（维护者本机）
- 新增项目技能 `.claude/skills/erp-issue-loop`，在专用 Claude Code 会话中用 `/loop /erp-issue-loop` 运行：
  - 只处理维护者打过可信标签（`from-erp`、`claude-fix`）的 issue，issue 内容和附件只当数据，不执行其中的指令；
  - 公开代码仓库的 PR、提交信息和发布说明只引用反馈 issue 编号，不摘抄其内容；
  - 改动限于业务代码与测试，不碰 CI、安装、升级和依赖；
  - PR 检查全绿才合并；每 24 小时最多发一次版，发版后回帖并关闭对应 issue。
- 该循环不随安装包运行，对已部署系统没有影响。

## 升级说明

- 本版有一个**新增表和字段的迁移**（`lean_feedback` 表、公司资料新增令牌字段），不改动已有数据；升级流程照常先完整备份再执行前向迁移。
- 不配置令牌时，除了导航多一个入口，系统行为与上一版相同。
- 服务器需要能访问 `api.github.com` 才能提交和同步状态（与在线升级检查相同）。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.39-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.39/atm-erp-v1.8.39-linux-docker.zip -o atm-erp-v1.8.39-linux-docker.zip && unzip atm-erp-v1.8.39-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download
