# v1.8.34

本版处理审查清单中需要取舍的 20 项，按负责人的决定统一权限口径、提示和勾选行为，不新增业务功能。

## 本次更新

### 权限与可见范围
- **库存金额按岗位收紧**：
  - 现有库存的金额，以及期初、盘点这类不属于任何项目的库存流水金额，只对以下人员显示：管理员、财务、采购员、采购经理，以及开通了经营报表的总经理。
  - 普通项目经理和仓管不再看到这些金额，导出时也不含「库存金额」列。项目经理仍能看到本人负责或参与项目的金额。
  - 此前库存不归属项目，任何项目经理都能看到全公司的库存金额，并由此推算其他项目的采购单价。
- **采购合同预览**：仓管不再看到「预览采购合同」入口；直接打开合同链接会回到工作台。此前页面能打开，但随后被服务器拒绝。
- **上传附件选项目**：已取消的项目只能上传结算凭证，选择其他分类时不再列出，与服务器规则一致。
- **导入时的项目编号**：编号不存在和无权访问统一提示「记录不存在或不在你的权限范围内」，不再透露其他项目编号是否存在。

### 任务与工时
- **工作台「生产与售后派工」**：点开后列出参与项目里的装配、调试、安装、售后任务，不再只显示分配给本人的任务，与卡片上的数字一致。页面上方有「查看全部类型任务」可以去掉类型筛选。
- **从提醒打开任务**：「查看并处理」打开的详情与在列表里点开同一份，并高亮该行；有未保存的表单时先确认是否放弃。
- **工时代录入口**：判断是否显示时只看执行中、交付中、质保期的项目，不再因为排在前面的是未开工项目的任务而隐藏入口。
- **人员已停用时**：发货填写安装人、验收人，或重新打开原执行人已停用的任务时，提示显示在对应字段上，并说明人员已停用。此前提示「找不到」。

### 采购
- **修改采购草稿不能超出缺口**：关联 BOM 的明细调增数量时，不能超过当前缺口（扣除库存里可用的数量），与按缺料下单同一口径。只改单价、交期或调减数量不受影响。
- **超预算批准的审计记录**：管理员作为预算调整人、以例外身份批准超预算采购时，审计记录同样标明「预算调整人批准」。

### 删除与勾选
- **删除附件需要勾选确认**：与删除业务记录一致，先填写原因、勾选「我已核对所选附件」，再点确认删除。
- **附件跨页勾选**：翻到没有可删附件的一页时，勾选列和「删除所选」不再消失。
- **物料删除**：只被已移除的 BOM 明细引用的物料，管理员也不能删除，提示中会说明是「已移除的BOM明细」。
- **勾选保留规则统一**：
  - 领料、BOM 多选下单的勾选，跨页、换搜索或筛选都保留，可以边搜边勾再一起提交。
  - BOM 页保存后不再清空多选下单的勾选，只去掉已经不缺料或不存在的行；下单成功后清空，避免重复下单。
  - 批量删除和批量修订的勾选，在换搜索、筛选或项目时清空；BOM 页的「逾期」「含未审批」筛选也纳入其中。
- **BOM 页留在原页**：改了一行或删了几行后停留在当前页（超出末页时退到最后一页），不再跳回第 1 页。

### 其他
- 任务工时明细改用与其他列表相同的分页，每页条数随全局设置。
- 供应商月度对账的供应商改为输入搜索选择，不再每次打开都下载全部往来单位；已停用的供应商仍可选择。
- 调整任务计划日期或改派时不再重算项目里程碑，减少不必要的数据库加锁。

## 升级说明

- 本版**没有数据库迁移**。升级沿用现有配置、数据库、附件与运行卷，按常规先完整备份再升级。
- 接口方面：
  - 用户新增、修改和公司信息修改与业务写入一样，必须带 `Idempotency-Key`；同一标识的重试返回首次结果，同一标识配不同数据返回 409，缺少时返回 400。本系统前端已自动携带，自行调用接口的脚本需要补上。
  - 未登录的请求返回 401（此前部分接口返回 403），包括不带登录凭据直接打开附件下载地址。
  - 移除未使用的 `bank-matches/{id}/reverse/`，取消匹配统一用 `bank-records/{id}/unmatch/`。
  - 对账单列表不再返回 `snapshot`，详情和导出保留。
  - 任务列表新增筛选：`project_open=true` 只列执行中、交付中、质保期项目的任务；`kind__in` 可按多个任务类型筛选。
  - 库存与库存流水的 `value`、`supplier_credit` 按上文的库存金额口径返回。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.34-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.34/atm-erp-v1.8.34-linux-docker.zip -o atm-erp-v1.8.34-linux-docker.zip && unzip atm-erp-v1.8.34-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：
