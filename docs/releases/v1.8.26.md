# v1.8.26

## 本次更新

- **BOM 首屏多看几行**：在 1366×768 下，BOM 页编制视图首屏从 5 行增至 10 行，采购视图从 2 行增至 7 行（已扣除底部选择条），项目页 BOM 页签增至 5～8 行。页面标题、说明和项目筛选合成一行，编制/采购切换与工具栏放在同一行；视图说明收进切换按钮旁的“?”提示，“展开完整列”移到“导出”旁边。表格行距和数量列收窄，单元名不再换行，1366 宽下“缺料”列完整可见。
- **采购导入可填超 BOM 原因**：导入模板末尾新增“超 BOM 采购原因”列。同一分组号里任一行填写即可，通常写在超出的那一行；几行写了不同原因时合并保存。没填原因时，预览会定位到这一列并写明超出数量。旧模板（没有这一列）仍可导入。
- **缺料项目直达选料**：工作台“缺料待采购项目”点进去，直接打开该项目 BOM 的采购缺料视图，默认只看缺料，勾选后“从 BOM 多选下单”。
- **发货时提示应收**：发货对话框的“应收状态”逐条列出本项目未收的应收款项、金额和到期日，已逾期的会标出。发货成功后再提醒一次，如合同约定发货后付款，请通知财务调整到期日。只提示，不拦截发货；金额只对能看项目金额的角色显示。

## 升级说明

- 本版没有数据库迁移，沿用现有配置、数据库、附件与运行卷；升级前仍请完整备份。
- v1.8.25 发布说明中“采购导入暂不支持原因列，超出缺口的行会被拒绝”的限制，本版已解除。请重新下载采购导入模板，以获得新列和填写说明。
- 发货规则和权限不变；发货接口成功响应新增只读字段 `receivables`，只对能看金额的角色返回。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.26-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.26/atm-erp-v1.8.26-linux-docker.zip -o atm-erp-v1.8.26-linux-docker.zip && unzip atm-erp-v1.8.26-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download
