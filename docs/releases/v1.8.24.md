# v1.8.24

## 本次更新

- **实际日期与任务历时**：任务统一显示计划完成日期，新增实际开始、实际完成日期、自然日历时和提前/延期天数；支持开始任务及历史日期补录、更正，保留修改记录。
- **工时提交后可核对**：保存后明确显示人员、工作日期和小时数；任务列表及详情显示累计净工时，可查看本人/全部明细、冲销与更正记录。
- **专业主管统一确认**：项目内设置机械、电气、采购、生产、交付与验收主管；由负责主管或有权限的项目经理统一确认任务、按人员和日期登记实际小时数，普通员工查看进度。未设置主管时由项目经理代管。
- **站内提醒直达任务**：分配、调整任务或更换负责主管后发送站内提醒，工作台显示未读提醒与待确认任务，点击即可进入处理。

## 升级说明

- 本版改变任务完成与工时录入权限：原执行人不再仅凭执行人身份直接完成或自录；升级后请由项目经理进入“项目 → 任务与工时 → 设置专业主管”确认分工。现有记录保留，无需重新建任务。
- 任务历时只用于进度分析，不自动折算工时或人工成本；人工成本继续依据实际人员的小时数及费率快照。日期与工时修改分别留痕。
- 正向迁移0024～0026新增实际日期、专业归属和站内提醒；未知历史实际日期保持空值，历史工时不改写，不补造历史提醒。主管授权不扩大派工、BOM、发货验收、预算、资金及完整成本权限。
- 自动汇总节点仍依据实际发货、安装、验收记录同步。升级沿用现有配置、数据库、附件与运行卷，先完整备份再前向迁移。
- 本版不包含尚在核对的ECN表格物料重复问题修复。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.24-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.24/atm-erp-v1.8.24-linux-docker.zip -o atm-erp-v1.8.24-linux-docker.zip && unzip atm-erp-v1.8.24-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。
