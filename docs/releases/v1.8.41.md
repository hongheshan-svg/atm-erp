# v1.8.41

本版放宽 BOM 导入里三条让非标设备 BOM 整份导不进去的规则，并把系统替人做的处理列在预览里供核对。没有数据库迁移。

## 本次更新

### BOM 导入：重复行合并数量
- 以前同一文件里同一物料在同一单元出现多次（单元留空也算同一单元），每个重复行都报「物料编码和单元不能重复」，整批不能导入。设计按工位、气路列料时这是常态。
- 现在重复行的数量并入首次出现的那一行，预览在「变更」列标明「并入第 N 行」和合计数量。新增、修改还是不变，按合计数量判断；变更说明和申请信息取先填写的值。
- 不同单元的同一物料仍是各自独立的行。

### BOM 导入：同规格、同品牌、同单位的物料直接复用
- 以前文件里的物料与已有物料规格、品牌、单位相同而名称等略有不同（如「拉手」与「把手」）时，系统要求先到基础资料填写独立建码原因，但导入表里没有地方填，这一行无法处理。
- 现在按同一物料复用，「物料处理方式」显示「按型号复用已有物料」并列出系统里的名称。系统里有多个匹配时仍要求填写编码。
- 例外：名称不同、且品牌栏填的是购买渠道（淘宝、天猫、京东、拼多多、1688、外购、市购、国产等）时不自动复用。这类物料的规格多是通用尺寸，同规格可能是不同零件。提示会给出两种处理：是同一物料就填写对方的编码，不是就把规格写完整。

### BOM 导入：填了编码但资料与系统不同
- 以前填了已有编码后，名称、品牌、单位、类别只要与系统有一处不同就整行拒绝，必须把后面八列清空。
- 现在这些差异只提示，按系统资料使用，不覆盖主数据。规格或图号与系统不同仍然拒绝，因为多半是编码填错；提示里写明系统中该编码是什么物料，以及怎么改。
- 原来为空的品牌仍按文件补填。

### 预览里的「请核对」清单
- 上面三种自动处理都不拦导入，预览新增一个「请核对 N 条自动处理」清单，逐条写明行号和处理内容；汇总行增加合并行数。确认前请逐条看一遍，尤其是合并的数量是独立用量还是重复粘贴。
- 确认提示里的「新建物料 N 个」改为按物料计数，不再按行重复计。
- 模板填写说明、页面帮助和文档同步更新。

## 升级说明

- 没有数据库迁移，没有配置变化。
- 已下载的旧模板仍可使用；模板「填写说明」页里「重复不能导入」的旧说明以本版为准。
- 接口：导入预览的行新增 `material_hint`、`merged_rows`、`merged_into`，`bom_action` 新增取值 `merged`，`summary` 新增 `merged` 和 `new_materials`。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.41-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.41/atm-erp-v1.8.41-linux-docker.zip -o atm-erp-v1.8.41-linux-docker.zip && unzip atm-erp-v1.8.41-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。

### Manual download

从下方 **Assets** 下载适合平台的安装包：

- 平台：`macos` / `linux` / `windows`。
- 安装方式：`docker` / `native`；原生包包含预编译依赖，运行环境与安装步骤见 Installation Guide。
- SHA256 校验清单：`atm-erp-v1.8.41-SHA256SUMS.txt`。
