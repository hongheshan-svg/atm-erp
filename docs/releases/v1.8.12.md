# v1.8.12

## 本次更新

- 业务按姓名操作：负责人、执行人、项目成员、工时人员、安装人和验收人的导入均支持姓名、登录账号或“姓名（用户名）”。例如用户名为 `wuxingguang`，可以直接填写“吴兴广”。
- 重名保护：姓名重名（含停用人员）或与他人账号冲突时，不自动选择人员，提示填写“姓名（用户名）”明确对象；停用人员仍禁止使用。
- 人员选择：业务下拉框显示“姓名（账号）”，便于区分同名员工，保存时仍关联稳定的人员记录。
- 模板说明：人员列统一标为“姓名或账号”，同步更新Excel填写说明、表头提示和可下载说明文档；项目多个成员支持中文或英文分号分隔。
- 确认保护：导入预览记录对应人员，确认时重新核对；期间人员对应关系变化则要求重新预览，避免误派任务。

## 兼容与验证说明

本版没有数据库结构迁移。原登录账号、旧模板表头与列顺序继续兼容；岗位权限、销售归属、项目范围、整批回滚和重复确认保护继续生效。姓名需与人员资料一致，不按简称或模糊拼音猜测。

## 📥 Installation

### Docker

下载下方对应平台的 `atm-erp-v1.8.12-<platform>-docker.zip`，解压并进入目录。仅需 Docker Engine / Docker Desktop（Linux 容器）与 Compose v2。包内 Compose 固定该版预构建多架构镜像摘要，不在本机构建。全新部署复制配置并填写随机密钥后启动：

```bash
# macOS / Linux
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写数据库密码、SECRET_KEY 和管理员初始密码
docker compose up -d
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
# 编辑 .env 后
docker compose up -d
```

### Download (Linux · Docker)

在空目录下载并解压，再按上方步骤配置和启动；不要覆盖已有配置：

```bash
curl -fL https://github.com/hongheshan-svg/atm-erp/releases/download/v1.8.12/atm-erp-v1.8.12-linux-docker.zip -o atm-erp-v1.8.12-linux-docker.zip && unzip atm-erp-v1.8.12-linux-docker.zip
```

安装后默认访问 `http://127.0.0.1:8080/erp/`，用户名 `admin`，初始密码为 `.env` 的 `LEAN_ADMIN_PASSWORD`，首次向导要求修改。已有 `.env.lean` 的部署显式使用 `--env-file .env.lean`，不要新建配置替代。新版 Docker up 后默认接入容器内网页升级，无需宿主机执行器或 docker.sock；须保留 lean_runtime 卷。兼容范围、恢复及原生 Linux systemd 安装见 README。
