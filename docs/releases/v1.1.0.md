# v1.1.0 · Lean ERP 经营管控与业务完善

面向约50人的非标自动化企业，继续使用固定六角色和原业务事实，不增加可配置审批流、权限树或会计模块。

## 新增与完善

- 材料、人工、费用预算，实际与在途成本比较，超预算采购复核与职责分离。
- 剩余材料、人工及费用完工估算，估算人员、时间与复核提醒；成本来源明细追溯。
- 管理员与单独授权总经理经营报表，风险筛选、金额追溯和紧凑分页。
- 编号规则配置，业务CSV/XLSX导入导出及服务端预览、确认和权限校验。
- 同料多单元BOM，按品牌、单元及标准件/非标件多选采购，变更影响预览。
- 采购退回修改、明细交期、独立付款期限、到货隔离及复检/退回处理。
- 合同补充协议、差额应收与退款；收付款银行信息、后补凭证及鉴权下载。
- 分批交付配套清单与快照，退料保护已交付用量。
- 工作台直接办理、分页和筛选记忆、桌面表格优化、移动抽屉导航与金额摘要。
- 备份完整性、磁盘和健康检查脚本，以及恢复演练与企业试运行规程。

## 安装与升级

使用install.sh或install.ps1；生产保持默认`LEAN_ENVIRONMENT=production`，开启登录限流。development只用于隔离开发测试，DEBUG仍默认关闭。

已有v1.0.0 Lean数据库升级前先备份数据库及附件，验证恢复后使用新代码重新运行安装器，正常执行前向迁移。保留原单据和金额流水；禁止绕过schema guard、清库或将旧镜像直接连接新schema。早期非Lean数据库仍不兼容。

历史采购未填独立付款期限时沿用原交期；历史交付无快照时保留比例规则。缺少剩余材料估算的项目显示未完整估算，不将缺省值视为零。共享库存不作项目预留，估算不替代实际成本或法定会计账。

## 验证

本地后端162项、前端26项及桌面/移动浏览器20项覆盖通过。隔离恢复30张表和57个附件一致，非空库保护及重复安装通过。远端CI结果以发布提交对应的GitHub Actions为准。

企业脱敏真实订单试运行、实际主机告警接收渠道仍需企业配置。详见docs/OPERATIONAL_REVIEW_REMEDIATION.md及docs/OPERATIONS_AND_PILOT.md。
