# 附件在线预览

在销售、采购、项目等页面打开附件，点击文件名或“预览”，即可在系统中查看。仍需编辑、打印完整原稿或保存到电脑时，点击“下载原文件”。

## 在哪里可以用

- 销售附件、采购附件、项目附件以及单据详情侧栏。
- 表单中已经选中或刚上传的附件。
- 收付款凭证、补录凭证记录、补充协议和对账附件。
- 采购合同中已经归档的签署文件。

## 各种文件怎么查看

| 文件 | 操作与说明 |
| --- | --- |
| Excel（XLSX、XLS）和CSV | 选择“工作表”，使用“上一页内容”“下一页内容”翻页，或选择页码。可按物料、型号等查找当前页；查找其他页需先翻页。左右滚动查看更多列，行号对应原表行号。 |
| PDF | 可逐页查看、放大缩小；扫描件按图片显示。有文字的PDF还可点击“查看本页文字”复制内容。 |
| 图片（PNG、JPG、JPEG、GIF、WebP、BMP） | 可放大缩小，“适合窗口”恢复宽度。 |
| Word（DOCX） | 查看正文段落与表格，长文档可以翻页。 |
| TXT | 直接查看文字；支持常见中文编码。 |
| 其他格式，如DOC、DWG、压缩包 | 页面会说明暂不支持，请下载查看，或请上传人从原软件导出PDF后上传。 |

Excel和Word预览用于快速核对文字与数据，不还原合并单元格、图表、图片和完整原稿排版。需要核对盖章、图纸或打印版式时，优先上传PDF。

Excel公式仅显示原文件已经保存的计算结果。若提示公式尚未计算或结果不完整，请上传人在Excel或WPS中重新计算并保存后上传；预览不会自动更新公式或外部数据。

## 没显示完整时怎么办

- 正在读取：稍候；读取失败可以点“重试预览”。
- 内容太多：表格最多预览前10000行、100列，每页100行；Word最多5000个正文段落或表格，单个表格最多100行、100列；过长文字会提示截断。需要完整内容请下载原文件。
- 文件损坏或加密：请上传人重新保存，或提供未加密的PDF。不要仅修改文件扩展名。
- 没有权限或文件不存在：请联系项目负责人或管理员核对附件归属和访问范围。

预览不会修改原文件，也不会触发导入。文件保留在公司系统中，无须上传到外部在线文档网站。
