# 50 人非标自动化公司 ERP 范围

本轮新增的固定业务管控、月度对账、采购质保、锁账和合同归档范围见 [OPERATIONAL_HARDENING.md](OPERATIONAL_HARDENING.md)，对应接口以 LEAN_REBUILD_CONTRACT.md 的本轮补充为准。

本版面向全新安装，围绕项目完成销售到交付售后。保留工作台、经营报表、销售、项目、BOM、采购、库存、收付款、基础资料和设置十个入口，按账号授权显示。

一个账号可兼任多个固定岗位，菜单与动作按业务权限合并；销售负责人范围、项目成员范围、金额过滤、按人员执行的审批约束及经营报表单独授权继续保留。沿用七种固定角色，不增加角色表或可配置权限树，已有单角色账号保持原权限。

## 必须跑通的业务链

1. 维护物料、客户与供应商，管理员建立七种固定角色的账户。
2. 销售录入需求与设备数量，报价后签约；通过项目服务生成执行项目、通过收付款服务生成应收，节点总额必须等于合同金额。项目也可独立创建，不要求先建销售。
3. 设计、装配、调试按顺序完成；项目成员记录工时。BOM 可逐行维护或通过 CSV/XLSX 预览导入，变更校验版本及已领料、在途数量。
4. 按缺料生成采购，采购员提交，经理批准后产生唯一应付；仓库支持分次收货、领料、退料、采购退货和盘点。
   供应商默认采购账期带入新单，可选择现付、月结30/60/90/120天、自定义月结天数或指定日期。月结按每批合格收货当月月底加自然日计算，跨月分别到期；原批次退货和净付款抵扣复用原资金、库存事实，不增加应付分账。
   BOM采购支持按品牌、功能单元及标准件/非标件组合筛选后多选下单；品牌/类别只在物料维护，单元只在项目BOM维护。同项目同物料可分属多个单元，每个单元一行；领料按物料总量校验；多单元交付提供本批配套清单并保留快照，库存共享且不预留。
5. 支持分批发货、安装与验收，每批数量不得超过合同设备数量，发货前校验生产任务和对应物料投入。
6. 验收后按批次保修期处理免费或收费售后，关联任务、领料、工时与应收。
7. 财务登记收付款、退款、费用与冲销，结项前检查所有任务、采购及收付余额；允许有审计记录的重新打开和纠错。
8. 成本来自实际领退料、工时快照和费用，采购退货价差单独展示；全部为 CNY 含税经营口径，不替代法定会计账。
9. 项目维护材料、人工、费用预算，对照实际成本及已批准在途采购；累计采购净额另检查材料预算。超预算采购由经理或管理员明确说明原因批准，保留快照，不增加可配置审批流或项目专属库存。
10. 管理员和单独授权的总经理可查看固定经营报表，按项目状态、名称及风险筛选，查看累计合同、成本、承诺、收付余额和预算/交付风险。数据复用既有业务投影，不新增报表台账或自定义报表构建器。
11. 业务列表支持 CSV/XLSX 导出全部筛选结果。物料、往来单位、销售草稿、执行项目、采购草稿、任务、期初库存、领料、费用、正常收付款、工时和发货支持模板、预览和整批确认导入；BOM 继续沿用版本校验导入。导入只调用原业务服务，不覆盖现有记录、不绕过签约审批或直接导入派生余额。

12. 工程变更先查看需求、已领、在途和受影响采购；按原单取消余量、隔离品处理、退回未用材料后修订BOM。采购可退回草稿修改，承诺到货日期按明细维护并提示逾期；不合格到货隔离于可用库存，经复检合格入库或退回供应商。隔离退回不自动取消补货与应付，需要取消余量时由采购明确操作。
13. 补充协议关联合同附件、保留原签约金额和不可变协议记录，增额新增应收，减额抵减指定合同款并保留退款余额。已发货后不改变设备总数和领料比例；质保修改仅影响后续批次。收付款可记录方式、账户标识、银行流水号和同项目结算凭证；后补凭证追加不可变关联及原因，不覆盖原流水。采购可独立设置付款到期日。
14. 项目经理维护剩余材料、人工和费用估算，单独展示预计完工成本，不计入实际账；剩余材料涵盖尚未领用及未下单需求，并排除已计入实际和在途部分。缺任一估算不显示完整预测，展示估算人、时间和复核提醒。预算调整人不得自行批准超额采购，其他经理可以复核，管理员例外也必须说明原因。共享库存不保证项目齐套，不新增库存预留机制。

销售和采购单提供独立附件入口，支持未签约销售上传合同、报价及技术资料；项目按原单据关联汇总文件。销售经理仅访问本人销售附件，采购附件不向销售经理、仓库或普通成员开放；复用统一受保护文件存储和鉴权下载。

15. 收付款内提供轻量业务对账与银行核对。采购普通付款受已收货净额及已确认对账额度约束；未收货预付款须提供合同依据，由经理或管理员核准。退款须先核对原款项及抵减余额。客户实际到账不因未对账而拒绝登记，未知或多汇款可先登记为银行待认领记录，认领复用原收付款服务；已登记款项只做银行匹配，不重复记账。对账保留快照、确认人与附件，源业务变化使未使用授权失效；差异回原业务处理，不另建可编辑应收应付。项目结项要求相关待确认对账及关联银行未匹配款处理完；完全未知项目的银行记录保留全局待办，不阻断所有无关项目。未认领错汇/多汇可关联真实银行退款，保留不可变关联及撤销历史，不伪造合同或费用。

## 删除范围

按用户新增要求，左上角提供管理员专用 ERP 版本检查与升级入口。仅检查固定 GitHub 仓库正式版本，通过可选宿主机执行器完成包校验、备份、前向安装及健康检查，不增加设备固件管理或通用远程命令功能。应用容器不持有 Docker socket。

删除 CRM 漏斗、OA/考勤/车辆、复杂 MES/APS、可配置审批流和权限树、BI/报表构建器、AI、复杂会计/税务/资产、委外门户、小程序、WebSocket、Celery、旧通用升级代理及旧部署入口。设计、装配、调试以项目任务保留，不另建生产系统。

## 数据与权限边界

固定 admin、manager、sales_manager、purchaser、warehouse、finance、member 七角色。销售经理只读写本人负责的销售订单，可维护共享纯客户资料、读取兼作供应商的客户，但不能维护供应商。交付和应收回款通过销售单只读投影，不能访问完整项目、采购、库存、成本或财务记账。签约时独立指定管理员或项目经理负责执行；补充协议由现有项目经理/管理员处理。后端强制授权，普通成员仅能访问所属项目；合同、财务与成本金额按角色过滤。附件仅走鉴权下载。

总经理使用 manager 角色账号，并由管理员在用户设置中开启 management_reports；该开关只授予经营报表读取能力，默认关闭，普通项目经理和财务不能查看该页面。管理员自动具有报表权限，授权及撤销记录审计。

业务事实只维护一处。金额和库存通过事务与锁校验，业务写操作使用 Idempotency-Key 防重复。纠错通过冲销、退货及审计保存历史，禁止物理删除金额流水。

新表使用 lean_ 前缀与代际标识，只接受空库或当前版本数据库；检测到旧表或旧迁移立即拒绝。禁止清空或迁移旧业务库来适配新系统。

## 验收

首次安装提供管理员网页配置向导：初始密码更换、公司资料、可选人员兼岗、编号默认或自定义、原子确认启用。现有系统升级不重新初始化；不扩展为云账号注册、权限引擎或自动造业务数据。

后端平台、完整业务链和 PostgreSQL 并发测试；前端 lint、类型、行为测试和构建；七角色真实浏览器业务链，包含销售经理到项目经理的签约交接及结项回款查询；全新三服务安装、私有附件下载、备份恢复及重复安装验证。每项证据写入 SIMPLIFICATION_EVIDENCE.md，缺项不得宣布完成。
