按新增要求使用十一个固定岗位及原业务事实，职责见 [ROLE_RESPONSIBILITIES.md](ROLE_RESPONSIBILITIES.md)；不引入权限树、可配置审批流或第二套资金/库存账。

| 评审项 | 实现与入口 | 验证重点 |
| --- | --- | --- |
| 审批隔离 | 采购创建人/最后提交人、预付申请人不能自批；管理员例外须原因及审计 | 兼岗不能绕过，拒绝无业务写入 |
| 项目范围 | 经理限负责/参与项目；兼任采购/仓库/财务沿用全局作业范围 | 列表、详情、导出、附件、待办及重放授权 |
| 角色选择 | 设置中勾选岗位，显示新增/移除及影响 | 键盘操作，至少一个岗位，保存回显 |
| 锁账 | 公司资料“锁账与重开” | 截止日期、版本校验、变更原因和事务锁 |
| 合同版本 | 采购预览中归档签署附件与主体/明细/条款快照 | 历史版本不被公司或物料修改覆盖 |
| 整套打印 | 正文与完整附件一起输出 | 单页正文、分页附件及长文本 |
| 月度对账 | 收付款独立页签，供应商跨项目月度汇总 | 期初＋合格收货－退货－净付款＝期末，复用原付款授权 |
| 物料防重 | 相似项提示，全半角/空白规范化，重复独立编码需原因 | 自定义编码、导入事务与历史保持 |
| 采购质保 | 原批次登记/处理/查看，引用真实退换货和费用 | 一年质保提示、数量约束、不重复入账 |
| 异常指引 | 冲突提供原单入口和具体处理要求 | 不将失败当成功，不直接改派生余额 |
| 经营关注 | 未来30天资金、账龄、采购逾期、90天未动库存 | 固定只读、分页、明确口径 |
| 实施运维 | 备份周期脚本、异地复核、期初切换签认表 | 状态文件与失败退出码，隔离恢复及企业现场签认分开 |

## 明确边界

- 锁账为业务截止保护，不替代会计结账。费用按现有创建日期入账，不将付款到期日当费用发生日；旧期间款项抵减需重开。仅能锁至昨天，重开保留审计。
- 兼任全局作业岗位只扩展该岗位动作的范围，不把财务或仓库的全局读取范围变为经理的全局审批权。经理审批、预算和项目管理仍限负责或参与项目，管理员除外。
- 签署附件仍鉴权下载；操作人勾选核对声明不等于电子签章认证。归档保留条款文本和模板版本，未来模板变更须保留旧版渲染行为。
- 月度单不把未到货合同额计入期末。其他业务变化后原授权失效；单供应商最多200笔应付，更多时从原应付分批核对。有跨单预付负余额时只记录核对，不自动跨采购单抵扣或新增付款授权；财务按原单确认处理方式。
- 质保事项不自动生成免费换货库存；收退货仍执行原库存业务，费用关联原费用单。已完结再次故障登记新事项。
- 90天未动仅为呆滞候选，不推断减值。未来资金只含已有到期事实，不含未签合同或未收货月结的日期预测。
- `backup_cycle.py` 用于 Docker 的现有主机调度，原生安装按 README 及宿主机规程备份。生产目录、异地挂载、告警接收方式未提供，未安装生产调度或发送告警。
- 用户明确表示企业项目、人员和生产信息后续提供。模拟数据和自动测试不能替代企业现场签认；待填表见 OPERATIONS_AND_PILOT.md。
