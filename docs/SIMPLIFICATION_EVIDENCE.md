## 验证中修复的实际问题

- 原始表单标签包含下拉选项文字：显式设置控件可访问名称。
- 项目状态控制新增入口时，Vue 将未传入的布尔参数默认设为 false：明确默认 true，并用真实组件回归验证角色和状态控制。
- 自定义镜像标签未持久化，维护命令可能转用默认镜像：安装配置保存 LEAN_IMAGE；备份预检镜像、禁止隐式拉取，并用 start 恢复原容器。备份完成前验证附件 tar 可读，恢复前校验哈希与路径。
