# 导入模板填写说明

适用于系统提供的全部13类导入模板。请从需要办理的业务页面重新下载模板，不要把项目、任务、BOM或列表导出的文件混用。

## 说明在哪里

- **Excel模板**：包含“数据”和“填写说明”两个工作表，打开后先显示“填写说明”。先看“①先准备、②最少填什么”，点击蓝色“开始填写”跳到数据页第2行；一行一条，不改表头。说明页提供用途、上传入口、每列必填条件、资料查找位置、允许值和格式示例。把鼠标移到数据页表头，也可以查看该列提示。
- **独立说明文档**：在下载模板旁点击“下载填写说明”。文档可用浏览器打开、打印或转发，内容与Excel说明一致。
- **CSV模板**：只包含数据表头，无法携带说明页；请把独立说明文档一起发给填写人员。
- **页面说明**：通用导入窗口先显示准备资料和最少填写内容；“模板字段与页面列对应说明”中也能查看必填条件、资料来源、规则和示例。

下载文件以中文业务名命名，例如“项目任务导入模板.xlsx”“BOM导入填写说明.html”。先核对文件名和当前页面，再开始填写。每份说明都有对应业务场景的例子，例如采购多种物料如何分组合单、BOM已有物料和新物料分别填哪些列。

示例仅说明格式，示例中的姓名、账号、编码和ID不代表系统已存在这些记录。必须换成实际业务值。说明页不会导入，数据页不预填示例，避免误生成业务记录。

## 各模板的用途与注意事项

| 模板 | 用途 | 填写前先确认 |
| --- | --- | --- |
| 物料 | 新增基础物料 | 自定义编码不能重复；留空自动编号。填写产品编码类别时须填规格，有图产品还须填图号。确需对相同物料独立建码时说明原因。 |
| 往来单位 | 新增客户、供应商或双用途单位 | 类型填“客户”“供应商”“客户及供应商”。采购账期只适用于供应商，纯客户留空或填“指定日期”。 |
| 销售 | 新增销售草稿 | 客户编码和负责人姓名或登录账号必须有效。导入不代替报价、签约；仅销售经理权限时负责人填本人。 |
| 项目 | 新增执行项目 | 项目负责人须具备管理员或项目经理岗位。已签约销售应从销售签约生成项目，避免重复建立。 |
| 项目任务 | 新增设计、装配、调试任务 | 阶段填中文选项，不填T0～T3。“期限”是截止日期，不是天数。执行人填姓名或登录账号，并须属于项目范围。采购、发货不作为此模板的阶段。 |
| BOM | 导入项目物料需求，可同步新建物料 | 已有物料填系统编码；新物料编码留空并填写名称、规格、产品编码类别、单位，有图产品另填图号。同料同单元不能重复。 |
| 采购 | 按分组新增采购草稿 | 同组表头信息一致、物料不重复，数量与含税单价分列。导入后仍需审批。需要关联BOM单元时使用“从BOM多选下单”。 |
| 期初库存 | 管理员录入上线期初 | 物料和库位不得已有库存历史。数量填正数，单位成本不填成库存总金额；已有库存通过盘点调整。 |
| 项目领料 | 从现有库存领给项目 | 库存ID对应具体物料与库位，不是物料编码；数量受库存和BOM需求限制。已验收项目须关联未完成售后任务。 |
| 项目费用 | 新增费用待付款项 | 填项目编号、费用名称、正金额和付款到期日；合同应收、采购应付由原单据生成，不能重复导入。 |
| 收付款记录 | 对已有款项登记正常收付款 | 款项ID从应收应付列表导出获取。采购付款须先确认对账，金额不得超过可收付余额；退款、冲销从原记录操作。 |
| 工时 | 向已有任务登记实际工时 | 填任务ID，人员填姓名或登录账号；日期不能晚于今天，同人同日净工时合计最多24小时，岗位与项目范围仍须满足。 |
| 发货 | 登记实际交付，并生成安装、验收任务 | 先完成设计、装配、调试与配套领料。设备数量填整数；多单元项目请从页面发货并填写配套清单。 |

银行流水使用银行原始文件，不属于上述可填写模板：在“银行到账与认领”上传工行XLSX或华夏XLS原始流水，保留银行表头与汇总，不改套业务模板。

## 最容易填错的地方

### Excel 下拉选择和填写提示

请重新下载 `.xlsx` 模板，并在支持数据验证的表格软件中打开编辑。在“填写说明”页点击字段下方的“▼点此选择”，可跳到对应的空白输入格；也可以先点击“开始填写”，再单击第2行起的数据单元格，点击右侧▼展开选项。不要点击表头，也不需要双击单元格。选中数据格时还会显示填写要求、资料来源和示例。

| 模板 | 可直接选择的内容 |
| --- | --- |
| BOM、物料 | 产品编码类别、标准件/非标件；单位提供常用选项，也允许手填实际单位 |
| 往来单位 | 客户/供应商/客户及供应商、采购账期 |
| 采购 | 采购账期 |
| 项目任务 | 设计、装配、调试 |
| 收付款记录 | 银行转账、现金、其他 |

固定选项只能选择列表内的中文值，避免漏字或写成其他类别。单位的列表只是常用建议，不限制实际单位；已有物料须沿用原单位。姓名、规格、图号、项目编号和记录ID等按真实资料填写，不提供虚构的人员或业务记录选项。

红色表头表示必填，黄色表示条件必填，蓝色表示可选；表头名称和顺序保持不变。开始填写一行后，能从该行判断的必填空格会标红，例如BOM编码留空时的名称、规格、类别和单位，有图新物料的图号。是否修改已有BOM、人员权限、采购付款对账等依赖系统数据的条件仍以预览为准。

下拉、输入提示及标红覆盖第2～1001行。空白行不会被标红，也不会作为记录导入。粘贴可能覆盖或绕过Excel校验，仍需上传预览；CSV不保留这些交互功能，须按填写说明中的允许值填写。旧模板仍可导入，但需要重新下载才能获得新提示。

### 产品编码类别与物料类别

| 列名 | 允许值与含义 |
| --- | --- |
| 产品编码类别 | 用于自动编号。11＝有图·机加，12＝有图·钣金，13＝有图·特殊工艺，19＝有图·其它，21＝无图·标准件，22＝无图·耗材辅料，23＝无图·办公用品，29＝无图·其它。Excel选完整中文名称，CSV可填编码或完整中文名称，不能只填1或2。 |
| 物料类别 | 只区分标准件、非标件，也可留空。通常外购标准产品选标准件，按项目图纸定制的零件选非标件；不填写机加、钣金。 |
| 图档版本 | 填实际版本，例如A；没有版本可空。不要填PCS或品牌。 |
| 单位 | 填实际计量单位，例如件、台、PCS；沿用已有物料的单位。 |

### 日期、人员、编号与ID

- 日期填具体年月日，例如`2026-10-20`。不填写`20天`、`20`或普通数字`46290`。Excel日期应使用日期格式，CSV应保存为`YYYY-MM-DD`文本。
- 负责人、执行人、项目成员、工时人员、安装人、验收人均可填写**姓名或登录账号**。例如用户名为 `wuxingguang`、姓名为“吴兴广”，可直接填“吴兴广”，也可填 `wuxingguang` 或 `吴兴广（wuxingguang）`。
- 姓名必须与人员资料一致，不按简称或模糊拼音猜测；重名（含停用人员）或姓名与他人账号相同时，请填写**姓名（用户名）**明确对象。括号可用中文或英文，姓名与用户名须属于同一人；人员须启用并满足原岗位、项目范围要求。人员选择列表以姓名在前、账号在括号内显示。
- 多个项目成员用中文或英文分号分隔，可混用姓名与账号。旧模板的“执行人账号”等表头仍兼容，新模板改为“执行人姓名或账号”等明确名称；不要手动调整列顺序。
- 预览后若姓名、账号对应关系变化，系统会要求重新预览，防止误派给另一人。BOM的“申请人”仍是纸面申请人姓名文本，不关联系统账号。
- 项目编号、物料编码、客户编码、供应商编码都来自相应业务列表。标为“ID”的字段填写列表导出的**记录ID**，不能填编号或名称。
- 编码、账号、电话、银行流水号和记录ID等输入列已设为文本格式，保留前导零及全部位数；粘贴时仍需核对原始值，已在其他文件中丢失的数字不能自动恢复。金额最多2位小数、数量最多3位小数；不加单位文字、货币符号、千分位或公式。

### 已有物料、新物料与重复行

- BOM引用已有物料：填有效物料编码，后方物料资料可空；填写时须与主数据一致，BOM导入不会覆盖物料资料。
- BOM新建物料：编码留空；名称、规格、产品编码类别、单位必填，有图产品另填图号。即使有图号，也不能省略规格。外部系统的编码不会自动成为系统已有物料。
- 规格填写真实识别信息：标准件填厂家型号，例如`HGW20CC`；加工件可填实际材质和尺寸，例如`6061铝板 200×100×10mm`。示例不能照抄为未知物料的规格，资料不足时请向设计人员确认。
- 同一编码可以用于不同单元；同一编码、同一单元只能出现一行，空单元也会判重。先核实是重复粘贴、独立用量还是不同单元，再决定保留、合并数量或区分单元，不能直接全部删除或累加。
- 修改已有BOM行必须填变更说明；数量还受已领、在途等业务事实限制。

## 提交前检查

1. 确认当前页面和文件类型对应；项目列表用于新增项目，项目任务页用于新增任务，BOM页用于导入物料需求。
2. 保留模板表头，不改列名、顺序，不增加业务列；最多1000条数据、5MB。Excel可保留系统自带说明页，不要增加其他工作表。旧单工作表模板仍兼容。
3. 本地文件选好后点击系统文件窗口的“打开”；无需使用浏览器的“从移动设备上传”。
4. BOM选择文件后会立即打开预览窗口，先显示“正在读取文件并校验物料”，随后显示明细或错误。校验未通过时按“文件行号”和“填写问题”修改原文件，关闭窗口后重新上传；只有校验通过才能确认导入。
5. 检查预览中的归属、数量与错误行号。预览不保存；确认时重新校验，任一行失败整批不保存。确认成功的文件不要重复导入。
6. 提示表头不匹配时，先确认业务入口，再重新下载对应模板，只把业务数据按列粘贴为值，不覆盖新模板表头。提示没有数据时，检查是否已在“数据”页第2行起填写；仅修改说明页或示例不会产生导入记录。

本说明不放宽系统的岗位、项目范围、状态和金额校验。每个模板的详细字段条件，以下载文件中的同版“填写说明”为准。
