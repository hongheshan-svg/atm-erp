# 导入模板填写说明

适用于系统提供的全部14类导入模板（13类通用业务模板及BOM模板）。请从需要办理的业务页面重新下载模板，不要把项目、任务、BOM或列表导出的文件混用。

每个模板的用途、上传入口、每列必填条件、允许值、资料出处和场景示例由系统随模板生成，以下载文件中的同版“填写说明”为准；本页只汇总跨模板的通用做法，不重复各列规则。

## 说明在哪里

- **Excel模板**：包含“数据”和“填写说明”两个工作表，打开后先显示“填写说明”。先看“①先准备、②最少填什么”和通用规则，再点击蓝色“开始填写”跳到数据页第2行；一行一条，不改表头。选中数据页的单元格可查看该列提示，点击单元格右侧▼选择固定选项。
- **独立说明文档**：在下载模板旁点击“下载填写说明”。文档可用浏览器打开、打印或转发，内容与Excel说明一致。
- **CSV模板**：只包含数据表头，须以 **UTF-8** 编码保存，不能携带说明页、下拉或提示；请把独立说明文档一起发给填写人员，按其中的允许值填写。
- **页面说明**：通用导入窗口先显示准备资料和最少填写内容；“模板字段与页面列对应说明”中也能查看必填条件、资料来源、规则和示例。

下载文件以中文业务名命名，例如“项目任务导入模板.xlsx”“BOM导入填写说明.html”。先核对文件名和当前页面，再开始填写。示例仅说明格式，示例中的姓名、账号、编码和ID不代表系统已存在这些记录，必须换成实际业务值；说明页不会导入，数据页不预填示例。

## 提交前检查

1. 确认当前页面和文件类型对应；项目列表用于新增项目，项目任务页用于新增任务，BOM页用于导入物料需求。
2. 保留模板表头，不改列名、顺序，不增加业务列；行数和文件大小上限见说明页。Excel可保留系统自带说明页，不要增加其他工作表。
3. 本地文件选好后点击系统文件窗口的“打开”；无需使用浏览器的“从移动设备上传”。
4. BOM选择文件后会立即打开预览窗口，先显示“正在读取文件并校验物料”，随后显示明细或错误。校验未通过时按“文件行号”和“填写问题”修改原文件，关闭窗口后重新上传；只有校验通过才能确认导入。
5. 检查预览中的归属、数量与错误行号。预览不保存；确认时重新校验，任一行失败整批不保存。确认失败会显示具体错误行，修改文件后重新预览。
6. 提示表头不匹配时，先确认业务入口，再重新下载对应模板，只把业务数据按列粘贴为值，不覆盖新模板表头。提示没有数据时，检查是否已在“数据”页第2行起填写；仅修改说明页或示例不会产生导入记录。

粘贴可能覆盖或绕过Excel的下拉与提示，上传后仍须检查预览。本说明不放宽系统的岗位、项目范围、状态和金额校验。

## 重复导入与结果核对

通用业务模板会按业务归属和规范化内容识别已经成功的导入，改文件名、改行序或在 CSV 与 Excel 之间转换不能规避检查。出现“相同业务归属和内容已成功导入”时，先核对现有记录；只有确实要新增另一批相同业务，才勾选“确认再次导入并新增相同内容”。费用、工时、收付款尤其要核对，不能把网络超时当成需要再记一次账。

确认时仍会检查是否已有同批内容导入；失败的批次不算成功。同一次确认因网络问题重试会返回原结果，不重复写入。成功后可点击“查看导入记录”或“查看首条导入记录”打开原记录核对。BOM仍按项目、物料和单元维护版本；银行原始流水沿用银行交易标识防重，不使用“再次新增相同内容”选项。
